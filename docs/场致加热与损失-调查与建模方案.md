> 以及正确的量级）；③ 分四层、可落地的建模方案与验收锚；④ 需要使用者裁决的 6 个决定。

## 0. TL;DR

1. **这不是一个"加热"问题，而是三类不同东西的混称**——必须分开建模，否则一定既漏又重：
   - **内态流出**（相对当前基组：60S→6P→5S/5P/…）：**已经能精确表达**（现成的 decay / Lindblad 通道），
     不需要"加热"这个概念；
   - **反冲加热 → 阱逃逸**（真正的物理损失，基组无关）：本项目**完全没有**，需要新增"场致损耗 + 阱模型"；
   - **机械/电离型直接损失**（Rydberg 被 ODT 推出、被寻址光光电离）：只需一个**线性于光强的速率**，
     但 ARC **不给光电离截面**，需要参数化。
2. **现成的载体已经够用**：非厄米对角 `−iΓ(t)/2` 恰好同时给出"布居流失 γ"与"相干退化 γ/2"，
   与 `L=√γ|sink⟩⟨i|` 的 Lindblad 等价（本仓已实测等价性 ≤2.2e-9）。
   真正的工程量在 ①**时变**（γ ∝ env(t)²）②**分支比/双计** ③**分项记账**。
3. **发现一个真问题（实测）**：`field_build.real_field` 里已有的"远失谐散射损失" `scatter[N]`
   **把源态与衰变率用反了**——它把损失记到**低能态**上、并乘**高能态的**寿命；
   对里德堡寻址几何（短寿命 6P 在**下面**）实测**恒为 0**（或小了 1000 倍），
   而正确的 60S 去布居率应是 `(Ω²/4Δ²)Γ_6P`。这正是当年"exchange depump 缺失"的根因候选。
4. 建议路线：**L2（时变场致损耗通道）+ L3（阱加热逃逸层，可选但推荐）**；
   今天就能用的临时方案是 **L1（把平均散射率当常数通道塞进 `dynamic.decays`）**。
5. **"光越强越容易加热逃逸"能否复现**（§4.5，本轮的追加结论）：
   **L2 单独只能给出"越强越丢"的内态损失（`γ∝I`，且有 `Γ/2` 饱和上限），
   给不出"加热逃逸"的三件特征——累积、阱深依赖、陡峭阈值**；这三件必须由 **L3** 补。
   并且实算表明：**µs 尺度 + mK 阱里反冲加热逃逸根本来不及**（需 11× 饱和上限的散射率），
   那个区间若观察到"越强越丢"，真凶更可能是**光电离/反陷阱**（∝I，无上限）——即 L4 应优先于 L3。

## 1. 机制清单与量级（本项目参数下）

记 `Ω` = 该对的峰值 Rabi（周频 MHz）、`Δ` = 相对该跃迁的失谐、`Γ_j = 1/τ_j` = 伙伴态总衰变率（MHz）、
`E_r = ħ²k²/2m` = 反冲能、`κ_geo` = 几何因子（扩散/定向，1～2）。

### 1.1 残余光子散射（**场致损失的"发动机"**）

正确的逐态规则（光源态 i、伙伴 j；`E_i<E_j`，光相对 i→j 跃迁失谐 Δ）：

$$\gamma_i^{\text{sc}} = \sum_{j \neq i}\frac{\Omega_{ij}^{2}}{4\Delta_{ij}^{2}}\,\Gamma^{\text{out}}_{j}
\qquad\text{（对称地交换 } i\leftrightarrow j\text{）}$$

即：**每个态的流失率 = 光把伙伴态"掺"进来的概率 × 伙伴态离开基组的衰变率**。

> ⚠ **上式的适用域 = `s≪1`**。含饱和的正确形式：`R_sc = (Γ/2)·s/(1+s)`，`s = 2Ω²/(4Δ²+Γ²)`。
> 两条推论（本文 2026-09-15 补，实算）：
> - **线性式在强场高估**：Δ=5 GHz、Γ_6P=8.464 MHz 时，Ω=5 GHz 高估 1.5×，Ω=20 GHz 高估 **9×**；
> - **散射通道有天花板**：`R_sc ≤ Γ/2 = 4.23 MHz`（6P）⇒ "光越强"到这一步就**不再更快**了。
> 这直接决定了"越强越容易逃逸"能不能复现：见 §4.5。

- 推导：原子在 i 时，j 的掺入振幅 `Ω/2Δ` → 布居 `Ω²/4Δ²` → 以 `Γ_j` 衰变；
  原子在 j 时同理，掺入 i 的布居相同，但按 `Γ_i` 衰变。**两个态的流失率数值系数相同、用的 Γ 是"对方"的。**
- **`Γ_out` 是相对基组的量**：伙伴的衰变落到基组内 = 回流（不是损失）；落到基组外 = 损失。
  这一条决定了"exchange depump"到底要不要算 loss（见 §4.2 双计规则）。
- 里德堡寻址的特例（本仓主场景：`60S ↔ 6P`，`ν=295.72 THz`，`λ=1013.8 nm`）：
  `Γ_out(6P)=8.464 MHz`（τ=118.1 ns）而 `Γ_out(60S)=4.35×10⁻³ MHz`（τ=230 µs）
  → **决定性地由 6P 的短寿命给出**，与 60S 自己的寿命无关。

| 场景（Ω/2π=100 MHz） | Δ | 正确 γ(60S) | γ(6P) 错误值（现行代码） |
|---|---|---|---|
| `60S↔6P` 寻址 | 1 GHz | 2.12e4 s⁻¹（但被归为"近共振相干驱动"，见 §3.3） | 0 |
| | 5 GHz | **846 s⁻¹** | 4.35e-7 MHz = 0.43 s⁻¹（**记在 6P 上**） |
| | 20 GHz | **52.9 s⁻¹** | 2.72e-8 MHz = 0.027 s⁻¹（**记在 6P 上**） |

（实测见 §3.2；`I(Ω=100 MHz)=6.09×10⁷ mW/cm²`，与手册"60S↔6P 需 10⁷–10⁸ mW/cm²"一致。）

### 1.2 反冲加热 → 阱逃逸（**真正的"加热损失"**）

- 每次散射注入运动自由度 ≈ `κ_geo·E_r`：
  `Ė = R_{sc}·κ_{geo}·E_r`，总散射光子数 `N_sc = ∫R_sc(t)dt`，升温 `ΔT = N_sc·κ_{geo}E_r/k_B`。
- 本仓参数（λ=1013.8 nm, ⁸⁷Rb）：`E_r/k_B = 107.2 nK`（`E_r/h = 2.23 kHz`）。
  → 846 s⁻¹ × 107 nK ≈ **90 µK/s**；1 mK 阱深（无冷却）需 ~11 s 才"烧穿"。
  可见 **µs–ms 尺度的短实验里，加热损失远小于内态流出**；它只在"长驻留 / 反复脉冲累积 / 浅阱"下主导。
- 逃逸模型（两档，见 §4.3）：① 现象学 `γ_esc = p_esc·R_sc`；② 温度 ODE + 逃逸判据 `P(E>U)`。
- 注意 **ODT 自身的散射**（非寻址光）也是同一公式：典型 1e2–1e3 s⁻¹ → 0.01–0.1 mK/s
  → 与实验上 ODT 寿命 1–10 s 同量级 ✓。

### 1.3 光电离（**强光下 Rydberg 的主损失**）

单光子电离率 `R_PI = σ_PI(λ,n)·Φ`，`Φ = I/hν` 光子通量。取 `σ_PI ≈ 1–10 Mb`（1 Mb=10⁻¹⁸ cm²，里德堡典型值）：

| I（1064 nm） | Φ | R_PI（σ=1 Mb…10 Mb） | τ_PI |
|---|---|---|---|
| 1e3 W/cm² | 5.4e21 /cm²/s | 5.4e3…5.4e4 s⁻¹ | 0.2…0.02 ms |
| 1e4 W/cm²（=1e7 mW/cm²，聚焦寻址光的量级） | 5.4e22 | 5.4e4…5.4e5 s⁻¹ | 20…2 µs |

→ **在强聚焦寻址光/深阱下，光电离可以比反冲加热快 5–6 个量级**：这才是"场造成原子丢光"的主因之一。
⚠ **ARC 不提供光电离截面**（已核对 API：只有 `getStateLifetime`、`getBBRshift`、`getTransitionRate`…，
无 photoionization 方法）→ 必须**参数化**（用户给 σ 或用解析近似）。

### 1.4 其它（按需）

| 机制 | 形式 | 备注 |
|---|---|---|
| **反陷阱 / 辐射压**（Rydberg 在 ODT 中） | 力 → µs 内被推出 | 不是加热；等价于给 Rydberg 态一个额外"寿命"；有方向性，还会给空间依赖相移 |
| **参量加热**（阱光强度/指向噪声） | `Γ_heat ≈ (π²/8)ω_t²S_I(2ω_t)` | 需要噪声谱输入（本项目无） |
| **光助碰撞 / 光缔合**（两体损失） | `L = √β\|sink⟩⟨i_A j_B\|`（∝n²） | 现有两体损耗是**逐原子**的，需新增两体损失算符 |
| **黑体辐射**（300 K） | 走 `auto_decays(temperature=300)`（ARC 温度寿命） | 只改变**内态**；BBR 光子反冲可忽略 |

### 2.2 完全缺失的

- 任何 **加热/反冲/阱** 概念：全库 grep `heating|recoil|反冲|加热|逃逸|photoion|ioniz` → **0 命中**；
- **时变** 的 Γ（现有 `_single_loss_rates` 返回常数向量；Lindblad 跳变算符也是常数）；
- **loss 分项记账**（现在只有一条总 `loss`；无法回答"这 3% 是自发辐射还是散射还是电离"）；
- **分支比**（`auto_decays` 把一切都当"丢失"，含基组内的回泵——见 §4.2 的双计风险）；
- 光电离、两体损失、参量加热。

## 3. 两条实测结论（调查的核心证据）

### 3.1 复现命令

```bash
python -c "
import sys; sys.path.insert(0,'.')
import src
from src.core import core, field_build as fb
from src.core.atomic_levels import make_levels
from arc import Rubidium87
cache=core.ArcCache(Rubidium87())
st=make_levels(cache,[                                    # [60S(m=+0.5), 6P3/2(m=+1.5)]
  dict(n=60,l=0,j=0.5,m=0.5,E_mhz=core._sublevel_energy(cache,60,0,0.5,0.5,0.0)),
  dict(n=6,l=1,j=1.5,m=1.5,E_mhz=core._sublevel_energy(cache,6,1,1.5,1.5,0.0))])
nu=st[0]['E_mhz']-st[1]['E_mhz']                          # 295.72 THz
d=core.dipole_amplitude(cache,fb._sublevel_row(st[0]),fb._sublevel_row(st[1]),+1)
I=core.intensity_mwcm2_from_rabi(d,100.0,1.0)             # Ω/2π = 100 MHz → 6.09e7 mW/cm²
for dg in (5000.,20000.):
    fld,ac,sc=fb.real_field(cache,st,nu+dg,I,pol='σ+',return_scatter=True)
    print(dg, 'scatter[60S]=%.3e scatter[6P]=%.3e MHz'%(sc[0],sc[1]))"
```

### 3.2 实测结果

```
det=  5000 MHz -> scatter[60S]=0.000e+00  scatter[6P]=4.349e-07 MHz
                 （正确应为 scatter[60S] = Ω²Γ_6P/(4Δ²) = 8.464e-04 MHz）
det= 20000 MHz -> scatter[60S]=0.000e+00  scatter[6P]=2.718e-08 MHz
                 （正确应为 scatter[60S] = 5.290e-05 MHz）
```

**读法**：`scatter[lo] += Ω²·Γ(hi)/(4Δ²)`（`field_build.py:376-411`：`lo/hi` 按**能量**分，
`gam` 取 `states[hi]`）。对"短寿命态在**上**面"的几何（如 `5S→6P`）它恰好是对的——
实测 `scatter[5S]=5.290e-05 MHz` 与公式**逐位一致** ✓；但对**里德堡寻址**几何
（短寿命 6P 在**下**面）就变成了：**源态取错 + 用了错的 Γ**（小了 1000 倍，且挂在 6P 上）。
里德堡态的流失在结果里恒为 0 ⇔ 使用者当年报的 "exchange depump 缺失"。

### 3.3 顺带一条**语义**发现

`real_field` 的分流判据是 `|Δ| < max(AC_NEAR_CUTOFF_MHZ=5 GHz, Ω) → 相干驱动`。
所以 **Δ < 5 GHz 时根本不算"散射损失"**（走 A 矩阵，由引擎精确演化）。这在物理上是合理的
（那个区间必须用含 6P 衰变的相干动力学描述，而不是二阶微扰），但**用户必须知道**：
"散射损失"这项只在 `Δ ≳ 5 GHz` 才有定义；近共振区间的去布居要**靠把 6P 放进基组 +
给它衰变通道**来精确得到。

## 4. 建模方案（分层，从今天可用到最完整）

### 4.1 L1 · 现象学常数通道（**零代码，今天就能用**）

算一个代表值 `γ̄_i = ⟨env²(t)⟩·Σ_w Ω²_{iw}Γ^{out}_w/(4Δ²)`，塞进：
```python
set_param('dynamic.decay_index', 2)
set_param('dynamic.decays', [{'from': <态键>, 'to': None, 'gamma_mhz': γ̄}])
```
- 适用：只想看"加了一项损耗会怎样"的量级判断；或验收用。
- 缺点：丢掉 env(t)² 的时间结构（脉冲只在一段时间内加热 → 常数 Γ 会**在脉冲外也损耗**，
  与 AC 化那条同类的错误）；不区分来源。

### 4.2 L2 · 时变"场致损耗"通道（**推荐核心**）

**物理内容**：`γ_i(t) = Σ_w env_w(t)² · γ_iw`，`γ_iw = Σ_j Ω²_{ijw}Γ^{out}_{jw}/(4Δ²_{ijw})`
（§1.1 的规则；`Γ^{out}` 由分支比给出）。

**三条必须写进文档/日志的规则**：
1. **双计规则**：只有当伙伴态 j 的衰变**离开基组**时才把 `γ_iw` 加进 loss。
   若 j 在基组内、且它的衰变已经作为 `decay` 通道建模（例如 6P 在基组里、已配 τ=118 ns），
   那么"i→j 相干驱动 + j 衰变"这条路径**已经由演化自动产生**了流失，**再加 γ 就是双计**。
   ⇒ 实现时必须按 `Γ_out(j) = Γ_j − Σ_{k∈basis}A_{jk}` 计算（ARC `getTransitionRate` 可算分支）。
2. **近共振区间不启用**（`|Δ| < max(near_cutoff, Ω)`）：那里必须靠相干动力学，见 §3.3。
3. **`loss` 必须分项**：`loss_自发辐射 / loss_散射 / loss_电离 / loss_黑体`，否则无法归因（也违反本项目的
   "改物理必须交代"纪律）。

**四个引擎的接缝（都已存在，工作量不同）**：

| 引擎 | 需要的改动 | 难度 |
|---|---|---|
| `mixed` | 复用 `ac_base/ac_env_tab` 的**同一形状**：另加一条 `loss_base`（复/或实数率） + 在 `rhs_phi_pairs` 加 `−iC·Σ_w γ_w·env²·φ`（现成的 `env²` 表，仅多一项） | **小** |
| `hard` | `gamma` 从常数向量 → 逐波表：在 njit RHS 里加"逐波 env² 查表 × 逐态 γ"项（与现成 `_env_at` 表同款） | 中 |
| `sambe` | 经 `opt_terms` 注入 `kron(I_P, −i·diag(γ)/2)·env²`（该通道支持复矩阵：非厄米走 `eig`） | 中 |
| `evolve_reference` / `evolve_rwa` | 时变跳变率 `L=√γ(t)\|sink⟩⟨i\|`（马尔可夫时变率合法）；或等价地加 `−iγ(t)/2` 对角 | 小 |
| **loss 记账** | `loss(t)=∫Σ_i γ_i(τ)p_i(τ)dτ`（把现在的常数 Γ 换成逐点 γ；梯形误差沿用 §非幺正文档 §5.2 的判据） | 小 |

**新参数（建议入册）**：`dynamic.field_loss`（开/关，默认**关**）、`engine.FIELD_LOSS_NEAR_CUTOFF_MHZ`
（默认沿用 5 GHz）、`engine.LOSS_BRANCHING`（是否用 ARC 分支比，默认开）、`engine.PI_SIGMA_MB`
（光电离截面，默认 0=不做，见 L4）。

**诊断输出（建议加进 `diag`）**：逐波逐态 `γ_iw` 表；`N_sc = ∫R_sc dt`（总散射光子数）；
`ΔT_heat`（升温估计，见 L3）；`loss` 分项曲线；"因双计规则被跳过"的通道清单。

### 4.3 L3 · 反冲加热 → 阱逃逸层（**要做"真加热损失"就需要**）

- 新参数（建议 `trap.*`）：`OMEGA_TRAP_KHZ`（ω_t/2π）、`DEPTH_UK`（阱深 U/k_B，µK）、
  `KAPPA_GEO`（1～2）、可选 `ESCAPE_MODEL`（`pesc` | `boltzmann`）。
- 两档模型：
  - **P-档（现象学）**：`γ_esc(t) = p_esc·R_sc(t)`，`p_esc` 由 `E_r/U` 或直接给（默认 `min(1, κE_r/U)`）。
  - **T-档（温度 ODE）**：`dT/dt = (2/3k_B)·κ R_sc E_r − Λ_cool(T)`，
    `γ_esc = R_sc·P(E>U)`（Boltzmann/截断高斯）+ 可选再捕获。
- 加法：`γ_esc(t)` 与 L2 的 `γ_i(t)` 一起进同一个 `−iΓ(t)/2` 对角（**形状完全相同**，只是权重不依赖 i）。
- **诚实声明**：这是"把运动自由度绝热消去"的模型，**必须**在文档与日志里写明所用 `κ`、`U`、逃逸判据；
  没有阱参数时**不许**给"加热损失"数字（否则是编的）。

### 4.4 L4 · 扩展（按需，不在第一版）

- **光电离**：`R_PI,i = σ_PI·env²·I/hν`（线性光强 → 与 L2 同一条通道，只是系数来自 σ_PI）。
  ARC 无此数据 ⇒ 需用户给 `σ_PI`（或接一个解析近似，如氢原子型标度）。
- **两体损失**（光助碰撞/光缔合）：新增算符 `L=√β|sink⟩⟨i_A j_B|`（现有 `_pair_loss_vectors` 只有逐原子项）；
  β 需要用户给或从碰撞模型来。
- **参量加热**：需要噪声谱 `S_I(2ω_t)` 输入；建议先留在 L3 的 `Λ_cool`/`p_esc` 参数里不单独建模。

### 4.5 【关键】L2 能不能复现"光越强越容易加热逃逸"？

**短答：L2 单独复现不了这个现象的完整形态——它只能复现其中的"越强越丢"，而且丢的是内态；
"加热逃逸"必须 L2 + L3 合起来。**

| 现象要素 | L2 单独 | L2 + L3 | 说明 |
|---|---|---|---|
| 损失率随光强单调上升 | ✅（`γ ∝ I·env²`，直到饱和） | ✅ | L2 已含"越强越丢"的趋势 |
| 依赖**脉冲时长/累积**（不是瞬时速率） | ❌（瞬时速率，无记忆） | ✅ | 逃逸需要累积 `N_sc ≈ U/(2E_r)` 次散射 |
| 依赖**阱深 U / 阱频 ω_t** | ❌（公式里没有 U） | ✅ | `N_crit ∝ U` |
| **阈值/陡峭开点**（低于某强度几乎不丢） | ❌（过原点的直线） | ✅ | 冷却存在时 → Arrhenius `exp(−U/k_BT_ss)`，极陡 |
| 饱和后"越强不再更快" | ✅（`R≤Γ/2`） | ✅（`t_esc→N_crit/(Γ/2)`） | 见下表 |
| 强场下改由**光电离/反陷阱**主导（∝I，无上限） | ❌ | 需 L4 | 单靠散射会**低估**强场损失 |

**L2+L3 的链条**（每一步都已在本仓有落点）：
`R_sc(t)`（§1.1，L2 的核心）→ `N_sc(t)=∫R_sc·p_i dt` → `E_motion(t)=2E_r·N_sc` →
逃逸判据（`E>U` 或温度 ODE + `P(E>U)`）→ `γ_esc(t)` → 与 `γ_i(t)` 一起进 `−iΓ(t)/2`。

> ⭐ **实现技巧（省一个新状态量）**：`N_sc(t)` **就是 L2 的散射分项 loss 累加量**
> （同一个积分 `∫γ_sc·p_i dt`）。所以 L3 可以直接读 L2 已经算出来的那条曲线来判"加热预算"，
> 不需要给引擎加辅助变量；确定性无冷却模型下，逃逸 = `N_sc(t) > N_crit = U/(2E_r)` 触发的一次额外损耗。

**三档逃逸模型的标度差别（决定"越强越快"长什么样）**：

| 模型 | 逃逸时间标度 | 对强度的形状 |
|---|---|---|
| 定向/漂移（每次散射 ≈ `2E_r`，无冷却） | `t_esc ≈ N_crit/R_sc`，`N_crit=U/(2E_r)` | `∝ 1/I`，直线 |
| 纯扩散（能量随机游走） | `t_esc ≈ (U/E_r)²/(2D)`，`D~R_scE_r²` | 仍 `∝1/I`，但对 `U` 是平方敏感 |
| 有冷却（稳态温度） | `γ_esc ~ exp(−U/k_BT_ss)`，`T_ss ∝ R_sc ∝ I` | **指数陡峭**（"阈值"感最强） |

**量级实算（本仓参数，Δ=5 GHz，Γ_6P 给定）**：

| Ω/2π | `R_sc`（饱和式） | 线性式偏差 | 1 mK 阱 `t_esc` | 20 µK 阱 `t_esc` |
|---|---|---|---|---|
| 100 MHz | 846 s⁻¹ | ×1.00 | 5.5 s | 0.11 s |
| 1 GHz | 8.3e4 s⁻¹ | ×1.02 | 56 ms | 1.1 ms |
| 5 GHz | 1.41e6 s⁻¹ | ×1.5 | 3.3 ms | 66 µs |
| 20 GHz | 3.76e6 s⁻¹ | **×9** | 1.2 ms | 25 µs |
| ∞（饱和上限） | 4.23e6 s⁻¹ | — | **≥1.1 ms** | ≥22 µs |

（`N_crit = U/(2E_r)`，1 mK → 4664 次散射；`E_r/k_B=107.2 nK`，每次散射注入 `ħ²k²/m = 2E_r`。）

**两个可检验的物理判断（建议写进结论口径）**：
1. **µs 尺度 + mK 阱里，反冲加热逃逸"来不及"**：要在 100 µs 内把原子踢出 1 mK 阱，
   需要 `R_sc ≥ 4.7×10⁷ s⁻¹`——**是 6P 散射饱和上限（4.2×10⁶ s⁻¹）的 11 倍，物理上不可能**。
   所以在那类实验里，若真观察到"光越强越丢"，真凶更可能是**光电离 / 反陷阱（∝ I，无上限）**，
   而不是反冲加热——这正好是 L4 里那两项该优先做的理由。
2. **浅阱或长驻留才是加热逃逸的舞台**：20 µK 阱 + Ω=5 GHz → `t_esc≈66 µs`，
   此时"越强越容易逃逸"会以**阈值**形式出现（脉冲长于 `t_esc` 就掉）。
   交叉校验：ODT 自身散射 ~1e3 s⁻¹ ⇒ 1 mK 阱 `t_esc≈4.7 s` ✓ 与实验上 ODT 寿命的秒量级一致。

## 6. 需要裁决的 6 件事

1. **加热损失要"物理量驱动"还是"现象学"？**（L3 的 `p_esc` 一参数 vs `ω_t/U/E_r/κ` 模型）
2. **场致损耗默认开还是关？**（默认开会**改变现有 exchange 结果**；建议默认关 + 运行前报告量级，
   与 `COST_BUDGET` 那次"成本不该默默改模型"的裁决保持一致）
3. **是否做分支比（ARC `getTransitionRate`）**？不做的话，"6P 在基组内"就会被误算成 loss（双计/漏项）。
4. **光电离要不要进第一版**？（ARC 无截面 → 必须由使用者给 σ，或用近似标度）
5. **是否要"内态流出"与"真实逃逸"两条独立的 loss 曲线 + 诊断分项**？（强烈建议要，否则无法归因）
6. **两体（光助碰撞/光缔合）是否纳入**？（需要两体损失算符，属新机制）
7. **"越强越快"的标度取哪一档**（§4.5）：漂移 `∝1/I`（直线）/ 扩散（对 U 平方敏感）/
   有冷却的 Arrhenius（指数陡峭，"阈值"感最强）？——这一项决定 L3 的模型形态与参数个数。
