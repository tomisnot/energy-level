# 多体接口与维护约定

本说明对应 2026-10-30 的整理。审查发现及原始复现记录见 [多体架构审查](多体架构审查-2026-10-30.md)。

## 代码职责

| 模块 | 负责的事实 |
|---|---|
| `model.py`、`assemble.py` | 模型和原子标定；完整或指定基空间的 CSR 共用装配实现 |
| `backends.py` | 后端规范名称、别名、执行入口、支持的任务/能力、配置到形参的映射 |
| `schema_mb.py` | 产品可设置参数、单位、默认值和值域 |
| `basis.py`、`hamiltonian_plan.py` | MSB 位序、原子身份、受限基、约束图及编译入口 |
| `state.py` | 初态语法、在指定基中准备态矢、MPS 接续与 checkpoint |
| `runtime.py`、`resources.py` | 时间网格、分段跳变、协作取消/进度、工作区预算 |
| `runspec_mb.py`、`eq_engine.py` | 产品配置适配，标定与纯数值执行的线程边界 |
| `eq_route.py` | 通用任务路由；gs、thermal、DOS、ramp 分开执行，共用 QMC 适配 |
| `engine_*.py`、数值算法模块 | 后端实现、模型相关适用条件和算法诊断 |
| `results.py` | 结果数据含义、坐标轴、单位、身份和兼容字段 |

配置默认值用 `mb_get` 读取，不能用 `value or default`，否则合法的 0 会被覆盖。新增后端先修改能力声明，再实现数值函数；schema、GUI 选项和公共分派从声明派生。动态适用条件仍在求解器内检查，不能把所有物理判断塞进注册表。

ARC 标定必须在 cache 所属线程执行。RunSpec 携带数值标定快照；工作线程/进程不重新访问 ARC。标定缓存键包含能级、位置、周期长度、相互作用项、B、窗口、截断及标定精度，不包含 Ω/δ/Γ 等运行级驱动。

## 产品模型与研究 API

产品 `manybody.*` 输入固定为每原子 g/r 二能级、标定后的 I1/I2/I3 全相互作用，模型标记为 `full`。

`manybody.template`、`manybody.terms` 已退出可写配置。旧快照仍可计算，但构建时会提示迁移并明确使用全相互作用。Python 研究 API `ManyBodyModel(template=..., terms=...)` 保留显式项选择，不将研究模型的开关重新暴露到产品配置。

## 当前含时能力边界

| 后端 | 分段驱动 | 投影基 | gamma/跳跃 | 返回态 | 固定荷 |
|---|---|---|---|---|---|
| ED | 支持，精确分割跳变 | 支持，共用稀疏/稠密路径 | 非厄米 no-jump | 态矢与基身份 | 含时暂不提供；平衡态支持 |
| CPU TEBD/TDVP 系列 | 支持 | 拒绝 | gamma 必须为 0 | 有限 TeNPy MPS | 支持，检查守恒 |
| GPU TEBD/SWAP-TEBD | 支持 | 拒绝 | gamma 必须为 0 | torch MPS 张量快照 | 拒绝 |
| 量子轨迹 | 明确拒绝 | 拒绝 | 局部跳跃通道 | 暂不提供 | 暂不提供 |
| 经典自旋 | 明确拒绝 | 拒绝 | gamma 必须为 0 | 自旋时序 | 不适用 |
| PEPS | 明确拒绝 | 拒绝 | gamma 必须为 0 | 暂不提供 | 暂不提供 |

TEBD/PEPS 还需满足各自的相互作用几何要求。原生 MPS 只能交给匹配的后端；全空间纠缠向量/叠加式与一般局部乘积态不是同一种输入。整数乘积态索引按 site0-MSB 展开，无需分配全空间向量。

不支持的物理输入必须明确拒绝。新实现不得通过 `**kwargs` 接受后静默丢弃；保留扩展参数的入口要拒绝未知键。进度与取消在输出/内部步的协作检查点处理，单个线性代数库调用通常不能中途打断。

## 基空间与资源

原子 0 对应最高位，`r=1`、`g=0`。`basis_bits(N, codes)` 是将基矢身份映射到原子占据的公共函数。编译器不修改共享 Plan。

受限基按独立集生成，设有最大输出状态数；图计数使用带预算的删除/收缩递归，避免直接遍历所有 `2**N` 构型。计数预算不足时，预估端回退到保守全空间估计并说明原因。后端选择按有效基维度进行。

`memory_budget_mb` 使用 MiB，是主要数组和工作区的保守估计，不是操作系统/CUDA 分配器峰值的硬保证。ED 根据预算调整稠密阈值与联合概率输出；GPU/PEPS 检查自己的张量工作区。KPM DOS 不再先计算完整谱，谱界在较大矩阵上使用迭代求解；显式 exact/ED 热态与 DOS 仍需要谱分解并检查预算。

投影态的纠缠熵在实际 Schmidt 行列身份上计算；超过临时矩阵预算时返回 NaN 并给出说明，关闭计算时返回 None，不能填零假装没有纠缠。

## 结果数据契约

旧字段保留以兼容既有调用方，新消费者读取 `data_schema.version=1`。`data_schema.quantities` 按数据路径描述 `quantity`、`axes`、`unit`；描述不复制数值数组。未定义的相位或未求得的量用非有限值表示，描述会标记 `missing_values`。

| 数据 | 语义与坐标轴 |
|---|---|
| `pops` + `pops_kind` + `states` | 兼容输出；明确为 `(time,basis)` 的联合概率或 `(time,site)` 的逐原子占据，标签必须逐列对应 |
| `pops_atom` | `(time,site)` 原子激发占据 |
| `basis_probabilities`、`basis_states` | 已物化的联合基概率及受限基编号；完整基由 MSB 约定确定 |
| `basis`、`sector_idx` | 态矢所在的基空间、位序与索引，避免把受限向量误作全空间向量 |
| `sites` | 稳定 site_id 与可用的位置，供二维点阵图映射 |
| `S`、`corr` | 纠缠熵与关联矩阵；缺失值有明确含义 |
| `observables.*` | 局部自旋、复值升降算符、关联与环相位，保留真实复数 |
| `stderr`、`E_err` | 对应观测量的标准误差 |
| `E0`、`gap`、`evals` | 基态、本征能量和能隙；QMC 低温近似不伪造能隙 |
| `E/C/F` + `betas` | 逆温度轴上的热力学数据 |
| `rho` + `energies` | 真实能量轴上的归一态密度 |

`loss` 是兼容别名。新消费者必须区分 `physical_loss`、`norm_drift`、`no_jump_weight_deficit` 和 `survival_weight`。PEPS 数值范数漂移不表示原子离场，GUI 不再将这些数据统一标为离场损失。

RunSpec 结果记录 `requested_backend`、`resolved_backend` 与传递的 `used_options`；算法实际步长、截断、收敛等信息在 `error_report` 中。直接数值调用同样附加数据描述。存档保存完整引擎结果，不再维护第二套容易遗漏新字段的白名单；原生态的大数组由求解器的显式返回选项控制。

## 维护与验证

新增能力至少验证一个公开配置入口和一个拒绝案例。矩阵/观测交叉验证使用不对称失谐、复耦合和非平凡初态；不要只使用全 g 初态和对称点阵。

`checks/manybody_contract_selfcheck.py` 集中验证能力声明、配置转发、缓存失效、投影身份、分段边界、资源拒绝、数值后端入口和存档完整性，并纳入 `run_checks.py --core`。既有物理基准继续独立保留，不能用契约测试代替 ED/解析解参照。
