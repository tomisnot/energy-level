 # 引擎能力边界
 
 本文帮助使用者选择 Energy Level 的计算路径，并说明结果需要怎样解释。边界由体系规模、场类型、频率尺度、耗散、时间范围和所需观测共同决定。
 
 ## 1. 选择顺序
 
 1. 明确原子态、体系规模和初态；
 2. 明确外场、频率、极化和时间范围；
 3. 先运行 preview 检查输入和适用条件；
 4. 使用 estimate 评估维度、内存和时间；
 5. 选择路径并保存运行规格；
 6. 对关键结论用更高精度或参考路径核对。
 
 ## 2. 路径特征
 
 | 路径 | 适合 | 主要代价 |
 |---|---|---|
 | reference | 小体系、验证其它路径 | 维度和时间成本高 |
 | RWA | 满足旋转波和频率分离的驱动 | 依赖近似条件 |
 | mixed | 不同频率/耦合尺度需要分层处理 | 参数选择和诊断更复杂 |
 | two-field | 光场与微波场共同作用 | 场分解和带宽控制 |
 | ED | 小到中等多体 Hilbert 空间 | 内存随维度快速增长 |
 | TEBD | MPS 顺序上的最近邻一维/准一维含时演化 | Suzuki–Trotter 误差；不接受长程 MPO |
 | TDVP | 一维/准一维 MPS 含时演化，可处理长程 MPO | 键维截断；纠缠增长会限制时间 |
 | DMRG | 可利用低纠缠结构的体系 | 需要合适的链和截断 |
 | KPM | 谱和大稀疏系统的统计量 | 结果是近似展开 |
 | SSE-QMC | stoquastic 自旋/Rydberg 模型的有限温和低温统计量 | 仅无符号子集；有统计误差 |
 
 ## 3. 结果必须带的上下文
 
 - 使用的路径和 backend；
 - 状态数、截断和相互作用范围；
 - 时间网格、容限和最大步长；
 - 外场规格和初态；
 - 近似条件、诊断和警告；
 - 是否使用 GPU、分块或缓存；
 - 是否为部分完成或取消的结果。

多体含时求解器由 `manybody.solver` 选择：小系统可用 ED；TEBD 仅用于 MPS 顺序最近邻
耦合；任意点云或长程偶极耦合应使用 TDVP。当前 MPS 路径要求厄米 Hamiltonian（`gamma=0`）
以及乘积初态、内部求得的 ground 或显式传入的有限 MPS；非厄米损失仍使用 ED。
`manybody.return_state=true` 显式返回态矢或后续演化所需的 MPS。CPU TDVP 可以
保持显式 `manybody.charge_sector`；所有驱动段都必须守恒该荷。原生 TeNPy MPS
和 CUDA 张量 MPS 不隐式互转。详见 [多体接口与维护约定](多体接口与维护约定.md)。

任意阶 Pauli 串（`manybody.pauli_strings`）只返回 `⟨Π σ^a_i⟩`，不解释物理含义。
含时 `ed`、CPU MPS 四档、GPU MPS 两档、轨迹（系综平均）与经典自旋（因子化）可用；
PEPS/QMC/KPM/free-fermion/gpu-batch 没有多体态，明确拒绝并给出替代。近似后端必须读
`observables.approximation`，不能把因子化/系综平均当纯态期望。详见
[多体接口与维护约定](多体接口与维护约定.md)。

`manybody.eq_backend=qmc` 使用 SSE-QMC。它支持任意图和长程密度键，但会检查局部
`+/-` gauge 后的 stoquastic 条件；复相位或不可消除的负权会明确报 sign problem。
QMC 结果必须同时查看 `average_sign`、`samples`、统计误差和自相关诊断。

blockade/PXP 约束在多体装配层生成 `HamiltonianPlan`：`ed`、Lanczos 和 SSE-QMC
可直接消费约化基；当前 TEBD/TDVP 对 projected Plan 会明确要求改用 ED，避免把未投影
的 MPO 当成 PXP Hamiltonian。
 
 ## 4. 不应做的推断
 
 估算时间不是物理结论。单次运行的数值稳定不等于模型近似成立。较高分辨率不自动意味着更准确；应结合 reference、收敛性和误差指标解释。
 
 ## 5. 开发者更新要求
 
 增加或修改求解路径时，同步更新参数 schema、preview/estimate 的诊断、用户手册和最小对照测试。文档只描述当前可用能力，具体字段以运行时查询为准。
