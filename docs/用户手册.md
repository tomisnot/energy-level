 # Energy Level 用户手册
 
 Energy Level 用于研究 Rb-87 原子能级、外场驱动、时间演化、损耗和多体体系。软件提供 GUI、Python 入口、MCP 和后台任务；所有入口共享配置快照、查询和结果语义。
 
 ## 1. 能力范围
 
 - 单原子能级、Stark 位移、偶极和谱线；
 - 光场、微波场、极化和时间波形；
 - reference、RWA、mixed、two-field 等演化路径；
 - 两体和多体相互作用、ED、DMRG、KPM；
 - 估算、预览、正式演化和参数扫描；
 - 结果图、诊断、资源提示和运行产物；
 - GUI、MCP、后台任务、取消和只读监控。
 
 ## 2. 启动
 
 ~~~powershell
 python app_entry.py --gui
 python app_entry.py --mcp
 python app_entry.py --mcp --with-gui
 python -m mecha --all --root .
 ~~~
 
 GUI 适合交互式选态、看图和调参。MCP 适合 AI 或脚本调用。带 GUI 的 MCP 让人工和 AI 共享同一个配置与计算服务。
 
 ## 3. 基本流程
 
 1. 查询参数和当前状态；
 2. 选择原子、能级和外场；
 3. 使用 preview 检查有效输入；
 4. 使用 estimate 了解维度、时间和资源；
 5. 使用 run_sim 或提交后台任务；
 6. 查看摘要、诊断、警告和产物；
 7. 需要时读取具体波形、布居、谱线或图表。
 
 每次计算优先使用 spec_patch 表示本次变化，避免为试算改写共享配置。
 
 ## 4. 选择演化路径
 
 - 小规模和参考核对：reference；
 - 满足旋转波条件的常规驱动：RWA；
 - 频率尺度差异明显且需要混合处理：mixed；
 - 同时含光场和微波场：two-field；
 - 多原子或大 Hilbert 空间：先 estimate，再选择 ED、DMRG 或 KPM。
 
 具体适用条件以 query_params、preview 和 [引擎能力边界](引擎能力边界.md) 返回的诊断为准。
 
 ## 5. 单位与输入
 
 输入参数必须使用协议中声明的单位。常见字段包括能量、频率、时间、场强、极化、相位、温度和衰减率。不要从显示字符串推断单位；先读取参数描述。
 
 初态、态标签和目标跃迁应使用查询返回的稳定索引或 state key。不要手写数组下标替代查询结果。
 
 ## 6. 扫描
 
 扫描规格可以用轴或显式点定义。每个点有独立索引和状态。读取 sweep status 时区分正在排队、执行、完成、失败和取消。部分结果可以用于诊断，但不能当作完整扫描结论。
 
 ## 7. 长任务
 
 后台任务接口：
 
 ~~~text
 submit_job -> read_job -> read_job(wait=terminal)
                          -> cancel_job（需要时）
 ~~~
 
 取消是协作式的。任务最终状态和部分结果以 read_job 回执为准。等待超时只表示本次调用结束，任务可能仍在运行。
 
 ## 8. 结果解释
 
 必须一起看：
 
 - solver 路径；
 - 基组、截断和体系规模；
 - 时间网格、容限和 max_step；
 - 外场和初态；
 - 诊断警告；
 - 资源消耗和是否有部分结果。
 
 估算只用于计划资源。近似路径的结果需要结合误差指标和适用条件解释。
 
 ## 9. 常见问题
 
 ### 计算很慢
 
 先 estimate，降低基组、采样点或时间范围，检查是否误用了精确路径。多体问题先用小体系验证。
 
 ### 结果不稳定
 
 检查时间步长、容限、RWA 条件、场频率和初态。使用 reference 或更严格设置做对照。
 
 ### 任务没有立即取消
 
 取消是协作式的，solver 会在安全点检查。继续 read_job，观察 terminal、progress 和 partial result。
 
 ### 参数被拒绝
 
 调用 query_params 获取键、单位、范围和依赖。配置写入受当前 Authority/Gate 模式控制。
 
 ## 10. 适用边界
 
 软件给出数值结果和诊断，不替代物理解释。基组截断、近似、外场模型和数值容限都会影响结论。保存运行规格、参数快照和结果引用，才能复核实验。
