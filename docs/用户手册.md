# Energy Level 用户手册

Energy Level 用于研究 Rb-87 里德堡原子的能级、驱动演化和多原子体系。它同时提供桌面界面、Python API 和 AI 工具。

## 能力

- 静态能级、Stark 位移、偶极矩阵元和谱线分析；
- 单体与两体的 sambe、hard、mixed 等演化路径；
- 多原子阵列、相互作用和 ED 等求解路径；
- 配置预览、规模估算、参数扫描和结果摘要；
- GUI、MCP、后台任务、写权控制和只读监控。

## 使用方式

```bash
python app_entry.py --gui
python app_entry.py --mcp
python app_entry.py --mcp --with-gui
python -m mecha --all --root .
```

AI 使用 `query_params`、`preview_run`、`estimate_run`、`run_sim`、`run_actions` 等能力。先从查询结果取得物理索引和配置键，再提交计算。参数探索使用 `spec_patch` 只修改变化量，批量结果使用 `pick` 选择关注字段。

## 选择引擎

引擎的近似条件、适用规模、单位和误差边界见 [引擎能力边界](引擎能力边界.md) 与 [物理引擎专家手册](物理引擎专家手册.md)。数值结果需要结合近似条件解释；估时只是资源规划，不是物理结论。

## 写入和任务

配置写入经过统一写权并保留操作理由。长时间演化使用 `submit_job`、`read_job` 和 `cancel_job`；取消是协作式请求，最终状态以任务查询为准。完整结果通过产物引用获取，不把大数组直接塞进对话。
