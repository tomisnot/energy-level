# 多体引擎通用观测与时间步长契约

这份契约约束多体页的所有实时后端。实验脚本可以选择观测量，但不得把观测量实现复制到某一个求解器中。

## 时间

`manybody.t_grid`（或 RunSpec 产生的 `t`）只表示输出观测时刻。含时后端用 `manybody.max_step_ns` 作为内部最大积分步长，在两个输出时刻之间自动细分；输出数组的第一维仍然只对应 `t_grid`。

精确 ED 不需要把区间细分为数值积分步，它直接传播到输出时刻；这不是遗漏，而是其传播算法的物理/数值语义。MPS、PEPS、经典自旋和量子轨迹后端必须消费这个参数。

MPS 实时后端提供三种 TDVP 模式：`tdvp` 为两站点 TDVP，允许键维增长；`tdvp-single` 为单站点 TDVP，不主动增长已有键维；`tdvp-adaptive` 先用两站点 TDVP，达到 `adaptive_switch_chi` 且满足最小步数后切换到单站点。自适应模式必须用更高键维的两站点结果做收敛对照，不能把切换本身当成精度保证。

## 公共观测键

当 `want_observables=true` 时，实时后端使用同一组键：

- `sx`, `sy`, `sz`, `sp`, `sm`, `phase`：逐原子时间序列；`phase=arg(sm)`，相干幅度低于阈值时为 NaN。
- `link_pairs`：请求的有向原子对 `(i,j)`。
- `link_corr[t,q]`：`<sigma+_i sigma-_j>`，列顺序与 `link_pairs` 完全一致。
- `loops`：闭环原子下标。运行构建阶段会自动把闭环边并入 `link_pairs`。
- `loop_phase_series` 与 `loop_winding_series`：从链路关联计算的闭环相位和绕数。

ED/MPS/PEPS 给出量子链路关联；经典自旋给出因子化近似
`<sigma+_i sigma-_j> ≈ <sigma+_i><sigma-_j>`，轨迹后端给出轨迹系综平均。各后端必须在 `observables.approximation` 或 `error_report` 中标明这种语义差异，不能静默冒充相同精度。

`phase` 是局部一阶相位；闭环相位/绕数使用链路关联，因而是更适合规范场诊断的量。方格 plaquette 只是实验脚本对 `loops` 的一种选择，不能写进引擎核心。

## 实现纪律

1. 物理观测量放在 `src/core/manybody/observables.py` 或公共引擎契约中，不放在单个实验脚本或单个求解器的私有分支里。
2. 新后端若暂不支持某种观测，必须明确返回 `None`/近似标记或报出能力边界，不能接收参数后静默丢弃。
3. MPS 的密集 `N×N` 关联只在显式请求 `want_corr=true` 时计算；逐时链路观测使用 `link_pairs`，不能因为某个实验需要链路而默认计算完整矩阵。
4. 任意实时后端都要区分内部积分步与输出步；收敛性由改变 `max_step_ns` 的结果交叉检查。
