# 混合引擎锚验证矩阵设计（目标 2）

> 2026-09-06 船长设计（t62 验收后执行）。混合引擎（φ-帧 + 远对 AC 化 + 微波
> 当场，evolve_mixed）与既有权威引擎的交叉验证方案。t62 8 用例证明混合引擎
> 在**自身设计点**正确；本矩阵证明它在**每个引擎的既有适用域**不倒退，并给出
> 混合适用域（光+微波强场）的相对误差估计。

---

## 1. 验证思想

混合引擎 = "光场走 Sambe 光子块 + 微波当场"。因此：
- 在**光主导**场景（微波→0）：mixed 应退化 ≡ sambe frozen（光路径同源）
- 在**微波主导**场景（光→0/弱光）：mixed 应退化 ≡ hard（微波当场同源）
- 在**光+微波**混合域：无单一现成锚 → 用全 Sambe（微波进光子块，M=4 级）
  或 reference（小场景可行时）作锚

三个域的锚不同，验证判据统一：末态布居 max|Δpops| ≤ 目标（1e-3 级，
混合适用域可放宽 5e-3）。

## 3. 执行顺序与前置

1. t62 8 用例全绿（前置，证明设计点正确）
2. V1/V2：mixed 光路径 vs frozen——用现有 t62 用例基建（run_case）
3. V3：mixed vs hard @ 微波主导（需要 mixed 支持弱光/无光——确认 setup 处理
   空光场组不崩）
4. V5：3 态混合域锚（M=4 贵但 3 态可行）
5. V4/V6（两体）依赖 t62 两体验收（用例 8 + dim 1452）

## 4. 接受判据

- V1-V3：max|Δpops| ≤ 1e-3
- V5：≤ 5e-3（混合域无同源锚，全 Sambe M=4 与 AC 化的已知差 ~1e-2 级——
  实际以 M=4 收敛序列为准，见 t60 方法论）
- norm 偏差均 ≤1e-5

## 5. 与目标 1（t62）的分工

- t62：混合引擎**自身正确性**（8 用例：AC 化值/阻断物理/π 脉冲/STIRAP 链/
  重构精度/同频多场/两体 V_dd）
- 本矩阵：混合引擎**相对既有引擎的一致性**（三个适用域回归不倒退）+
  混合域误差定量
