# 多体含时后端

多体页的 RunSpec 只携带原子、标定后的逐键 `V/J/A`、逐原子 `Ω/δ/γ`、初态和时间网格。哈密顿量仍在后端装配；三个后端没有为涡旋或某个实验写特例。

## 求解器

- `classical-spin`：每个二能级原子输入一个单位 Bloch 向量（或局部乘积态），积分经典 Poisson/LLG 方程。输出 `spins[t,atom,3]`、`pops_atom`、能量和自旋范数/能量漂移。它是大阵列的平均场近似，计算量随原子数和输入键数线性增长；不产生量子纠缠。
- `tdvp-trajectories`：输入局部 collapse 通道 `{site, rate, operator|matrix}` 和乘积 MPS 初态。Hamiltonian 用两站点 TDVP，跳跃/无跳跃用内部分裂步；输出轨迹平均、Monte-Carlo `stderr`、跳跃数和生存权重。速度约为 `n_trajectories ×` 一次 MPS 演化，误差同时来自键维、内部步长和统计抽样。
- `peps-real-time`：输入矩形二维网格、最近邻局部哈密顿量和乘积态或五阶 PEPS 张量。每个局部门通过真实 PEPS 张量的共享键 SVD 更新，采用 simple-update；输出布居、范数漂移、累计丢弃权和键维。它适合二维局域模型；当前明确拒绝非网格最近邻和长程键，不会静默丢项。

`auto` 仍只在 ED 与 TDVP 间选择，不会把量子问题静默降级成 classical-spin。PXP/blockade 投影目前只允许 ED，因为其它三个后端尚未实现受限局部空间的 MPO/PEPS 编译器。

## 交叉验证

`checks/manybody_timeevolution_crosscheck.py` 独立验证：一站点横场的经典 Bloch 解析解、1×2 XY PEPS 与四维稠密矩阵指数、局部振幅衰减轨迹与 `exp(-γt)`。现有 `manybody_mps_selfcheck.py` 继续用 ED 对拍 TEBD/TDVP 的布居和范数。

PEPS 和轨迹结果必须查看 `error_report`：`discarded_weight`/`norm_drift`、`max_step_ns`、`stderr` 是结果的一部分；只给一个键维或一条轨迹不能当作精确解。
