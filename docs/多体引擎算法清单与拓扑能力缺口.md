# EL 多体引擎算法清单与拓扑能力缺口

这份清单按 `src/core/manybody` 当前实现整理。`rydberg_fci.py` 是论文模型适配器，单列为隔离项，
不计入通用引擎能力。

| 层 | 当前能力 | 入口/模块 | 适用边界 |
|---|---|---|---|
| 物理标定 | ARC 单原子基、球基 `V_dd`、一阶复 `V/J/A`、二阶 Löwdin/downfolding、guard 报告 | `assemble.calibrate`, `calibrate_pair` | 逐对 4 维局部空间；二阶近简并需看 guard |
| Hamiltonian | 稀疏/稠密 2^N 装配、复交换/双激发、驱动/失谐/损耗 | `build_H_sparse`, `build_H_ed` | ED 维数指数增长 |
| 约束 | blockade/PXP 等投影、稀疏计划编译 | `hamiltonian_plan` | 当前投影主要由 ED 执行 |
| 含时 ED | 稠密 `eigh` 全时刻传播、稀疏 Krylov `expm_multiply`、分段驱动、激发数扇区 | `engine_ed` | `2^N`；全联合布居有物化闸 |
| 平衡态 ED/Lanczos | 精确小维对角化、稀疏 `eigsh`、虚时幂法、基态/能隙 | `equilibrium`, `eq_route` | 仅厄米基态路径 |
| GPU ED | CuPy/torch 批量本征、显存分块 | `equilibrium.batched_ground_state` | 批量稠密矩阵 |
| 矩阵自由 | 线性算子、Torch Lanczos | `matrix_free` | 需要可作用 Hamiltonian |
| KPM | Chebyshev moments、Jackson kernel、DOS、有限温 | `kpm` | 统计谱量；不替代简并基态 Chern |
| DMRG | TeNPy ladder/cluster/任意点云 autoMPO 路线 | `dmrg`, `eq_route` | 长程键/切割宽度决定代价 |
| MPS | TEBD、TDVP、单站点/自适应、Torch/GPU 变体 | `engine_mps`, `engine_mps_gpu`, `mps_torch` | 需要可排序链；二维点云是近似映射 |
| PEPS | 小型实时 PEPS 张量更新/收缩 | `engine_peps` | 当前是实验性有限尺寸后端 |
| 轨迹 | MCWF/量子轨迹、collapse operators | `engine_trajectories` | 开放系统近似取样 |
| 经典近似 | Landau-Lifshitz/经典自旋动力学 | `classical_spin` | 非量子拓扑序证据 |
| QMC | SSE/符号检查 | `qmc` | 非随机符号问题；复 hopping 通常不能直接用 |
| 自由费米子 | 适用性检查、单粒子填充基态 | `free_fermion` | 仅满足自由费米子结构 |
| 对称性 | 反射能力判断、投影/降维 | `symmetry` | 目前不是完整空间群工具 |
| 观测量 | 布居、关联、纠缠熵、自旋、链接相位/闭环卷绕 | `observables` | 还没有拓扑序专用结果契约 |
| 拓扑原语 | Peierls 扭转、Abelian/非 Abelian Wilson loop、flux 谱流、纠缠谱、统一诊断契约 | `topology` | 扭转如何进入 Hamiltonian 仍由模型层提供 |

## 已完成的本轮通用改进

`src/__init__.py` 现在会在仓内 `.arcdata/` 存在时自动设置 ARC 的 `AlkaliAtom.dataFolder`，
所以 ARC 的 SQLite literatureDME 初始化不会再默认写入用户目录；缺少仓内数据时仍回退 ARC 默认路径。

`assemble.decompose_pair_channels` 公开一阶 4×4 块的球基 `q,q'` 通道，按
`(1/R^3) T_{q q'} d_{1,q}⊗d_{2,q'}` 返回每个通道和重构总和；回归检查已验证重构误差约
`4.2×10^-22`。二阶 downfolding 没有被错误拆成单通道。

`manybody.topology` 现在提供：

- `twist_pairs` / `twist_calibration`：按显式跨胞元 winding 或位置/周期推断给复 hopping 加 `θ_x,θ_y`，可直接回接 `build_H_sparse`；
- `wilson_loop`：单态和简并子空间的极分解 Wilson 矩阵及本征相位；
- `spectral_flow`：沿通量路径用能量排序或相邻态重叠追踪能级分支；
- `entanglement_spectrum`：纯态 Schmidt 权重、纠缠能和熵；
- `topology_result` / `topology_report`：统一 schema、状态、证据、警告和失败原因。

`twist_pairs` 不猜测周期 Hamiltonian 的物理结构：如果点云没有胞元内坐标、周期和明确的
跨边界 winding，调用方必须先在模型层补齐这些元数据。对于 `A` 双激发项，因其可能破坏
U(1) 粒子数，工具不会静默施加 hopping 扭转。

## 仍需补的通用拓扑能力

1. **边界/模型接缝**：把 `ManyBodyModel` 的周期胞元、最小像和跨边界 winding 接入标定与
   Hamiltonian 计划，避免实验脚本手工注入周期元数据。
2. **多体 Berry 扫描**：把 `fukui_chern` 接到统一的扭转 Hamiltonian builder，并报告网格收敛、
   最小 gap、规范重叠和失败原因。
3. **flux insertion 层**：把 `spectral_flow` 接入基态求解器，增加基态置换、泵浦量和简并
   子空间的闭环比较。
4. **拓扑序观测层**：拓扑纠缠熵、局域 Chern marker、手性/自旋手性、粒子泵浦和边界态。
5. **结果契约**：明确区分“未计算”“有限尺寸迹象”“收敛失败”和“诊断通过”；禁止把单粒子
   Chern 数或单个闭环相位自动标成多体拓扑序。

## 暂不应加入的内容

固定蜂巢晶格、论文参数、特定 ramp、Fukui 网格和某篇文章的几何构造继续留在模型适配器或仓外
实验目录。通用层只接受几何、局部态、链接和边界元数据。
