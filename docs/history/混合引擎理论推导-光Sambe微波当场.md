## 0. 结论摘要

1. **"当光子 vs 当场"不是物理之分，是频率尺度的计算选择**：载波周期远小于
   演化窗/步长能力 → Floquet 化（当光子）；可解析 → 当场积。两者数学等价
   （hard ≡ reference 1.93e-9；微波光子块 ≡ 当场）。
2. **混合的正确架构 = φ-帧（D=K0 全对角）+ 远失谐强对 AC 化 + 微波当场**——
   单 DOP853 一次贯穿，无 Strang 无 eigh，RHS 全慢（无 THz）。
3. **之前五连败（t40-t44）逐条归因 = 从没有一次是"正确组合"**——不是路线错，
   是每次都缺一环。
4. **独特优势**：φ-帧无参考选择 → STIRAP 链天然正确（hard 的 rot_pick 链式
   是已知盲区）；微波不进光子块 → 两体 dim 1452 vs 全 Sambe 7260（5 倍降维）。

## 1. 问题设定

基组 {|i⟩}，能量 E_i。场：
- 光场 f：ω_f（THz 级），Rabi 矩阵 A_f（全偶极对），包络 env_f(t)
- 微波 m：ω_m（GHz 级），Rabi A_m，包络 env_m(t)

实验室系哈密顿：
H(t) = H_atom + Σ_f env_f(t)·cos(ω_f t)·A_f + Σ_m env_m(t)·cos(ω_m t)·A_m

## 2. 为什么频率尺度决定"当光子 or 当场"

- 光场 295.7THz：周期 3.4fs；620ns 窗 = 1.8e8 周期。DOP853 步长需 << 周期 →
  ~1e9 步不可行 → **必须 Floquet 化**（cos(ωt) 展开成光子数 n，载波变静态
  对角 −n·ω）。
- 微波 17GHz：周期 0.058ns；DOP853 自适应 ~0.005-0.01ns 可解析 → **当场积**。
- 不是物理本质之分——是"载波周期 vs 演化窗/数值步长能力"的工程选择。

## 3. φ-帧方程推导（核心）

光场已进光子块：扩展态 X，K0 = diag(E_i − n·ω_f)（THz 级，静态）。
扩展空间方程：
  dX/dt = −iC·[K0 + Kc(t) + M(t)]·X
  Kc(t) = Σ_f env_f(t)·Kc_f（光场耦合，光子数 ±1，值 A_f/2）
  M(t) = Σ_m env_m(t)·cos(ω_m t)·(I_P⊗A_m)（微波，块内同 n）

定义 φ = e^{iC·D·t}·X。**关键：D = K0（全对角，不只去 E）**：
  dφ/dt = iC·D·φ + e^{iCDt}·(−iC)(K0+Kc+M)e^{−iCDt}·φ
        = −iC·[e^{iCK0t}(K0+Kc+M)e^{−iCK0t} − K0]·φ
        = −iC·[Kc∘e^{iC·ΔK0·t} + M∘e^{iC·ΔK0·t}]·φ    （K0−D=0 自动消对角）

**对角全消，只剩耦合项带 e^{iC·ΔK0·t} 相位。** 逐项分析：

| 耦合项 | 连的扩展态 | ΔK0 | 频率 | 处理 |
|---|---|---|---|---|
| 光场近共振对 | \|i,n⟩↔\|j,n+1⟩ | E_i−E_j+ω_f ≈ 失谐 | MHz 慢 | DOP853 ✓ |
| 光场反旋对 | 反向 | ≈ −2ω_f | THz | M=1 截断丢弃（1e-14）|
| 光场远失谐强对 | \|i,n⟩↔\|j,n±1⟩ | ≈ ±295.7THz | THz | **AC 化** |
| 微波共振对 | \|i,n⟩↔\|j,n⟩ | E_i−E_j ≈ −ω_m | cos 拍频 → 慢 | DOP853 ✓ |
| 微波反旋对 | 同 n | ≈ +ω_m | 2ω_m=34GHz | DOP853 ✓ |

**微波关键**：连同 n（微波不驱动光场载波）→ ΔK0 = E_i−E_j 与光子块无关 →
cos(ω_m t)·e^{iC(E_i−E_j)t} 共振对拍频慢——E-IP 由 φ-帧**自动给出**，无需手工。

## 4. 远失谐强对的 AC 化（为什么必须 + 怎么注入）

φ-帧里光场远失谐强对（60S↔60P @ 295.7THz，ΔK0≈±295.7THz）是 THz 快项——
DOP853 钉死、过滤丢 AC 位移。物理上它不转移布居，净效应 = AC 位移
（far_sos 双向公式，±18MHz 级，与 M=4 eigh 一致——t60 仲裁 C1≈锚 6.87e-3）。

**注入位置（理论关键）**：far_sos 位移加进**物理能级 E_i** → K0 对角变
E_i+δE_i−nω。φ-帧 D 同步更新 → 方程形式不变，但：
- 光场近对失谐变了（δE 影响失谐）
- 微波对能级差变了（δE_i−δE_j 影响共振）——**这就是"光频移阻断微波"的物理**，
  由 AC 化自动产生，不是额外处理。

## 5. 完整算法（理论版）

```
1. 分类（物理驱动）：
   每光场每偶极对 (i,j)：
     Δ = |E_i−E_j| − ω_f；r = A_f[i,j]/ω_f
     - 近共振慢对（|Δ| 小）→ 保留（φ-帧带失谐慢相位）
     - 反旋对（|Δ|≈2ω_f）→ 丢弃（1e-14）
     - 远失谐强对（r 大，|Δ| 大）→ AC 化：剔除 + far_sos 位移注入 E_i/E_j
2. E_i ← E_i + δE_i
3. 单 DOP853 一次贯穿：
   dφ/dt = −iC·[ Σ近对 env_f(t)·Kc_f∘e^{iC·失谐·t}
                + Σ微波 env_m(t)·cos(ω_m t)·A_m∘e^{iC(E_i−E_j)t} ]·φ
   （RHS 全慢：失谐 MHz + 微波 GHz + 34GHz 反旋 → 无 THz 钉死）
4. 输出重构：ψ(t) = e^{−iC·K0·t}·φ(t)（THz 相位输出时刻精确乘）
```

| 版本 | 缺什么 | 理论错误 |

## 7. 相对两个现有引擎的独特价值

- **vs hard**：φ-帧无参考选择 → STIRAP 链（5S↔6P↔60S 两光场）天然正确
  （hard 的 rot_pick 链式是 t34 已知盲区：5S+ω1/6P+ω2 → 光1 对 THz 残差）。
- **vs 全 Sambe**：微波不进光子块 → 两体 P=3（光）→ dim 1452 vs 7260（5 倍降维）。
