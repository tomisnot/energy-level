## 二、物理模型

### 2.1 路径 A：丢失型耗散 = 条件（no-jump）非厄米演化

对"从态 `|g⟩` 以速率 Γ 离开建模空间"的通道，引擎在哈密顿对角上加 `−iΓ/2`：

$$H_{\text{eff}} = H(t) - \tfrac{i}{2}\sum_g \Gamma_g\,|g\rangle\langle g|,
\qquad |\psi(t)\rangle = e^{-iH_{\text{eff}}t}|\psi(0)\rangle$$

- 布居：`p_g(t) ∝ e^{−Γt}`；**相干**（g 与稳定态的 off-diagonal）`∝ e^{−Γt/2}`——与主方程一致；
- 范数不再守恒：`⟨ψ|ψ⟩ = 存活概率`，漏出的部分按
  `loss(t) = ∫₀ᵗ Σ_g Γ_g p_g(τ) dτ` **事后记账**（见 §五）；
- **成立条件（三条，缺一不可）**：① 落点**在建模空间之外**（"丢失"）；② 没有从落点回来的回流；
  ③ Γ 不随时间变。此时 `ρ_modeled = p_surv·|ψ_cond⟩⟨ψ_cond|`，路径 A 的 `|ψ_cond⟩` 就是主方程
  在建模空间上的解——`tensor._pair_loss_vectors` 的 docstring 把它写成"**严格 L=√Γ|loss⟩⟨from|
  主方程在建模空间的解**"，这是该设计的权威表述。
- 通道类型限制的由来：显式落点会在空间内**回流并重建相干**、纯退相不改布居只磨相干，
  两者都不能用"一个衰减的波函数"表达，所以路径 A **显式拒绝**（不是近似，是表达力不足）。

### 2.2 路径 B/C：完整 Lindblad 主方程

```python
# src/core/evolve_reference.py:91-102（路径 B，实验室系 + H0 相互作用绘景）
d = -1j * C * (H @ rho - rho @ H)
for L in Ls:
    LdL = L.conj().T @ L
    d += L @ rho @ L.conj().T - 0.5 * (LdL @ rho + rho @ LdL)
```
- 跳变算符 `L = √Γ |to⟩⟨from|`（`evolve_util._decay_ops:229-252`，`Γ` MHz）；
- `to=None` → 汇入**虚拟 loss 态**（下标 `N`，`N_eff = N+1`）：`H` 不耦合它、trace 守恒、
  布居只进不出 ⇒ `loss = ρ[N,N]`（**精确**，不含数值积分误差）；`to` 在基组内 → 真实的
  内空间转移（回流/相干重建都被正确描述）；`from == to` → `|g⟩⟨g|` 型测量算符 = **纯退相**
  （相干按 `e^{−Γt/2}` 衰减、布居不变，D8 对它做了§解析）;
- 数值：路径 B 用 `scipy BDF`（ρ 是 `N_eff²` 维复向量，含耗散后可能刚性；`Radau` 不支持复数）；
- 路径 C（`evolve_rwa`）是同一方程的**旋转系**实现：`lindblad_eig`（常数 H ⇒ Liouvillian
  本征分解，机器精度、成本与时长无关，`N_eff ≤ 48` 否则回落）与 `lindblad`（numba 矩阵 RK4，
  步长 `h = 最快非 RWA 载波周期 / frac`，默认 `frac=20`；S 预计算到 dt/2 子网格）。

### 2.3 单位约定（**最容易写错的地方**）

| 量 | 约定 | 说明 |
|---|---|---|
| Γ | **MHz** | `decay(g, gamma_mhz, e)` 与 `auto_decays` 的产出 |
| 时间 | ns | 全库统一 |
| 哈密顿 | `×_CONV = 2π×10⁻³` | MHz → rad/ns |
| **跳变算符** | `L = √(Γ×10⁻³)` | **不乘 2π**（`evolve_util` 模块头与 `decay()` docstring 都点名这条） |
| 耗散率 | `Γ_ns = Γ_MHz × 10⁻³` /ns | 布居衰减率；幅衰率 = `Γ_ns/2` |

引擎内部的换算链（**全部等价**，只是写法不同）：

| 引擎 | 传入内核的形式 | 内核里怎么用 | 等价于 |
|---|---|---|---|
| `mixed` 单/两体 | `gamma = Γ_ns / _CONV`（MHz，按扇区 `np.tile` 复制） | `res[k] -= 0.5*Cv*gamma[k]*phi[k]`（`coupling.py:268-272`） | `−Γ_ns/2` |
| `hard` 单/两体 | `gamma = Γ_ns / _CONV` | RHS 对角 `−(C·Γ)/2` | 同上 |
| `evolve_twofield.evolve_hard`（GUI hard 单原子） | 直接传 `Γ_ns` | `out -= 0.5*Gamma_ns*y` | 同上 |
| `sambe` 两体 | `gamma_pair = (Γ_A+Γ_B)/_CONV` | 扩展空间对角 `−iΓ/2`（`_SambeSetup(gamma=…)`） | 同上 |
| `sambe` 单原子 | — | **不在这里**：遇 `decays` 直接转路径 B（`sambe.py:822-829`） | 主方程 |

## 三、通道（通道从哪来，怎么配）

### 3.1 数据模型：`decay(g, Γ, e)`

`src/core/evolve_util.py:171-180`——`{'from': g, 'to': e, 'gamma_mhz': Γ}`：

| 写法 | 物理 | 路径 A | 路径 B/C |
|---|---|---|---|
| `decay(i, Γ)` / `to=None` | 自发辐射/寿命 → **丢失** | ✅ | ✅（虚拟汇） |
| `decay(i, Γ, j)`（j 在基组） | 落到基组内某态 | ❌ `NotImplementedError` | ✅ |
| `decay(i, Γ, i)`（`from==to`） | **纯退相** | ❌ `NotImplementedError` | ✅ |

### 3.2 自动档：`auto_decays`（ARC 权威寿命）

`src/core/evolve_util.py:183-207`：
- 逐态查 ARC `cache.atom.getStateLifetime(n, l, j, temperature)`——由**偶极矩阵元对全部下能级求和**
  得到的权威寿命，比逐通道算 A 系数更省事；
- 过滤：`τ ≤ tau_max_s = 1e-4 s`（只留 5P/6S/6P/4D 等低激发态；里德堡 ~0.1 ms+ 被排除），
  并要求 `Γ = 1e-6/τ [MHz] ≥ 1e-6`；
- 每个 **(n,l,j) 的每个子能级各一条通道**（自发辐射率与 F/mJ 无关）；
- `temperature=0.0` 默认 = **纯自发辐射，不含黑体**（参数存在，但 GUI/MCP **未接线**，见 §七）；
- 落点恒为 `None`（丢失）。D10 锚：6P₃/₂（τ=118 ns）→ 4 条通道、Γ=1/τ(ARC)；60S（τ~230 µs）排除。

### 3.3 GUI / AI 面

- GUI：动态页「自发辐射」三档 `自动（ARC 寿命）/ 禁用 / 自定义`（`ui_dynamic.py:262-268`）；
  自定义表 = 从态下拉 + Γ (MHz) + 落点下拉（末项「（丢失）」→ `to=None`）；
  同态同落点会弹提示"这是纯退相通道（不转移布居，只衰减相干）"（`:609-612`）；
- 通道按 **label** 存，运行前解析成索引；`from` 已不在基组 → 跳过并在状态栏说明（`:629-643`）；
- `auto_decays` 必须在**主线程**算（ARC 的 SQLite 连接不能跨线程）——注释里记着一次
  "提前调用导致 Qt 原生堆损坏"的事故（`:862-866`），所以只有真正运行时才算一次；
- **AI 面已入册**：`dynamic.decay_index`（0/1/2，`pm_setup.py:190-191`）与 `dynamic.decays`
  （通道列表，`pm_setup.py:276-283`）⇒ AI 可以自己开耗散档、写通道（于是"纯耗散演化"这类
  实验 AI 也能发起，见 §八对 SKILL 坑 22 的更正）；
- 两体：A/B **共用同一份** `states`，`auto` 档给两侧各生成一份相同通道表；自定义档
  **只允许落点=丢失**，否则直接 `NotImplementedError`（`ui_dynamic.py:1352-1367`）。

### 3.4 两体的张量化

`tensor._pair_loss_vectors:145-183`：把单原子通道提升到 N² 基——
A 侧 `from=i` ⇒ 两体态 `|i⊗j⟩`（∀j）按 Γ 耗散；B 侧 `from=j` ⇒ `|i⊗j⟩`（∀i）。
返回 `(GammaA, GammaB)` 两条长度 N² 的速率向量，**分别累计 lossA / lossB**。
即：**两体耗散 = 两个原子各自独立的自发辐射，没有集体（Dicke 超辐射）项**（见 §七）。

1. **同一份通道配置，走 `sambe` 单原子会换掉引擎**（后端变成 `reference-bdf`，日志有

4. 混合/两体的 loss 是**逐点梯形积分**，与积分器容差无关（§五）。

## 五、精度与记账（本次实测）

### 5.1 等价性锚（路径 A ≡ 路径 B）

合成两能级（`|g⟩`, `|e⟩` 差 1000 MHz，无场），初态 `(|g⟩+|e⟩)/√2`，`decay(e, Γ=15 MHz)`：

| 比较项 | 结果 |
|---|---|
| 布居 `pops`（混合 vs 参考） | `max|Δ| = 2.2e-9` |
| 相干 `|ψ_g ψ_e*|`（A）vs `ρ_ge`（B） | `Δ = 6.1e-11` |

⇒ 对"丢失"型通道，**非厄米波函数路径与主方程在建模空间内数值等价**（差异只来自积分器容差）。

### 5.2 loss 的精度来源不同（**读 norm_dev 时别误判**）

同一算例，改变**输出点数**（`npts`）：

| 路径 | npts (dt) | 布居误差 | `loss` 误差 | 报出的 `max_norm_dev` |
|---|---|---|---|---|
| `mixed`（非厄米） | 11（10 ns） | 4.5e-10 | **1.46e-3** | 1.46e-3 |
| `mixed`（非厄米） | 101（1 ns） | 5.9e-10 | **1.46e-5** | 1.46e-5 |
| `reference`（主方程） | 11（10 ns） | 4.0e-9 | **4.0e-9** | — |

- 非厄米路径的**布居是精确的**（积分器容差级），但 `loss` 是 `∫Σ Γ p dt` 的**梯形积分**，
  误差 ∝ `(Γ_ns·dt)²/12`（实测 dt 缩小 10 倍 → loss 误差缩小 100 倍，正是二阶）；
- 于是 `norm_dev = max|Σpops + loss − 1|` 在非厄米路径里**主要就是梯形误差**：
  `hard`/`mixed` 那条 `>1e-6 就告警` 的日志（`hard.py:159, 578`、`evolve_twofield.py:822`）
  在"Γ 大 + npts 少"时会**报出并没有物理问题的 l.e-3 级偏差**；
- 主方程路径的 loss 取自汇态对角元，**没有这层误差**（4e-9）。
- **实用判据**：要 `norm_dev ≲ 1e-4`，需 `Γ_ns·dt ≲ 0.03`，即 `npts ≳ Γ[MHz]·T[ns]/30`；
  否则请把 `norm_dev` 读作"loss 曲线的数值积分误差"，或直接改用 `sambe` 单原子档（走主方程）
  取精确 loss。

## 六、结果里怎么看耗散

- 返回契约：单原子 `loss`（n_t,）、两体 `loss_A` / `loss_B`；UI 在布居曲线上叠一条 **loss 虚线**；
- `error_report['max_norm_dev']` 与诊断摘要 `solver.norm_dev` 是同一口径的偏差（§5.2 有读法）；
- 含耗散时 **`Σpops + loss = 1`**（而不是 `Σpops = 1`）；无耗散时才断言 `Σpops = 1`；
- 未建模的"落点"一律 = 丢失（布居离开建模空间）——**不是**从结果里消失，而是进了 `loss`。

| **集体衰变 / 超辐射（Dicke）** | 两体耗散是"两个原子各自独立"（`_pair_loss_vectors` 只需单原子 Γ 向量）⇒ 恒为独立衰变率之和，无集体增强 |
| **非马尔可夫记忆 / 结构化浴** | 只有马尔可夫 Lindblad（跳变算符常数），无记忆核 |
| **激光线宽 / 相位噪声** | 无环境退相干源；只能手工加"纯退相通道"（且仅路径 B/C 支持） |
| **两体的显式落点 / 纯退相** | v1 明确不支持（`NotImplementedError`，提示先用单原子引擎）；两体只有"丢失" |
| **光子的动量反冲 / 运动自由度** | 完全不建模（无外部自由度） |
| **辐射压/加热导致的逃逸** | 无（里德堡黑体电离也不含） |
| **静态散射损失**（§一 路径 D） | `real_field` 算出 `scatter[N]`（`Ω²Γ_up/4Δ²`）并放进 field dict，**`src/` 内无消费者**；唯一消费者是 checks 侧的 `checks/pair_evolve.py:_scatter_loss_curve`（report-only）。⚠ 且该公式在里德堡寻址几何下**取反**（见《场致加热与损失-调查与建模方案》§3） |

## 八、可达性陷阱（用之前要知道的三件事）

1. **GUI 上只有"单原子 + sambe"能跑显式落点/纯退相**：`hard`/`mixed` 会在引擎里抛
   `NotImplementedError('hard 耗散仅支持落点=丢失…请用单原子 lindblad 引擎')`
   （`evolve_util.py:269-272`），但 **GUI 的方法下拉里没有 "lindblad" 这一档**
   （只有 `sambe/hard/mixed`）——报错信息把用户指向一个界面上不存在的档位。
   实际可用组合：**单原子 + sambe + 自定义通道（显式落点 / from==to）**。
   *建议*：把报错改成"请改用 sambe 档（其含耗散时走 Lindblad 主方程）或脚本
   `evolve_rwa.evolve(method='lindblad')`"，或者让 hard/mixed 在检测到显式落点时自动转参考路径。
2. **无波形 ≠ 不能跑**：只要**有耗散通道**（自定义非空，或 auto 档且基组含 n ≤ 15 的低激发态），
   GUI 允许"零波形 + 纯耗散"演化（`ui_dynamic.py:855-873`）——这正是自发辐射/纯退相实验。
   ⇒ `skills/energy-level/SKILL.md` 坑 22 的表述（"零波形 = 跑不了，静止类验收必须加窗外脉冲"）
   应更正为"**既无波形、也无耗散通道时**才拒绝；AI 可用 `dynamic.decay_index=2` +
   `dynamic.decays=[…]` 直接跑纯耗散"。D1/D8 自检就是这么跑的。
3. **同一物理、两条数学**：给同一份通道选 `mixed` 与 `sambe`（单原子），
   布居一致（§5.1）但 **loss 的精度不同**（§5.2）、后端与耗时不同（`mixed-phi-dop853` vs
   `reference-bdf`）。要"精确 loss"就用 `sambe` 单原子档。
