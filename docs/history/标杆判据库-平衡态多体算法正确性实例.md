# 标杆判据库：平衡态多体算法正确性实例（教科书级·易实现·难写错）

> **目的**：我们将为多体引擎新增**平衡态**求解算法族（张量网络 TN / 神经网络波函数 NQS·VMC / 对称性约化 ED·Selected-CI / QMC），
> 并**按问题特征路由**到不同算法（1D、2D 都接受）。**每个算法上线前，必须用"独立、教科书级、不易写错"的标杆实例判定正确性**。
> **本文 = 标杆实例规格（spec），不改代码**；供实现会话照此写 `checks/equibench_*_selfcheck.py`。
>
> **对接现有框架**：数值断言用 `checklib.Checker.close(name, ours, ref, rtol, atol)`（打印 `ours=… ref=…`）与
> `group(name, subs)`；判据分档注册 `run_checks.py` 的 `FAST_KNOWN_SEC`；重实例（大 N TN/NQS、2D）标 `SKIP` 或归 `--slow`，勿拖内循环。
> 现成先例：`checks/manybody_m1_ed_selfcheck.py`（已覆盖含时 + 装配：N=1 拉比、N=2 blockade 独立构造、扇区≡全空间、张量积、非厄米衰减）。
> **本文专补"平衡态"这块空白。**

## 0. 三条设计原则（决定"标杆可信"）

1. **独立性铁律**：参考值来源**绝不能与被测算法共享代码路径**，否则同源 bug → 判据假绿（本仓反复强调"给错答案 vs 静默无效"）。
   三类**互相独立**的参考源：
   - **(A) 解析闭式**——不依赖任何数值法，连我们的 H 装配都能反证；
   - **(B) 独立暴力 ED**——小 N 用**朴素 numpy 显式 Kronecker 构造 H → `eigh`**，独立于 TN/NQS/QMC/我们引擎；
   - **(C) 文献金标准**——第三方已发表值。
2. **交叉一致律**：因为我们将同时有 ≥2 个平衡态算法，要求**同一实例上 各算法两两之差 < 容差**（TN↔ED↔NQS↔QMC）；
   单方法只锚自身会漏系统误差，**交叉 + 锚到 (A)/(B)/(C)** 才既能抓算法 bug 又能抓装配 bug。
3. **确定性**：NQS/QMC 是随机的——判据里**必须固定种子**并**自证采样数/收敛**（否则红绿抖动=无意义判据；呼应本仓"读不到与没命中长得一样"纪律）。

## 1. Tier-A：解析闭式（跨切·先抓 H 装配与热力学骨架）

| 编号 | 实例 | 可核查的闭式量 | 数值锚（已核实） | 主要测 |
|---|---|---|---|---|
| **A1** | **横场 Ising 链**（TFIM，开/周期） | Jordan-Wigner/Bogoliubov **自由费米子精确谱**：E₀、能隙、⟨σˣ⟩、关联函数 | 有限 N **精确到机器精度**（闭式 vs ED）；临界 h=J；临界**中心荷 c=1/2**（纠缠标度） | 装配 · TN(1D) · ED · NQS · 纠缠估计器 |
| **A2** | **XX / Heisenberg 链** | XX=自由费米子闭式；XXX 有 Bethe 精确 | 临界 **c=1**；XX 关联 ~ (−1)^r/√r | 对称性(SU(2)/U(1)) · 纠缠 · TN |
| **A3** | **2D 经典 Ising（方格）** | **Onsager 精确自由能**（闭式）；自发磁化 M(β) 闭式 | 临界耦合 **K_c=½ln(1+√2)≈0.4406868** | 有限温 · 转移矩阵 · **QMC 骨架**（QMC 在此有精确对照） |
| **A4** | **顺磁 Curie 律**（无相互作用自旋 ½） | χ=(gμ_B)²/(k_BT)，M=½ tanh(gμ_BB/k_BT) | 平凡闭式 | 有限温最基础健全性 · ⟨O⟩_β |
| **A5** | **硬核**六角**晶格气体（Baxter 严格解）** | 配分函数/序参量 R/密度 闭式（模函数） | **z_c=(11+5√5)/2≈11.0902**、**ρ_c=(5−√5)/10≈0.2764**、最大密度 1/3、关联黄金比 | **里德堡三角晶格·深阻塞·经典极限**（见 D3） · QMC/转移矩阵 |
| **A6** | **Haldane 链**（自旋 1 AF 链） | 非自由、可积外；gapped | **Δ≈0.4105 J** | **TN 对 gapped 模型收敛性**（键维有限即收敛） |
| **A7** | **toric code（雷德堡 kagome 可实现，Verresen）** | 拓扑 | **拓扑纠缠熵 γ=ln 2** | 2D 拓扑 · 多体纠缠/REP · 序参量 |

> 注：A3 经典映射——**量子 d 维 = 经典 d+1 维**，2D 经典 Ising 可经转移矩阵/路径积分对照量子链；QMC 在 stoquastic 情形**本就该复现** A3/A5，故 A3/A5 是 **QMC 路由的准入门禁**。

## 2. Tier-B：独立暴力 ED 生成器（**覆盖我们"任意广义 H"**——最关键）

这是"保留哈密顿广泛性"的核心抓手：**解析/文献锚多是标准模型；我们独有的 J/A/各向异性/mJ 结构，用闭式覆盖不了 → 用 tiny-N 暴力 ED 造参考**。

- **B1 配方（对任意实例）**：N ≤ 10–12，用**朴素 numpy 显式 Kronecker 逐项搭 H**（与引擎的稀疏/扇区装配**不同实现**）→ `eigh` → E₀、能隙 Δ、⟨n⟩、⟨σˣ⟩、纠缠熵 S、结构因子 → 作 `close(ref)`。
  （复用 A1b 的"独立构造 3 能级块"精神，推广到多体全空间。）
- **B2 三方一致律**：同一 H、同一观测，**引擎 ED ≡ 暴力 ED ≡ TN ≡ NQS ≡(若 stoquastic)QMC**，两两 < tol → 任一越界定位到具体方法。
- **B3 对称性约化 ≡ 全空间**：守恒量子数（总激发数/粒子-空穴/平移动量）分块结果 = 全空间 ED（现 A2 已有先例，扩展到动量扇区）。
- **B4 无耦合极限**：关相互作用 ⇒ 积 = 各单体之积（现 A4 已有）。

> **实现要点**：B 类把"我们的 H 约定（V/J/A 符号、(θ,φ) 复相位、CONV、降 downfolding）"钉死；**任何平衡态算法接入前先过 B**（否则错的是"我们对 H 的理解"，不是算法）。

## 4. Tier-D：里德堡专属实例（把标杆落到"我们的 H 项"上）

逐个**泛化项**配一个"难写错"的锚，保证广泛性每一项都被钉：

- **D1 二体 blockade/Förster**：2 原子 {|gg⟩,|S⟩,|rr⟩} 3 能级块解析（现 A1b）；Förster 失谐 → 解析本征。测 V_dd/A 装配。
- **D2 PXP（大 V 约束）链**：阻塞约束实现 → **合法独立集计数 = Fibonacci 数**（闭式！子空间维数直接对）；Z₂ 序、纠缠谱、scar 塔（文献）。测**约束/子空间**实现。
- **D3 深阻塞→经典晶格气体**：Ω→0、扫 δ/Ω，基态映射到**经典硬核模型**——三角晶格 → **A5 硬六角（Baxter 精确 z_c/ρ_c）**；方格 → 硬平方（**无严格解**，只用高精度级数/转移矩阵对照，勿当闭式）。测 QMC/经典极限/有限温。
- **D4 XY/各向异性偶极（连库内 `ExperimentalRydbergSimulator_DipolarXY_Chen2023`）**：取一个"角向依赖可解析或小-N 可暴力核"的构型（如共线/θ=0 退化），验证**各向异性 T_qq' 装配**。
- **D5 交换 J（flip-flop，σ⁺σ⁻）扇区**：粒子数守恒 ⇒ k 激发子空间维数 = **C(N,k)（闭式）**；二体 J 的 |gr⟩↔|rg⟩ 2×2 解析本征（含复相位）。测 J 项与复相位处理。
- **D6 有限温**：无耦合极限 → **A4 Curie**；stoquastic → **A3/A5** 对照；⟨n⟩_β、χ_T 对闭式。

## 5. 路由决策矩阵 + **每条路由的准入门禁标杆**

> 用户输入问题特征 → 选算法 → **该算法必须先在下列标杆上通过，才允许被路由选中**。

| 问题特征 | 路由到 | 上线前必过 |
|---|---|---|
| 1D / 准1D（链、梯）· 任意 H · 纯基态 | **虚时 TDVP / iTEBD / DMRG** | A1,A2,A6 + B1/B2（同实例 vs ED）|
| 1D · 有限温 | **热化 TDVP / METTS** | A4 + D6 + B2 |
| 2D · **stoquastic**（Ising 子集）· 基态/热 | **SSE-QMC** | A3,A5 + C4（vs Merali）+ B2 |
| 2D · **通用/阻挫/复** H · 基态 | **NQS/VMC**（Transformer/RNN）+ 可选 PEPS/TNR | C1,C2 + D4,D5 + B1/B2 |
| 任意 · 中小 N · 需**精确参照** | **对称性约化 ED + Lanczos/Davidson + Selected-CI** | B1,B3 + A1 |
| 深阻塞 · 经典/热 | 经典硬核极限 / 转移矩阵 | A5(D3) + C4 |

## 6. 落地约定（给实现会话）
- **命名**：`checks/equibench_<tier>_<name>_selfcheck.py`（如 `equibench_a3_ising_exact`、`equibench_c1_heisenberg2d`）。
- **断言**：数值走 `C.close(name, ours, ref, rtol, atol)`；一组子条件走 `C.group(...)`；**每个 ref 注明出处**（闭式公式 / 暴力 ED 脚本 / 文献 DOI），便于日后复核。
- **容差策略**：能量按 |E₀| 标度取 rtol（如 1e-8 闭式、1e-5~1e-4 ED/TN、NQS/QMC 给统计带并**固定种子**）；序参量/纠缠各自定带；**文献带容差**（如 C1 m_s=0.30±0.01）。
- **分档**：秒级（A4/D1/D5/B 小 N）进 `--core`；A1–A6/C1–C3/D2–D3 进 `--fast`；大 N TN/NQS/2D → `--slow` 或 `SKIP`（登记 `FAST_KNOWN_SEC` 现测耗时）。
- **确定性 + 自证**：随机方法固定种子、记录采样数；"没跑到"必须报 SKIP 而非误判 PASS（沿用 `checklib` 精神）。
- **独立性纪律**：ref 走独立闭式/独立暴力构造/文献，**绝不复用被测的装配函数**——这是整套判据有意义的前提。

## 9. 施工优先级（剩余）

- **P3**：A5/D3 硬六角·深阻塞·经典极限、C4 vs Merali 曲线、A6/A7 → 覆盖更广 regime 时。
