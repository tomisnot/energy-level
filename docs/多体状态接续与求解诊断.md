# 多体状态接续与求解诊断

本接口服务于任意有限二能级图模型。晶格生成、论文中的场纹理、实验协议和物理解释由模型或研究脚本提供。

## 固定激发数与基态

产品配置使用 `manybody.charge_sector=k`。ED、CPU Lanczos 和 CUDA Krylov 在守恒模型中直接生成 C(N,k) 个位编码，不先构造全空间 Hamiltonian 再切片。CPU matrix-free 按键向量化作用，临时转移数组按一条通道分配，不预存所有键与构型的笛卡尔积。

低层 `eq_route.solve_equilibrium` 支持显式 `sector` 或 `system['charge_sector']`；直传任意 H 时，需额外提供对应基矢的 `sector_labels`。DMRG 使用 `charge_sector` 启用 TeNPy Sz 块结构。非零横向驱动和有效双激发项不守恒数目，要求固定荷时会被拒绝。

固定荷热态/DOS 和 QMC 产品路径尚未实现，不能静默忽略约束。小矩阵可调用 `equilibrium.thermal_from_h(..., basis_indices=...)` 计算指定基空间的精确 Gibbs 统计量。

## 有限 MPS 状态与接续

Python API 示例（calib 为一般逐键耦合，delta 为逐点 onsite 能量）：

```python
from src.core.manybody.dmrg import dmrg_rydberg_cluster
from src.core.manybody.engine_mps import evolve_mps
from src.core.manybody.state import save_mps_checkpoint, load_mps_checkpoint

ground = dmrg_rydberg_cluster(
    calib, delta=delta, charge_sector=k, return_state=True)
first = evolve_mps(
    calib, psi0=ground['state'], delta=delta,
    t_grid=[0., 1., 2.], max_step_ns=0.1, return_state=True)
save_mps_checkpoint(first['state'], 'state.h5')
restored = load_mps_checkpoint('state.h5')
second = evolve_mps(
    calib, psi0=restored, delta=new_delta,
    t_grid=[0., 1.], max_step_ns=0.1, return_state=True)
```

时间为 ns，Hamiltonian 系数为 MHz，传播相位包含 `2*pi*1e-3`。改变 Hamiltonian 不要求重建初态。每段的 `t_grid[0]` 是输入状态对应的起点；接续恒定 Hamiltonian 时可从局部零时刻开始，显式含时协议的 segment 时间则必须采用同一参考系。

状态包含 `kind=mps`、`backend=tenpy`、版本、独立的有限 TeNPy MPS、原子到 MPS 顺序、局部 g/r 基和可选总激发数。返回快照会在副本上恢复 canonical form，保留范数并不截断额外奇异值。演化也复制输入，不原地消耗上一阶段的状态。

接续要求站点数、原子顺序、物理腿/局部基和荷区相容。所有后续分段控制都要满足相同荷守恒。不会自动重排不匹配的 MPS，也不会把未知算符作用态自动归一化为单位谱权重。

原生状态是 Python 数值对象，不是可直接写入 JSON 的参数值。跨会话使用本地 HDF5 checkpoint，跨进程 Python RunSpec 可使用受信任的序列化；checkpoint 应来自本地可信计算，并记录 TeNPy 版本和模型来源。文件保存是显式动作，不在引擎导入时执行。

产品配置可设置 `manybody.return_state=true`，再将返回状态交给下一次 Python RunSpec 的 `manybody.psi0`。auto 会依据 MPS 后端选择兼容演化器。ED 对应原始输出为终态 `psi_amp`，基态向量输出为 `vec`；原始态不塞进面向人的简短摘要。

CUDA TEBD/SWAP-TEBD 可显式返回 `backend=torch` 的 `(left,2,right)` 数组列表，再用于相同后端。CUDA 张量不带 TeNPy U(1) 块，暂不支持固定荷张量接口，也不隐式转换带荷 TeNPy 状态。暂不支持返回状态的算法会明确拒绝 `return_state` 请求。

## 数值诊断

- DMRG 的 `truncerr` 接到 TeNPy 的 `trunc_cut`；结果同时回报实际截断记录。`S_mid` 对应明确的 `entropy_cut=N//2`，使用自然对数。
- CPU MPS 的关联、熵或范数收缩失败会抛出异常，不返回伪造的零关联、零熵或单位范数。在 canonical 误差影响局域测量时，使用副本恢复规范，保持演化缓存独立。
- 输出时刻与内部步长分开；CPU 分段驱动会在跳变边界细分，即使边界不在输出网格上。
- CUDA 低能求解使用两向量起始、完全重正交和 Ritz 残差。检查 `converged`、`residuals`、`tolerance` 和重启数。未全部收敛时 `gap=NaN`，E0/evals 仍是 Ritz 估计。完全重正交增加 Krylov 存储；可用 `memory_budget_mb` 进行保守预算检查。
- GUI 本地产物保留公共 observables、误差报告及显式请求的原始状态。MCP 的简短摘要不是完整科研数据导出；研究 runner 仍需显式保存完整数组和模型元数据。

## 验证与边界

`checks/manybody_state_solver_selfcheck.py` 覆盖通用复耦合图、完整与无序约化基的 matvec、固定荷产品入口、禁止全矩阵的路径检查、CUDA 能隙和简并、DMRG 诊断、HDF5 往返、DMRG 到 TDVP、分段接续和观测失败。

这些接口不提供 iDMRG、任意圆柱几何、算符分辨的 Lehmann/动态谱或大系统有限温 MPS。此类扩展应继续保持模型输入、求解算法和物理解释分层。
