## 2. 三步合并（每步独立验收）

### B2：`sambe.SambeSetup`——扩展空间结构唯一实现
- 几何（photon_geometry）、块对角（V_dd 块对角嵌入、−iΓ/2 NonHermitian）、
  光子邻接耦合 kron(T, ½K)+转置厄米、非光子常数项（两场变体光场）、
  hamiltonian_seg(mid) 段装配、dense/sparse 分流，统一为一个 N 无关类；
- `_SambeSetup` / `_PairSambeSetup` 变为薄包装（保留旧构造签名；
  mats/As/K2_w 与 envs/envs_w 键由统一层识别，三个引擎零改动接入）；
- 单体的 `_seg_decomp`（K0/Kc_dense 内联装配）、`V_segs`、`coup`、`real_K`
  全部删除；`_probe_pops`/常数包络快路径改走 hamiltonian_seg；
- 单体特有的"中点全零包络 → 冻结对角"快路径保留在单体 `_seg_decomp`
  （两体不走此捷径——其缺陷修正需要捕捉段内包络变化）。
- **逐位等价论证**：每矩阵元恰有一个贡献源（偶极对只属一个波形、diag 与
  耦合不重叠），构造方式（repeat/tile vs kron）不影响数值。

### B1：φ-帧打包与 RHS 内核统一（t66 语义收敛落地）
- `coupling.rhs_phi_pairs`：唯一 φ-帧内核（a<b 单侧打包 + 内核厄米补齐；
  is_mw 载波门控；逐波时变 AC 对角 ac_base (n_ac, dim) × env²（独立
  env 表）；NonHermitian gamma）；
- evolve_mixed 的 `_rhs_phi`/`make_env_tabs`/内联打包删除，`_MixedSetup`
  产出 7 元组 pairs 走 `coupling.pack_rhs`——单体耦合对数减半
  （12→6，双向打包→a<b），AC 对角从"挂主 env 表行"改为独立表；
- evolve_mixed_pair 的 `_rhs_mixed_pair` 变为别名。

### B3：纯冻结段传播统一（`sambe.frozen_seg_propagate`）
- 单/两体同一实现；单体注入 expm_multiply 稀疏策略（大 dim 不稠密化），
  两体注入 eigh 缓存；
- **顺带修复两体缓存键隐患**：旧键只含微波组包络值——两场变体下光场
  env 变化会错用陈旧分解；现键含全部波形（含 opt_terms）；
- 单体从此也享受 eigh 缓存（square 平台/全关区段不再重复分解）。

## 5. 教训

1. **"逐行复制已验证代码"与"合并"的汇合点**：把两份实现合一时，先证明
   两者每矩阵元贡献源唯一（或差异可列举），合并才可能逐位等价——本次
   B2/B3 逐位、B1 在重排序处止步于容差级，全部事先预判并有对照实验背书。
2. **合并会暴露潜在 bug**：两体 frozen 缓存键漏光场 env（两场变体场景
   才触发）在统一实现时暴露并修复——统一不是纯重构，也是一次交叉审查。
3. 兼容层（薄包装 + 键别名）让三个引擎零改动接入统一层，回归面被压缩
   到"统一层正确性"一个问题。

## 6. 第二批（t73b）：hard 单原子并入两体内核 + mixed 重构统一

### hard：单原子 = N_B=1 旁观维的两体
- `_embed_triplets(A, side, n_self, n_other)`：嵌入维度分离——旁观维 1 时

- `_rhs_hard_pair` 内核 N_A×N_B 化（E_B=[0] → uB≡1）；
- `evolve_hard_fast` 重写：合成 `meta_B = dict(E_rot=[0], 无场项)`，走
  共享打包/内核/驱动；`_rhs_hard/_pack_hard/build_hard_rhs` 删除（−139 行）；
- **修复潜伏断链**：`evolve_engine` 单原子 `method='hard'` 引用的
  `evolve_hard` 此前不存在（GUI 不走该入口故未暴露）；现补
  `evolve_hard = evolve_hard_fast` 别名并验证 loss=1−e^{−Γt} 解析一致。
- 验收：22 态 hard 单原子旧内核 vs 旁观内核 max|Δpops|=9.7e-14（舍入级，
  三元组累加 vs 全矩阵装配的结合顺序差）；hard 两体烟测 norm 1.16e-10。

### mixed：重构统一为相干扇区和（正确性修复）
- φ-帧代数：ψ_i = e^{−iC·E_i·t}·Σ_p φ[p,i]——光子相位与 D 对角恰好对消，
  物理布居 = **相干**扇区和；旧单原子用 Σ_p|φ[p,i]|²（非相干），丢掉
  O(Ω/ω) 交叉项；record_amp 也返回过扩展态而非物理振幅——均修复；
- `sambe.sector_sum_pops/sector_sum_amp` 单/两体同一实现（两体的
  Xf/ns 相位式与之解析等价，改用同一 helper）；
- 交叉验证：mixed vs hard 单原子（22 态微波+双光 620ns）max|Δpops|=
  1.92e-05（优于两体版 mixed-vs-hard 的 1.39e-4 验收水平）；mixed vs
  sambe-frozen 差 4.45e-3 为 known 远强对处理之别（AC 化二阶 vs M=1
  动态，t55-t58 norm 漂移 3.2e-3 同源），与本修复无关（该场景旁扇区
  ~1e-13，两种重构不可区分）。
