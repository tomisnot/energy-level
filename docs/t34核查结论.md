## 疑点 1：交换全过程基准（load_scene ≡ 该存档）

A 侧 4 波（微波 17236.743 MHz ×2 + 光 295724187.476 MHz ×2）：

- **ref_add 只有 (6,1,1.5) = +295724187.476 MHz**（build_two_field rot_pick 旋转**低流形 6P**）；
  60S/60P（微波对所在）ref=0 → E_rot = 实验室能量。
- **60S↔60P 微波对 E_rot 差 = 17.20–17.38 GHz，THz 级残差 0/8 对** ✓
- 60S↔6P 光学对 E_rot 差 = 297–620 MHz（停失谐，RWA 有效 ✓）
- hard 620ns：末态 60S=0.000161 / 60P=0.999814（与 t24 刷新基线一致；π 脉冲正常完成，
  norm 5e-8）——**动力学健康，未被钉死**。用户"结果合理且跑得快"与实测一致。

**结论**：hard/两场引擎旋转的是光场耦合对的**低能流形**（6P 平移 +ω_L），60S/60P 保持
实验室能量 → 微波对不产生 THz 假差。"跨光平移态的微波对仍 THz 振荡"只发生在 ip4 系
（`_rwa_reference` 向上传播 ref[60S]=ref[6P]+ω_L 的链式约定）——**hard 路径绕开了该污染**。

## 疑点 2：V_dd 相位扭曲 E_lab vs E_rot

数据（交换全过程，R=10μm/θ=45°）：V_dd 5184 非零元 → `_VDD_MIN_FRAC` 过滤后 144 存活
（max|V|=3.82 MHz）；**存活元素 |dE| = 0–34.7 GHz，0 个 THz 级**。

分析：
1. 内核场项走 E_rot IP（u=exp(iC·E_rot·t)），V_dd 项相位 exp(iC·(E_lab[k]−E_lab[l])·t)。
   两者差 = exp(iC·(ref[k]−ref[l])·t)。
2. 存活 V_dd 元素全连接里德堡态（60S/60P），其 ref=0（旋转只落在 6P 上）→
   **E_lab = E_rot，分歧为零** → E_lab 选择在此类场景正确。
3. 会产生分歧的 THz-dE 元素（连接 6P 的 Förster 通道）**全部被过滤器剔除**
   （|V|≤1e-4·max，净效应 V²/Δ ≤ 1e-8 MHz 可忽略）→ 分歧不可观测。
4. t13 交叉验证（hard ≡ exact_pair，V_dd 开，1.05e-4）背书该约定在测试几何下自洽。

**结论**：用 E_lab 不是巧合而是对**存活物理元素**等价于 E_rot 的正确选择（t8 内核注释
"旋转系 Ω-twist 与 IP u-twist 合并 = E_lab 差"的推导成立的前提 = 连接的态无 ref 差）。
潜在局限：若未来场景把 ref 放到里德堡态上（如链式参考的 60S 平移）且 V_dd 连接平移态
与未平移态，E_lab 相位会漏掉 ref 差——需届时复核（当前引擎约定不把 ref 放 Rydberg 上）。

## 疑点 3：rot_pick 设计决策

- build_two_field 的 rot_pick（每个光场取耦合流形对的**最低流形**、ref=该场载频、
  同流形多场用 exp(iC·δ·t) 拍频）是**同流形多光场拍频**的简化设计（任务书 §2.3，
  当前 GUI 场景：一个光学场对 6P、微波对里德堡对——不需要链式）。
- 不用 ip4 的 `_assign_reference` 链式（ref[高]=ref[低]+ω_L 向上传播）的原因：
  链式正是现象①污染的产生机制（ref[60S]=+ω_L 拖死 60S↔60P 微波对）——hard 身份
  （微波实验室系硬积分）要求里德堡流形保持不旋转。
- 覆盖不到的：纯光场跨流形链（STIRAP：5S↔6P↔60S 两光场——_t33 分析：rot_pick 给
  5S +ω1、6P +ω2 → 光1 耦合对旋转系差 −295.7 THz 残差；正确链式 5S+ω1/6P 0/60S−ω2
  才停失谐）——这是"纯光场链"的修复方向（船长已分析），与本核查的"光+微波跨尺度"
  场景是两类问题。

## 疑点 4：问题.json 现象① 当前状态

- **ip4（两体按侧参考）**：B 无光 → ref_A[60S]=+295723987.476、ref_B=∅ →
  交换对 k1↔k2 旋转系差 = **−2.95724e8 MHz（−295.7 THz）** → 交换被杀；
  B=1e-6（同频）→ ref_B[60S] 也 +295.7 THz → ±ω_L 抵消 → 差 ≈ 0（文档 +20.224 的
  差异来自缺陷对选取）→ **现象①对 ip4 仍存在**（机制精确复现文档 §2.3 数字）。
- **hard**：只旋转 6P → k1 微波对差 = −17.3 GHz（两配置一致，无 THz）——交换走
  实验室系 V_dd，不依赖 RWA 参考抵消 → **现象①对 hard 不存在**（B 有/无光一致）。

**核查结论**：用户对"跨光平移态微波对 THz 振荡"的理解困惑来自两套引擎的参考约定
差异——hard/两场引擎（当前默认、用户看的 交换全过程）**没有**该问题（被绕开）；
ip4 系（evolve.evolve 的 RWA 路径）**仍存在**该参考污染（现象①未处理，文档 §2.5
"待复核边界"结论维持）。若需 ip4 路径修复，方向 = 两体按侧参考的链式约定对齐或
改用两场引擎（属算法改动，需船长另行立项）。
