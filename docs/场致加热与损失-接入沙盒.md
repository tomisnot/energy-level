> 源仓在 core 之外另起了 `dissipation_lab/`（"不改 src/"的实验场）。本文记录把它
> **按"不套层"原则接入 `src/core/`** 的分层设计、落点、与 dissipation_lab 的差异。
> 基线：`##RE0_SUMMARY scripts=21 fail=0`。

## 0. 一句话

`dissipation_lab` 里**模型/速率公式**是引擎该有的物理 ⇒ 收进 core（`field_loss.py`）；
它那个**平行演化器 `evolve_field_loss`** 是套层 ⇒ 不收，改由三引擎现成的
**非厄米时变对角**（`coupling.rhs_phi_pairs` 的新损耗块）承担——这正是 dissipation_lab
自己在 docstring 里指明的"提升进真引擎的接缝"。

## 1. 三层模型（L2/L3/L4）

| 层 | 物理 | core 落点 |
|---|---|---|
| **L2 散射** | 远失谐光把源态抽走：`R=(Γ/2)·s/(1+s)`，`s=2Ω²/(4Δ²+Γ²)`。含饱和上限 Γ/2；**修正旧 F3 取反**（源态=被掺入短寿命伙伴者、Γ 取伙伴离基组率）| `field_loss.scatter_rate_mhz` / `scatter_pair_rates` / `add_scatter_pair` |
| **L3 加热逃逸** | 散射事件累积 → 阱逃逸：`budget`（`loss=1−exp(−N_sc/n_crit)`，`n_crit=U/κE_r`）/ `arrhenius`（温度 ODE）| `field_loss.TrapModel`（budget 档已在引擎侧报告性落地；arrhenius 见 §4）|
| **L4 光电离** | `R_PI=σ_PI·Φ`（线性于光强、无上限）| `field_loss.photoion_rate_mhz` |

**L1 的关系**：调查文档的 L1（`real_field` 远失谐散射公式源态/Γ 取反、里德堡几何下
恒 0）所依赖的代码 `real_field`/`scatter` 已在**第 6 刀整体删除**，沙盒 core 内无错值
对象。它缺的"正确散射损失"能力，由本层 `scatter_pair_rates`（含 F3 修正 + 饱和）补回。

## 2. 分层接入（Phase H1–H3 已做，H4 未来）

- **H1 模型进 core**：新建 `src/core/field_loss.py`（纯模型，`scipy.constants` 取 SI、
  与 `static_atom` 同源；不含演化器）。判据 `checks/field_loss_selfcheck.py`（锚
  A1/A7/A8/A9 + 光电离量级 + 双计/近共振）。
- **H2 配置装配**：`field_build.build_field_loss(cache, states, fields, decays, spec)`
  自动逐远失谐对推 Ω/Δ、查 ARC 寿命取伙伴离基组率、套**双计规则**与**近共振剔除**，
  产出 `FieldLossConfig`（可挂 `TrapModel`）。`runspec.build_run` 据登记册
  `dynamic.field_loss` 产出 `run['field_loss']`——**无该项 → None（默认关）**。
- **H3 引擎消费（opt-in）**：
  - 共用内核 `coupling.rhs_phi_pairs` 增 `loss_base/loss_env_tab/loss_env_dt`——与
    AC 位移块**同构**，但作用为实衰减 `−½·Σ_w env_w(t)²·loss_ns_w[k]·φ`（`loss_base`
    直接以 /ns 存）。`loss_base=None` ⇒ 整块跳过 ⇒ **逐位不变**。
  - `evolve_mixed`（单体）建 `field_loss` 参：摊表、跨光子扇区平铺、传给驱动；
    收尾用 `evolve_util.split_field_loss` 做**分项记账**（spont/scatter/photoion），
    `out['loss']=spont+scatter+photoion`、`out['loss_components']=分项`。budget 逃逸作
    **报告性** `escape` 曲线（不回灌 ψ）。
  - 判据 `checks/field_loss_engine_selfcheck.py`：分项记账数学 + mixed 端到端
    "散射抽布居 + 分项守恒 `Σpops+Σloss≈1` + 开/关差异"。
  - **None 路径的硬闸**＝全基线里所有 `mixed_*` 判据（同内核同驱动，loss_base=None）。

## 3. 对原计划的更正（一处事实）

计划 H3 假设"hard 的 RHS 也经 `rhs_phi_pairs`"。**实测不成立**：`hard.py` 用独立的
`_rhs_hard_pair` + `_pack_pair_hard` + `dop853_driver_hard`（单/两体共用，与 mixed 不同内核）。
故本轮把时变损耗端到端接在 **mixed 单体**（共用内核已就绪），**hard 与两体 mixed 的
接线**（各自的 pack/driver 扩参）列为 **H3b 机械后续**——能力（内核块 + 装配器 + 记账）
已全部就位，只差把它们在 hard/两体路径上也喂进去。

## 4. 尚未接的部分（明确边界）

| 项 | 状态 | 归处 |
|---|---|---|
| hard 单体 / 两体 mixed 消费 field_loss | 内核块与装配已就位，未喂参 | **H3b** |
| L3 `arrhenius` 温度 ODE（回灌 ψ + 精确分项） | 未做——需增广状态（改 `dop853` y 向量与内核），风险最高 | **H4** |
| budget `escape` 仅报告、不回灌 ψ | 有意为之（精确回灌属增广态） | H4 |
| 分项用梯形积分（同 F2 口径） | 与现成 `_loss_and_norm` 一致；精确分项靠增广态 | H4 |

## 5. 开关口径（opt-in）

登记册 `dynamic.field_loss` 缺省 ⇒ `run['field_loss']=None` ⇒ 三引擎行为与不接
**逐位一致**。给出 spec 才启用，形如：
```python
{'near_cutoff_mhz': 5000,
 'photoion': {'sigma_mb_by_idx': {i: σ_Mb}, 'lam_m': 1064e-9},   # 可选 L4
 'trap': {'lam_m': 1013.8e-9, 'depth_K': 1e-3, 'mode': 'budget'}} # 可选 L3
```
