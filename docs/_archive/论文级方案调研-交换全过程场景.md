### 2.2 关键定量修正（重要：文档此前判据有误）

**6P₃/₂ 流形的正确失谐与耦合参数**（用 JSON 内真实能量 E_mhz 计算）：

| 量 | 值 | 说明 |
|---|---|---|
| 光学 W3 失谐 Δ₂ | **+620 MHz** | 载频 295724248.29 − 跃迁 295723628.29 |
| 光学 W4 失谐 Δ₄ | **+420 MHz** | 载频 295723987.48 − 跃迁 295723567.48 |
| 单光子混合 Ω/(2Δ) | 0.084 / 0.125 | ≠ 子代理 F 报告的 5.4e-5（其误用 6P 绝对能量 −296.7 THz 与载频之差 0.98 THz 作失谐） |
| 消去展开参数 ε=Ω/√(Δ²+Γ²/4) | **0.169 / 0.249** | 二阶微扰消去的下一阶误差 = ε²·(有效项) ≈ 125/400 kHz |
| 6P 稳态布居 | 1.4% / 3.0% | 弱占据 → 消去合法（物理上与"强饱和 Ω/Γ=12.4"不矛盾：Ω≫Γ 但 Ω<Δ） |
| 有效丢失率 | 119 / 255 kHz | 远小于微波 Rabi 5.1 MHz |
| AC 位移 | −4.4 / −6.5 MHz | **与 V_ex（~MHz）同量级，是退泵窗口内交换被压制的物理主因** |

**结论 1（修正 Julia 文档 §16.3）**：文档以"Ω/Γ=12.4 强饱和"否定绝热消去是**误判**——正确判据是 Ω vs Δ（Ω/Δ≈0.17–0.25，弱中场），且 6P 稳态布居仅 1.4–3.0%。**消去路线重新可行**。

**结论 2（为什么必须用高阶/精确消去）**：二阶微扰消去（Reiter–Sørensen 式）的下一阶误差 ~125–400 kHz，在 1500 ns 上累积相位误差 O(0.1–4 rad)（布居误差 ~0.7–7）——**不可接受**。必须用：**精确 Löwdin/Schur 消去**（对 6P 子空间精确折叠，误差由能量依赖的有效算符截断控制）或**高阶（≥4 阶）有效算符**（含 Ω⁴ 项）。这决定了方案 A 的"精度天花板"不在消去本身，而在截断阶。

**结论 3（逐载频 M 严格性）**：子代理 F + 文献（Ho–Chu 多模 Floquet 1983；Kuwahara–Mori–Saito 严格收敛 2016；Abanin 准周期扩展 2017）确认——**每个载频独立截断 M 有定理支撑**，统一 M 无任何必要性。微波 r=3.0e-4 ⇒ |k|≤1 误差 ~3e-17；光学 r=3.5e-7 ⇒ |k|≤1 误差 ~1e-13（单光子阶；k=0 扇区错误理解见子代理 F §一）。

### 2.3 方案 A（6P 消去）精确判定（子代理 D 报告，与 §2.2 交叉吻合）

**分类**：本场景是**色散型消去**（Δ/Γ=47–71，Ω/Δ=0.17–0.26），**不是** Reiter–Sørensen 原文的耗散型（Γ≫Ω）——故 Ω/Γ=12.4 不使公式失效，但收敛慢。

**有效性条件与误差**：
- 展开参数 ε=Ω/√(Δ²+Γ²/4)≈0.17–0.25；二阶截断误差 ~ε²≈**3–7%**；
  tol=1e-6 需 **~9 阶**展开（P5/P6 Sylvester 递推可实现，Azouit QST 2017 方法）；
- 有效丢失全程 ≈9.6%（率 0.06–0.14 MHz），**不可忽视**但弱；
- AC 位移 4.6–6.8 MHz 与 V_ex/Ω_mw 同量级，**必须保留**（这正是退泵窗口压制交换的物理）；
- 22→6 压缩公式（16 通道独立求和 + 复位移）：δ̃_k=Ω_k²/(4(Δ_k−iΓ/2))，Σ_k 得 60S 上复能移
  （实部=AC 位移、虚部=丢失率）——**定性/10⁻³ 级满足，1e-6 不满足（需高阶）**；
- **方波边沿是第二大误差源**（绝热跟随需边沿 t_r ≫ 1/Γ≈118 ns，现 20 ns 边沿 ⇒ 明确违规）。

**方案 A 结论**：二阶消去可做快速原型（10⁻³ 级），但 tol=1e-6 需高阶展开 + 边沿整形（方差）+ 与全模型交叉验证。**保留 6P 的全模型（每流形独立旋转系）是"墙钟 60 s 硬约束"下的更稳妥主路线**；消去作为加速/交叉验证路线。

### 2.4 方案 B/C 判定（子代理 E 报告，高振荡数值方法）

**① UA 两标度族**（Chartier–Crouseilles–Lemou–Méhats, Numer. Math. 129:211–250, 2015, arXiv:1308.0507）：
**部分适合**——其理论前提是单快标度/严格周期/幺正；3 载频 + Lindblad 不被现成定理覆盖
（多频 UA、UA-Lindblad 未见文献）。但"段内载波精确化"思想应继承。

**② Magnus/指数积分器**（Hochbruck–Lubich 2003, SIAM JNA 41:945；Hochbruck–Ostermann 2010,
Acta Numerica 19:209）：**不适合单独解耦 295 THz**——交互绘景酉相似不改变算子范数，
纯范数型误差界下步长仍受 Rabi Ω 约束；须 Floquet 平均化先吸收反旋项。适合做段内/慢动力学传播。

**③ Filon/Levin**（Levin 1982, Math. Comp. 38:531；Iserles–Nørsett 2004；Deaño–Huybrechs–Iserles 2017）：
**部分适合**——Wosc 属此族，边界是 f 不得含 ω 尺度微运动（须先剥载波相位）——与 Julia 文档
§8.4"Wosc 微运动天花板"的实测完全一致。

**④ HMM/两标度**（E–Engquist 2003, CMS 1:87；Abdulle 2012 Acta Numerica 21）：
**部分适合**，是"冻结段"的严格理论外衣，支持缓变包络+快周期微动力学收敛性。

**⑤ 冻结段 Floquet**（Shirley 1965, PR 138:B979；Sambe 1973, PRA 7:2203；Grifoni–Hänggi 1998,
Phys. Rep. 304；Bukov 2015；Dey 2025 arXiv:2504.20533；Gu–Zhang 2023 arXiv:2302.03918）：
**适合，主路线**（与项目现有 Sambe 冻结段一致）。

**⑥ 稀疏线性代数加速**（Polizzi FEAST 2009, PRB 79:115112；Zhou–Saad–Chelikowsky 2006, JCP 219；
Sakurai–Sugiura 2003, JCAM 159；Li–Saad 2016, SIAM JSC 38:A2515）：**适合**，作为 60 s 验收
的加速器——位移反演 Krylov/多项式滤波，只求每段 ~30–60 个准能量，跨段热启动。

**⑦ 耗散 Lindblad**：部分适合/无三合一现成方案；建议**非厄米冻结段 Sambe（复准能量）+
量子轨迹分解**（Plenio–Knight, RMP 70:101, 1998）。

**关键定量发现（子代理 E）**：
- 光学反旋项全程 Bloch–Siegert 相位 ≈ **4.4e-5 rad**（略超 tol，M=1 谐波即可精确吸收）；
- 微波反旋 ≈ **1.8e-3 rad**（远超 tol，**必须去 RWA**，不能只留 k=0 扇区）；
- GHz 级旁观者与 17.2367 GHz 载波的非共振混叠 (Ω/δ)²~1e-4–1e-2 是**"单旋转系 RWA 静默
  失效"（P1）的定量根源**。

**子代理 E 最终推荐**：非厄米冻结段 Floquet（光学 M=1 × 微波 M=1–2，段矩阵 4356 维）+
部分准能量求解 + 段间 Krylov/Magnus-2 传播 + 段长自适应 1–50 ns——与现有 Sambe 冻结段
路线一致，主要增量是稀疏/滤波求解与跨段热启动。

### 3.2 推荐决策（三路文献 + 定量交叉一致）

**主路线 = R3（Löwdin/Schur 消去 6P → 逐载频 M → 稠密/稀疏精确传播）**，理由：
- 6P 是色散型弱占据（布居 1.4–3.0%），Δ≫Ω ⇒ 消去物理合法（修正 Julia 文档 §16.3 误判）；
- 维度 60500 → ~10²–10³，直接落入稠密本征分解/expm_multiply 舒适区，60 s 验收轻松；
- 消去的 **−296.7 THz 绝对尺度与 295.7 THz 光学载频同时消失** ⇒ 混叠/光子维/求积瓶颈一网打尽；
- 但**必须高阶/精确消去**（二阶 ε²≈3–7% 不够，需 ~9 阶 Azouit 递推或精确 Schur 折叠），
  并以全模型短窗交叉验证消去误差。

**并行保底 = R4（每流形独立旋转系）**，理由：
- 不改物理（6P 全保留），van Vleck/Floquet–Magnus 给出多参考一致性框架（修 P1 与 §10.1-6）；
- 维度 ~3388，稀疏可解；是"墙钟 60 s 硬约束 + 最高物理保真"下的稳妥替代。

**对方案的直接后果（比 §3.6 更强）**：

   交换 Rabi √((2V)²+Δ²) vs 2V，幅度降 ~15%）。**tol=1e-3 任何情况都不够，必须更高阶或全保留**。
