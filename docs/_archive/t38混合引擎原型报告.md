# 混合引擎 Strang 分裂可行性原型报告（t38）

> 2026-09-02 harddev 原型验证（未改 src）。目标：光场 Sambe（光子块免 RWA）+ 微波
> DOP853 硬积分的混合引擎架构可行性。
> 场景：620ns 单原子 22 态（光 295.7 THz ×2 + 微波 17 GHz ×2），对拍参考 = 纯全 Sambe
> frozen h=1ns（微波也光子块，t36 frozen 模式）。

## 1. 结论摘要

| 项 | 结果 |
|---|---|
| THz 对角与微波项对易性 | **确认对易**：‖[THz 对角, A_mw_ext]‖ = 4.8e-7（≈0） |
| Strang 60ns 窗（E 正确划分后） | **≡ 参考**：max\|Δpops\| = 2.4e-5（全部 Δt=0.5-5ns 一致，不随 Δt 增长——分裂误差 < 参考自身引擎差） |
| Strang 300ns 窗 | ✗ 失败：混合 60S=0.99 vs 参考 0.00017（π 脉冲）——E 相位划分缺陷暴露 |
| 单步耗时 | U_mw 的 mw-DOP853 ~1.7s/5ns 步（Python RHS）；620ns 外推 ~210s+（需 numba） |

## 2. 架构难点与关键发现

**难点**：光场 Sambe 扩展空间的 THz 定常对角（−n·ω_opt）若与微波项同进 DOP853 → 步长被
THz 钉死。Strang 分裂 U_mw(Δt/2)·U_opt(Δt)·U_mw(Δt/2) 是候选。

**发现 1（U_mw 必须走 E 相互作用绘景）**：最初 U_mw 只含 cos·A（无 E 相位）→ 完全不驱动
（60S 恒 1.0——微波驱动需要能级相位与 cos 干涉）。修正：U_mw 在 E 的相互作用绘景
（φ = e^{+iC E t}ψ，A_phased = A∘e^{iC(E_i−E_j)(t−ta)}），残余频率 = 能级差∓ω：共振对慢
（失谐）、非共振对 ~2ω（34 GHz）→ DOP853 可行。**但 E-IP 含 6P 对的 C·3e8 相位（即使
耦合 ~1e-4）→ THz 钉死——须先过滤 A_mw 至近共振对（|能隙−ω|<5GHz）**。

**发现 2（E 相位双计 vs 光场共振需 E 的矛盾）**：Strang 中若 U_opt 的 K 含 E（Sambe K0 原生
含）且 U_mw 的 lab 转换也含 E → 总 E 相位 2Δt（双计）→ 60ns 不驱动。去掉 U_opt 的 E
（K0' = K0 − diag(E_ext)）→ 60ns 窗 ≡ 参考（2.4e-5 ✓）——**但 300ns 失败**：光场共振依赖
E 在光子块对角（K_noE 的对角 = 纯 n·ω，光学耦合失共振）→ 长窗光场物理丢失。

**正确划分方向（推荐，需后续实现验证）**：E 保留在 U_opt（Sambe K 原生含 E——光场共振
正确），U_mw 的 E-IP **不做 lab 转换**（φ 帧为工作态），U_opt 亦须作用在 φ 帧（K 的 IP 化：
THz + 光场耦合的 e^{iC·gap·t} 相位由光子块吸收）——即全程 φ-帧一致表述，E 相位单次
承载于 U_opt。这是架构可行的关键补丁，尚未验证。

**发现 3（对易性）**：‖[THz 对角, A_mw_ext]‖ = 4.8e-7——THz 对角（每扇区 n·ω·I）与
I⊗A_mw（扇区块对角）对易 → 分裂误差只来自 [光场耦合, 微波]（MHz 级）+ [E, mw]（由
φ-帧划分控制）→ **大步 Δt 可行**（60ns 窗 Δt=5ns 误差仍 2.4e-5）。

## 4. 推荐

1. **架构可行**（60ns 窗证明 U_mw-IP + U_opt 分裂结构正确），但需先实现 φ-帧一致表述
   （E 单次承载于 U_opt + U_mw 不重复 lab 转换）再跑 300ns+ 验证——这是第二阶段的
   前置补丁。
2. 大步长可行（Δt=5ns 误差不增），620ns 全程步数 ~124。
3. U_mw 的 DOP853 需 numba 化（现 Python RHS ~1.7s/5ns 步；620ns 外推 ~210s+）。
4. 原型脚本：tempsimu/_t38_strang*.py / _t38_debug*.py / _t38_300ns.py / _t38_proto3.py。
