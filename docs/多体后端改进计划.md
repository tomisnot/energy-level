# 多体后端改进计划（实现状态）

Runspec 只接收模型参数；HamiltonianPlan 在装配阶段决定 full/effective basis，求解器只消费矩阵或线性算子。

- blockade/PXP：支持显式或自动边，project 模式编译到独立集基；projected Hamiltonian 自动限制到 ED/Lanczos。
- sector：ED、CPU matrix-free Lanczos 与 thermal 入口支持 `basis_indices`；扇区入口会检查守恒。
- DMRG：只有显式 `charge_sector` 才启用 TeNPy `Sz` 守恒，并在结果中返回 `charge_sector/conserve`。
- GPU：`gpu-lanczos` 与 `gpu-kpm` 均为矩阵自由/分块 probe；无 CUDA 时检查脚本明确 SKIP。`manybody.memory_budget_mb` 和 `manybody.dtype` 是统一旋钮。
- estimate：显式 blockade edges 直接给出 `effective_dim/reduction_ratio` 并用于 ED、时间和内存粗估；`edges=auto` 需装配标定后确定。
- 自由费米子：`free-fermion` 对无相互作用、无局部翻转、最近邻实 XY 的数守恒模型直接对角化单粒子矩阵，并支持固定激发数；超出条件立即拒绝。
- 其它对称性：实现显式声明的 1D 反射对称性检查与 ± parity 投影工具；不对任意点云自动假定平移或反射对称。

所有新后端都配有小系统基准，基准在无 CUDA 主机上只报告 SKIP，不伪造通过。
