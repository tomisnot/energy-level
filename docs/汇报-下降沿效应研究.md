## 摘要

前人的结论是"下降沿越缓、800 ns 窗口内峰值越低（−5.4 ~ −6.7 点）"，并在判决实验中
否定了"停留时间/超额积分"机制，留下"疑似平滑穿越共振"的线索。

本轮我把问题**换了形态**：先证明前人的主指标（峰值）**混了两个物理量**——真正的交换能力
（振幅）与相位落在哪里（采样）；再用锁相法提取振幅，跑了一个 9 点判决实验
（对称往返 / 停留式 / 单向下降三族，全部回到同一末态光强）。结论：

1. **下降沿基本不改振荡频率**（跨 21 条曲线 2.3347 MHz，相对散布 5e-5），
   **但大幅改相位**（φ0 跨 5.4 rad > 0.85 周期）。
2. **它也确实削弱交换能力**：可达最大值 (C+A0) 从 0.7623（理想阶跃）变到 0.6161
   （100 ns 对称往返），**−19%**（前人 F 族 τ_f 0→100 ns 为 −9.3%）。
3. **但这不是"布居损失"**：交换子空间（两个工作通道）内的总布居在 9 条曲线间极差仅
   **6.6%**，而目标通道占比 a/s 从 **0.910 变到 0.713**。⇒ **原子没有跑掉，是两通道之间的分配被改了。**
4. **损伤尺度 ∝ 沿造成的净相位积累 |Δφ|**（双变量拟合标准化系数 +1.04，单向项仅 +0.40）。
5. **我自己的预注册预言 P1/P2 被数据否定**：我以为"对称往返自我补偿"，实测只在
   τ=25 ns 成立（**比理想阶跃还好 5.4%**），到 τ=100 ns 却**最差**（−19%）。

**可交付的工程结论**：不要"慢慢降光"。首选 **~25 ns 的短对称往返**（可达最大值
0.8064 > 阶跃 0.7623）；τ 越长越糟（50 ns −11%、100 ns −24% 相对振幅）；相位必须随沿标定。

### 1.2 我做的第一件事：质疑指标

前人主指标 `峰值 = max_t P(换后态)`。我发现它对 12 条曲线给出的差异里，
**混进了相位采样**。判据：

```
峰值_i ≈ C_i + A0_i      （A0 = 单模振幅，C = 单模基线）
12/12 条吻合，|差| 中位 3.5e-3、最大 8.4e-3
而主频 f0 跨 12 条：2.3348 MHz，相对散布 1e-4
```

**频率不变、峰值差 12 个点** ⇒ 差异主要来自**相位**，不是能力变化。
这是本轮所有后续工作的基础。

### 1.3 方法：锁相式单模提取

- 稳态段（≥340 ns）加 Hann 窗 → FFT 取主峰频率 f0（抛物线细化）
- 最小二乘投影到 {1, cos2πf0t, sin2πf0t} ⇒ **C（基线）、A0（振幅）、φ0（相位）**
- **弃用 Hilbert**：布居含主交换 + 慢拍两个分量，解析信号把拍当包络，给出
  **非物理**结果（E1/hold100 的"包络" 0.83 > 观测峰值 0.78）
- **窗口稳健性（必做）**：A0 在 4 个含 2.2–3.9 个振荡周期的窗口下一致到 **±2.7%**；
  只剩 1.4 个周期的窄窗失效（跨窗口极差 68%）
  ⇒ **纪律：分析窗内 ≥2 个交换周期**（T ≈ 428 ns ⇒ 窗口 ≥900 ns）

### 1.4 判决实验设计（关键约束）

**所有轨迹的末态光强都必须回到 I_res = 0.42·I₃。**
否则末态哈密顿量不同，(C, A0, f0) 本身就会变，振幅差异无法归因于"沿"。

| 族 | 形状 | 穿越 I_res | 单向行程 |
|---|---|---|---|
| **C** | 单向下坡（前人 F 族定义） | 1 次 | 0.58 |
| **A** | I_res → I₃ → I_res（对称三角） | 2 次 | **0** |
| **B** | 跳到 0.71 停 dwell → 跳回 I_res（E1 式） | 1 次（瞬时） | 0.29 |

共 9 点（A:25/50/100 ns；B:dwell 10/25/50 ns；C:step/25/50 ns），
`record='pops'`（带时间序列），7 进程并行，357 s 跑完，**9/9 成功**。

## 三、物理原理

### 3.1 为什么"频率不变、只改相位"

交换由 V_dd 网络驱动（前人静态引擎：目标通道 −1.2056 MHz，竞争通道 −1.2585 MHz，
另有 4 个 0.31–0.70 MHz 的通道）。沿结束后光强回到 I_res，
**末态哈密顿量回到同一算符** ⇒ 本征频率固定 ⇒ 观测到 `√(V²+δ_res²) = 2.3347 MHz`
跨 21 条曲线逐位相同（5e-5）。

而沿期间，瞬时广义 Rabi 频率

```
Ω(t) = √( V² + δ(t)² ),   δ(t) = κ·(I(t) − I_res)      （κ>0 为光移系数）
```

与光强历史耦合，积累相位

```
φ_i = ∫ Ω_i(t) dt        （i 标记通道；各通道 V_i 与 δ 系数不同）
```

各通道 φ_i 不同 ⇒ 沿在通道间留下**相对相位** ⇒ 改变两通道的干涉分配 a/s。

### 3.2 为什么"不是泄漏"（本轮最硬的结论）

若机制是布居跑到别的态，`s = a+b` 应随沿变宽下降。实测 `|Δs| ≤ 3.6%`
而 `|Δa| ≤ 19.2%`，且峰值时"堆外布居"为 0。
⇒ **原子没有离开交换子空间，只是两通道之间的分配被相位重排了。**
这也解释了为什么前人把"峰值下降"读成"交换被破坏"会误导：能力还在，分配变了。

### 3.3 为什么"停留时间/光强积分"被否（三次否定，本轮最干净）

同一平台段光强积分 `S = ∫ I dt = 747.4 I₃·ns` 的四条轨迹：

| tag | 末态换后 a | 相位行程 |
|---|---|---|
| `A/tri25_d1.00` | 0.0326 | 最短 |
| `B/hold50@0.71` | 0.0661 | |
| `C/down50` | 0.0233 | |
| `A/tri50_d0.71` | **0.1799** | 最长 |

**同 S，末态差 7.7 倍**。前人否掉"超额积分"`∫(I−I_res)⁺dt`，
本轮否掉"完整光强积分"`∫I dt` ⇒ **末态只可能是相位的函数**。

### 3.4 损伤尺度：相位积累主导

两个候选控制量（相关系数 −0.717，**不共线**，可分离）：

```
X1 = |Δφ|            沿造成的净相位（相对理想阶跃）
X2 = 单向净扫过的强度行程（对称往返 = 0，单向下降 = 0.58）

loss_rel = +0.1169·|Δφ| + 0.1340·X2 − 0.0688
           标准化 +1.04      标准化 +0.40        拟合 rms 0.0475
单变量：corr(|Δφ|, 损失) = +0.748 ;  corr(X2, 损失) = −0.341
```

⇒ **相位项主导（2.6 倍）**，单向性次之。|Δφ| 达 2.2 rad 时损失 ~24%。

### 3.5 为什么"短对称往返"反而增强

`A/tri25` 的 (C+A0) = 0.8064，**高于理想阶跃 0.7623**，且 4 个窗口下稳定
（−5.0% … −5.7%）。机制图像：短 excursion 给两通道引入一个**有利的相对相位**，
把分配推向换后态（a/s 0.878 → 0.910）。
但 excursion 拉长后相位继续累积、越过最优值（τ=50 ns 时 a/s 落到 0.816，τ=100 ns 到 0.713）
⇒ **存在最优相位，不是"越短越好"也不是"往返更好"**。
这是本轮唯一"可利用"的物理效应，也是下一轮该做物理闭合的地方（§6）。

### 3.6 前人 §4 的"竞争通道更大"如何并入本图像

竞争通道 V=1.2585 MHz > 目标 1.2056 MHz ⇒ 末态两通道**本征混合角**偏向竞争通道
⇒ 分配上限就压在 ~0.88，这是 a/s 的**几何上限**；沿造成的相对相位在这个上限内
上下调节 a/s（0.713–0.910）。两者是"上限"与"调节量"的关系，不矛盾。

## 五、与证据一致的解释与仍缺的一环

**解释（H6 + H8）**：沿通过光移历史在 V_dd 网络的各通道间留下相对相位 φ_i，
改变末态两通道的干涉分配 a/s；频率由末态哈密顿量固定，故不变；
损伤尺度由净相位积累 |Δφ| 主控。

**仍缺的一环**：φ_i 的**显式计算**未做。需要
1. 用静态引擎算出各通道的 V_i 与 δ 系数（`direct_ac_stark_shifts`）
2. 逐通道算 φ_i = ∫√(V_i²+δ_i(t)²)dt
3. 检验 a/s 是否 = f(φ_i − φ_j)

**未解释的两点**（必须一起引用，不能藏）：
- `B/hold50` 的 Δφ=0.87 rad 却零损失（残差 +7.0%）
- `A/tri25` 的增强（线性律会预测 +0.9%，实测 −5.4%）
⇒ 双变量模型 rms 0.0475 仍不小，**这是经验律，不是定律**。

## 六、结论与工程建议

| # | 结论 | 数据支撑 |
|---|---|---|
| 1 | 下降沿**不改交换频率**，主频 2.3347 MHz 跨 21 条曲线不变 | 相对散布 5e-5 |
| 2 | 下降沿**主要改相位**：φ0 跨 5.4 rad | 同频率下相位差 >0.85 周期 |
| 3 | 下降沿**也削交换能力**：可达最大值 −19%（本实验）/ −9.3%（前人 F 族） | A0 跨 38%，C+A0 从 0.806 到 0.616 |
| 4 | 削的不是布居，是**两通道分配**：a/s 0.910→0.713，而 s 只变 6.6% | 峰值时堆外布居 ≈ 0 |
| 5 | 损伤尺度 ∝ **净相位积累 \|Δφ\|**，单向性次之 | 标准化系数 +1.04 vs +0.40 |
| 6 | "停留时间/光强积分"**不是机制**（第三次否定） | 同 S=747.4 末态差 7.7 倍 |
| 7 | **最优边沿 = ~25 ns 短对称往返**（+5.4%）；拉长急剧变差 | 4 窗口稳定 −5.0~−5.7% |

**实验建议**
1. **报告口径**：报 **(C+A0)**（可达最大值）与 **A0**（振幅），**不要**报单一时刻峰值。
   前人文档的 −5.4/−6.7 点需按此重述。
2. **不要"慢慢降光"**：τ_f 0→100 ns 掉 9.3%；若要缓沿，必须同时接受**相位重标定**。
3. **首选短对称往返**（~25 ns）；**别拉长**（50 ns −11%、100 ns −24%）。
4. **相位必须标定**：沿造成相位差可达 0.85 周期，固定时刻读交换会因沿不同而完全变样。
5. **窗口纪律**：≥2000 ns，且分析窗内 ≥2 个交换周期（≥900 ns）。

## 七、限制（须与结论同时引用）

1. **时间网格收敛性未直接验证**（预注册 P5 未做）：本批全为 `npts=1001, tol=1e-8`。
   **旁证**（非等价）：前人 F 族与本文在**相同 npts** 下 `C/down50` 观测峰值
   **逐位一致（0.7395 = 0.7395）**，说明流程可复现，但这**不等于**网格无关。
   ⇒ **绝对幅度（尤其 +5.4% 增益）应视为该网格下的值；趋势（τ 越长越差）比绝对值可靠。**
2. **A0 对分析窗有 1–3% 敏感度** ⇒ 本文 A0 取 4 个有效窗口平均，单窗口数字不可直接引用。
3. **单几何（R=14.1 μm/θ=31.1°）、单光强标度（I₃=2.0e8）**：未跨标度验证。
4. **经验律而非定律**：双变量拟合 rms 0.0475、个别残差 ±7%。

### 8.2 其他工程坑

- `submit_sweep(points=[...])` **不能带 `tag` 等元数据键**（`apply_delta` 把每个键当参数路径校验）
- `FileEnv` 要求时间样品**严格递增**（折线重复时刻即报错）
- `record='final'` 的 npz 只有 `labels/final_pop/t_ns`；要时间序列须 `record='pops'`
