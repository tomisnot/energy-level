## 第 4 刀：能级枚举收成一处（治"两页两套实现"）

### 改前有三份实现

| 函数 | 用途 | 行 |
|---|---|---|
| `static_atom._base_level_rows` | 静态页显示（`E0/E/color/label/x/ac`） | L849-891 |
| `static_atom._group_sublevel_rows` | 最近跃迁对查找（`E_mhz/qstr`） | L959-981 |
| `runspec.build_states` | 动态基组 | L79-122 |

三份都做同一件事：`get_hyperfine_levels` → 循环算能量 → 裁剪。
**能量算法还不同**（静态页自算 Zeeman，动态页调 `_sublevel_energy`）。

### 改后只剩一处

```
static_atom.base_sublevels(cache, groups, B_gauss=0.0, E_vpcm=0.0, pump=None)
    """静态页与动态页共用的唯一「组 → 子能级」实现"""
        ↓ 三个消费方各自投影
    ├─ _base_level_rows      → 补 x/E0/E/ac/affected（静态页显示）
    ├─ _group_sublevel_rows  → 直接返回（跃迁查找）
    └─ runspec.build_states  → 投影成 make_levels 的 specs（动态基组）
```

**为什么逐位安全**：`_sublevel_energy(cache,n,l,j,m,B)` 的定义就是
`cache.E_mhz(n,l,j) + cache.gJ(l,j)*MU_B_MHZ_PER_G*m*B`——与静态页自算的
表达式**逐字相同**；F 态两边都是 `cache.E_mhz + e_hf`。所以 `E_vpcm=0` 时
统一前后**逐位不变**（实测：22 个态全部 `Δ = 0`）。

### 验收

新判据 `checks/levels_twopage_selfcheck.py`：

| 包 | 断言 |
|---|---|
| A | 同一 `groups + B + E_vpcm` 下，两页**态集合相同**且**能量逐位相同**（`E_vpcm` = 0 / 1 / 10 V/cm 三档） |
| B | `E_vpcm` 0→10 V/cm 时两页能量**都移动**，且移动量**逐位相同** |
| C | 超精细 DC 按 mJ 加权（见第 5 刀） |

## 第 5 刀：静态页补 DC-Stark（并修掉超精细态的静默失效）

### 静态页原来**完全不看静电场**

全仓 AST 调用点搜索：`dc_stark_shift_mhz` 的调用点只有 `runspec.py`（动态路径），
静态页的 `_base_level_rows` **一次都不调**。⇒ 静电场在静态页没有任何效果，
而动态基组会因它移动——**同样的 `field.E_vpcm`，两页能量分叉**。

### 顺带发现并修掉一个静默失效

动态页对超精细态传的是 **`mF`**，而 `dc_stark_shift_mhz` 的 `m` 参数要的是 **mJ**。
`mF` 超出 `|m2| ≤ j1` 的范围 ⇒ **整项被跳过，恒返回 0**。实测（`E_vpcm=100 V/cm`）：

| 算法 | 6P₃/₂ F=3, m_F=−3 |
|---|---:|
| `dc_stark_shift_mhz(..., mF, ...)`（旧动态页） | **0.000000e+00** |
| `Σ_{mJ} \|amps[mJ]\|²·ΔE(mJ)`（加权，AC 路径同款） | **−1.022076e−01 MHz** |

即：**动态页对超精细态的 DC-Stark 一直是空操作**。新增 `_dc_stark_hf` 按 mJ
分量加权（与 `_floquet_ac_static` 对 F 态的处理同源），两页同时修正。

### 验收数字

`E_vpcm` 0 → 10 V/cm（`B=21.7 G`）：

| 态 | 位移 |
|---|---:|
| 60S₁/₂ m_J=−0.5 | −5362.6 MHz |
| 60P₃/₂ m_J=+1.5 | −3543.8 MHz |
| 6P₃/₂ 各 (F,m_F) | −0.0102 MHz（加权后的真实值；旧行为是 0） |

`E_vpcm=0` 时**零改动**（默认值就是 0，故默认路径逐位不变）。

### ⚠ 留给使用者的物理提示（未改）

里德堡态在 `100 V/cm` 下 SOS 给出 **−5.4 THz（60S）/ −37 THz（60P）**。
n=60 的 Inglis-Teller 场约 **25 V/cm**——**超过它二阶微扰已失效**。
公式本身没问题，但 `field.E_vpcm` 的界面量程是 **±1e6 V/cm**，远超有效域。
**要不要给这个参数加有效域提示/夹取，是物理裁决，本次没动。**
