## 2. 静态能级与基组

### 2.1 唯一基准：`base_sublevels`

`static_atom.base_sublevels(cache, groups, B_gauss, E_vpcm, pump)`（`static_atom.py:888-941`）：

- 里德堡态（`n ≥ RYDBERG_N_MIN=20`，`static_atom.py:63`）走 `get_hyperfine_levels` 返回 `None` 分支（`static_atom.py:914`）→ 只展开 fine-structure 的 `m_J`，能量 `E0 + gJ·μB·m·B`（`static_atom.py:917`）；
- 低激发态走超精细分支（`static_atom.py:926-937`）→ `(F, m_F, e_hf, w, amps)`，`amps` 是 `{m_J: 复振幅}`；
- 每行同时给 `label`（**身份名**，`auto_label` + 量子数，与 `make_levels` 逐字相同）与 `group_label`（用户起的人工名，只供显示）（`static_atom.py:894-897`）；
- **不含 AC 位移**：AC 是静态页显示层叠加（`static_atom.py:900-901`）；动态页的光移由场耦合在传播中涌现。
- 逐子能级裁剪在末尾统一施加 `apply_trim(g_rows, *trim_of(g))`（`static_atom.py:938`，`static_atom.py:984-1024`）。

`runspec.build_states` 把它投影成 `make_levels` 的 specs，并**显式传 label**（不让 `make_levels` 再拼一次），`E_hf` 留 0（行里的 `E_mhz` 已含超精细）（`runspec.py:126-150`）。两页态名同源同字由 `checks/levels_twopage_selfcheck.py` 守。

### 2.2 身份键

`atomic_levels.state_key(s)` = `(kind, n, l, j, m, round(E_mhz,6))`（`atomic_levels.py:78-90`）；`find_state_index` 三级回退：完整键 → 前 5 元 → 组内能量最近（`atomic_levels.py:93-124`）。**末位能量使键跨 B 稳定**，也意味着 B 一变键就变。

### 2.3 偶极 / Rabi / AC-Stark / DC-Stark

- `dipole_amplitude(cache, a, b, q)`（`static_atom.py:575-620`）：四种 kind 组合分别按 Δm_J=q / m_F 守恒判，**缺匹配返回 0**——"把耦合错归到别的 mJ 态"的防线。
- `rabi_mhz(d_au, E0_sq, pol_frac)`（`static_atom.py:429-436`）：**Ω/2π 周频约定**；Sambe 子空间耦合取 Ω/2（`sambe.py:169` 的 `0.5*Ksp`）。
- 偏振：`elliptical_coeffs`（`static_atom.py:82-110`）给 `(c₊,c₀,c₋)`；`build_fields_exact` 对 `pol=='椭圆偏'` 走相干叠加（`field_build.py:136-150`）。**历史坑**：旧版 `_POL_Q.get(pol, 0)` 把"椭圆偏"静默当 π（`field_build.py:133-135` 记录）；`arbitrary_mw_group` 曾手写第三份 q 映射并同样静默退化（`evolve_twofield.py:66-77`，现改为告警 + `_POL_Q`）。
- AC-Stark **唯一后端**是 Floquet 直接对角化 `direct_ac_stark_shifts`（`static_atom.py:688-767`）：`H_F = Σ_n (H0+nω)⊗|n⟩⟨n| + (V/2)⊗(移位)`（`static_atom.py:694`），默认 `AC_N_PHOTON=4`（`static_atom.py:523`）。内存闸 `_ac_check_space`（`static_atom.py:545-557`，`AC_NM_MAX=12000`，实测 42848 维 OOM）。**只影响静态页显示，不参与演化**（`static_atom.py:519-522`）。
- DC-Stark `dc_stark_shift_mhz`（`static_atom.py:466-508`）：二阶 SOS，吸收/发射两方向都算（`static_atom.py:501-507`）。
- 远失谐非 RWA 二阶：`far_sos_shift_mhz`（`static_atom.py:449-463`），近共振返回 0 防除零（`static_atom.py:458-461`）。

## 3. 三引擎（逐个：算法 / 适用域 / 失效情形 / 关键参数）

### 3.1 mixed（**默认引擎**，`runspec.py:516`）

**算法**（`evolve_mixed.py:1-23`）：φ-帧变换 `φ = e^{iC·D_full·t}·X`（`D_full` = 光子块全对角 = `E − n·ω`，`evolve_mixed.py:249`），THz 对角被吸进全局相位，剩下光场共振对慢、微波同扇区 cos 干涉 → **单 DOP853 直接积分**：

```
dφ/dt = −iC·[Σ_光场 env·Kc∘e^{iC·ΔD·t} + Σ_微波 env·cos(ωt)·A∘e^{iC·ΔD·t}]·φ
```

- 光场对：`BW_OPT=2e4` MHz 过滤反旋（`evolve_mixed.py:284`）；
- 微波对：**先成本后精度**——`det > mw_cap` 丢（`evolve_mixed.py:306`）→ `mw_pair_keep` 的 Θ 判据丢（`evolve_mixed.py:323-326`）；
- 远强光场对 AC 化：`acize_physical`（`evolve_mixed.py:73-102`）按 `r=Ω/ω > R_CRIT` 剔除，位移走 `far_sos_pair_shift` 注入物理 E（`evolve_mixed.py:62-70`、`evolve_mixed.py:418-421`）；
- 输出：`X = e^{−iC·D·t}·φ` → **相干扇区和** `sector_sum_pops`（`sambe.py:418-420`）。旧的非相干和 `Σ|φ|²` 丢 O(Ω/ω) 交叉项，22 态实测 ~4e-3 系统误差（`evolve_mixed.py:564-566`）。
- RHS 内核 = `coupling.rhs_phi_pairs`（`coupling.py:212-298`），numba njit，含微波 `cos(φ(t))` 查表、AC 对角 `env²`、耗散、场致损耗四个块。
- 积分器 = `coupling.dop853_driver_mixed`（`coupling.py:323-332`）——薄包装，**唯一目的是让 numba 磁盘缓存命中**（`coupling.py:301-315` 有完整事故记录：rhs 当参数会让缓存键含 WeakType → 永不命中、索引膨胀到 375 文件/100MB、保存时 `ReferenceError` 搞失败整轮演化）。

**关键参数**：`DEFAULT_RTOL=1e-8`（`evolve_mixed.py:46`）、`DEFAULT_ATOL=1e-10`（派生 `= rtol×ATOL_RTOL_RATIO`，`evolve_mixed.py:44,47`）、`max_step=0.05` ns（`evolve_mixed.py:367`）、`BW_OPT=2e4`、`M_EST_TOL=1e-6`（`evolve_mixed.py:48`）、`_RHS_ENV_TAB_N=20001`（`coupling.py:20`）、`_AC_ENV_TAB_N=4001`（`evolve_mixed.py:49`）。

**两体 mixed**（`evolve_mixed.py:786-1192`）：同一 φ-帧内核，共享光子块 `M=1`（`evolve_mixed.py:705`），微波/V_dd **不进光子块** ⇒ `dim = N²·P`，P=3（标准 5 倍降维，`evolve_mixed.py:895-896`）。V_dd 同扇区保留（`env≡1`，`evolve_mixed.py:913-940`），按 `static_phase_keep` 过滤（`evolve_mixed.py:925-926`）——**这一处修好了** hard↔mixed 差 ~1e-5 的根因（`evolve_mixed.py:914-919`）。AC 化**位移不注入**（`_ac_ize_pair`，`evolve_mixed.py:655-669`）：近对留在光子块 M=1，位移自然涌现；再注入静态位移会与动态**双计**（375ns 交换 0.012 vs 0.558 的根因）。光场**载频必须一致**（`evolve_mixed.py:845-852`，异频 → `NotImplementedError`）。初态：`psi0_pair` 优先于 `psi0_A/psi0_B` 的直积（`evolve_util.py:153-168`）。

**适用域**：光+微波共存（核心）；强光近共振 + 微波；STIRAP 链（φ-帧无参考，绕开 hard 的 `rot_pick` 盲区）；任意波形微波（t79）；无光场合法（P=1 退化为实验室系微波/V_dd 当场精确积分，`evolve_mixed.py:425-429`、`evolve_mixed.py:890`）。

**失效情形**：
- 光场反旋对必须滤（`BW_OPT`），漏滤 → DOP853 步长被钉死（`evolve_mixed.py:284`）；
- **无光场且基组含光学流形**时任意波形路径会被 THz 相位钉死（`field_build.arb_applicability` 第②条，`field_build.py:300-304`，实测 2 ns 演化 >60 s）；
- 微波对全被删时只写一条 log（`evolve_mixed.py:497-503`），**不报错**；
- 成本窗剔除是**真的改模型**：`drop_cost_loud` 记账 + 吵闹日志（`evolve_mixed.py:308-321`、`504-513`），但**只在单体**——两体无此记账（见 §8.3/§8.4）。

### 3.2 sambe（第一性原理，最慢最准）

**算法**（`sambe.py:1-15`）：实验室系 `H(t)=H0+Σ env·cos(ωt)·A`，**无 RWA / 无旋转系 / 无近远分流**。三段结构：
1. 核心层：`photon_geometry`（`sambe.py:44-82`）给光子块几何（逐载频 `M_g`、块数 `2M_g+1`、`P=Π(2M_g+1)`、`diag = E − (n−M)·ω`）；`SambeSetup`（`sambe.py:85-235`）单/两体同一实现；
2. 单体引擎：`_m_analytic` 解析下界 `(r/4)^{2(M−1)} ≤ tol`（`sambe.py:562-583`，逐载频独立）+ 探针复核（`sambe.py:883-909`，`r_g<1e-5` 跳过探针）+ 自适应分段（中点冻结精确指数 + Duhamel 缺陷修正 + Gauss–Legendre 节点倍增，`_propagate_adaptive` `sambe.py:668-779`）；
3. 两体引擎：`_pair_propagate`（`sambe.py:1223`）稠密本征基缺陷 / 稀疏 IP Volterra-GMRES（`_subspace_segment` `sambe.py:1071-1156`）/ frozen（`frozen_seg_propagate` `sambe.py:356-402`）。

**关键参数**：`tol=1e-6`（`sambe.py:823`）、`_M_START=2`/`_M_MAX=8`（`sambe.py:609-610`）、`M_EST_BW_MHZ=2e4`（`sambe.py:605`）、`_DENSE_MAX=2200`（`sambe.py:606`）、`_DT_MIN_FRAC=2e5`（`sambe.py:607`）、`_ENV_PROBE_N=2001`（`sambe.py:608`）、`_NODE_LADDER=(16,32,64,128)`（`sambe.py:611`）、EP6 保护 `_SPARSE_MAX_DEPTH=4`/`_SPARSE_SEG_MAX=50000`（`sambe.py:612-613`）、Volterra `_VOLT_*`（`sambe.py:614-616`）。

**适用域**：STIRAP/拉曼类多光场无 RWA（收敛 3.5e-7，`docs/引擎能力边界-终稿.md:45`）；全频段两体；作为 mixed 的对照锚。

**失效情形**：
- **慢**（frozen eigh/段）；
- **变频/任意相位不支持**（光子块周期性假设）→ `runspec.effective_method` 自动改道 hard（`runspec.py:336-339`）；
- **稀疏路径（dim > 2200，非 frozen）**：两体有 EP6 保护并明确报错建议 frozen（`sambe.py:1293-1300`、`1347-1356`）；**单体稀疏路径无任何误差控制**（`sambe.py:715-716` 直接 `expm_multiply` 返回，不细分不记 est）——见 §8.12；
- 远失谐强对需 AC 化（`R_CRIT` 判据，`sambe.py:1478`）；
- **两体的 `ac_ize` 产品路径不可达且实现是近似**（`sambe.py:1457-1464` 自述"峰值位移当整窗静态对角"）——见 §8.10；
- `sambe.py:93` 注释说"两体 700"是**过时注释**：`_PairSambeSetup` 缺省一律取 `_DENSE_MAX=2200`（`sambe.py:969-970`、`sambe.py:1574`），`_DENSE_MAX_PAIR` 已删（`sambe.py:426`）。

### 3.3 hard（微波硬积分，零微波近似）

**算法**（`hard.py:624-644`）：光场旋转系 RWA 吸收载波（唯一近似是光学 RWA，反旋 Bloch–Siegert 相位 4.4e-5 rad）；微波**不做任何变换**，`H(t)=diag(E_rot)+Σ c(t)·A_opt+Σ c(t)·cos(C·ω·t)·A_mw` 交给 DOP853 自适应硬积分 ⇒ 微波多光子/BS/任意谐波**天然全含**。单/两体共用 `_rhs_hard_pair`（`hard.py:376-437`，单原子 = `N_B=1` 旁观维，`hard.py:106-109`）。包络**查表**（`_TAB_N=2^17`，`hard.py:618`；载波**不查表**、直接 `cos()`——`hard.py:14-16` 有理由）；V_dd 按 `dE` 分组、每组一个 `exp`（`hard.py:419-425`），先经 `static_phase_keep` 过滤（`hard.py:341`）。

**关键参数**：`rtol=1e-9`/`atol=1e-11` 是 `evolve_hard_fast` 签名默认（`hard.py:82`），但**产品路径用 `1e-8`/`1e-10`**（`runspec.py:692` 传 `DEFAULT_RTOL`/`DEFAULT_ATOL`）；`_TAB_N=2^17`。

**适用域**：微波主导（π 脉冲/变频/任意波形）——**唯一支持任意相位场**（t18 `cos(φ_f(t))`，`hard.py:287-291`）；弱光远失谐 + 微波。

**失效情形**：
- **STIRAP 跨流形链结构性不可用**：`rot_pick` 每光场独立取低能流形（`evolve_twofield.py:236-244`）→ 跨流形链的旋转系残差 −295.7 THz → RWA 完全失效（框架盲区，非精度问题）；
- 强光近共振时 AC/dressed 处理是近似（t39：STIRAP 中段 2.2e-2 为 ip4/hard 同源 RWA 误差）；
- 步长由 17 GHz 载波决定：1500 ns ≈ 4×10⁵ 步 × 22 维（`hard.py:637-638`）。

### 3.4 引擎选择与改道（唯一实现处）

`runspec.effective_method`（`runspec.py:328-340`）：**只有一条规则**——`method=='sambe' and 任一波是 ArbitraryWave` → `hard`，并写 warnings。`dynamic.method` 的合法值由 `protocol.CONFIG_SCHEMA['dynamic.method'].enum` 声明（`protocol.py:41`）。`docs/_history/research/auto路由方案-动态引擎选择.md` 的"auto 路由"**没有落进 core**——`runspec` 里没有 auto 分支，`build_run` 只读快照里的 `dynamic.method`。

## 4. 两体相互作用（V_dd / 交换 / vdW）

### 4.1 V_dd 矩阵

`static_pair.vdd_sparse(cache, single, R_um, θ_deg, φ_deg)`（`static_pair.py:203-238`）：

```
V[k,k2] = (1/R³)·Σ_qq' T_qq'(θ,φ)·⟨i2|d_q|i⟩·⟨j2|d_q'|j⟩,  k=(i,j), 基序 k=i·N+j
```

- 张量 `_vdd_tensor`（`static_pair.py:183-200`）：`T_qq' = e_qᵀ(1−3nnᵀ)e_q'`，`n=(sinθcosφ, sinθsinφ, cosθ)`；θ=0 退化为 `T_{+1,−1}=T_{−1,+1}=−1`、`T_00=−2`；
- 换算 `_DD_CONV = Hartree_Hz/1e6/(1e-6/A0)³` MHz·µm³/(a.u.)²（`static_pair.py:42`）；
- 单原子偶极 `_dipole_sparse`（`static_pair.py:154-180`）：`Δl=±1, |Δj|≤1`，`|d|>1e-12` 才存；
- 缓存 5 个 LRU（`_BASIS_CACHE=32`/`_DIPOLE_CACHE=64`/`_VDD_CACHE=64`/`_HAM_CACHE=32`/`_EIGEN_CACHE=32`，`static_pair.py:93-97`）；**返回一律给拷贝**（`build_system` 会原地改 `H[k,k]`，`static_pair.py:44-46`）——但 `vdd_sparse` 自身返回的是缓存**对象本身**（`static_pair.py:216-217`、`237`），调用方不得原地改。
- `runspec.vdd_matrix`（`runspec.py:416-437`）再包一层进程内 `_VDD_MEMO`（键 = 基组指纹 + round(R,9) + round(θ,9) + round(φ,9)，`runspec.py:426-427`；>8 条清空，`runspec.py:434-435`）。`states_fingerprint` 用 `state_key`（含能量）⇒ B 变则键变（`runspec.py:153-158`）。

### 4.2 交换耦合（一阶，∝1/R³）

`static_pair.exchange_coupling`（`static_pair.py:316-333`）：**直接查矩阵元，不对角化**——`⟨SP|V_dd|PS⟩`，默认 `ket_a=(60,0,0.5,0.5)`、`ket_b=(60,1,0.5,0.5)`（`static_pair.py:325-327`），返回 `float(np.real(V[k1,k2]))`（**取实部**，`static_pair.py:333`）。

### 4.3 vdW 位移（二阶，∝1/R⁶）

`static_pair.vdw_shift`（`static_pair.py:336-349`）：先 `pair_eigen` 对角化（`static_pair.py:275-300`），再取 `|ref⊗ref⟩` 上 overlap 最大的本征支，`shift = E_支 − 2·E_ref`。**二阶项不在 raw 对角里**，必须对角化后提取（`static_pair.py:12`）。

### 4.4 雷达图 / 交换对只在里德堡之间

`coupling_strength_map`（`static_pair.py:352-426`）：`|⟨tgt1⊗tgt2|V_dd|src1⊗src2⟩|`，`V_c=(1/R³)Σ_ab T_ab·d_a·d_b`。**任一态 `n < RYDBERG_N_MIN` → 返回全零 Z 且不报错**（`static_pair.py:411-414`）——交换对只在里德堡之间才有物理意义。

### 4.5 判据的依据（`PHASE_TOL` / `R_CRIT` / `PHASE_BUDGET` 当初为什么这么定）

**`PHASE_TOL = 1e-4` rad**（`coupling.py:320`，`tier='check'`）：V_dd 与微波对**共用**的弱耦合门，判据 `Θ = C·T·|V|²/max(|ΔE|,|V|) ≥ θ`（`coupling.static_phase_keep` `coupling.py:168-199`；`coupling.mw_pair_keep` `coupling.py:143-162`）。物理含义 = 该耦合在窗口内累积的二阶相位：共振 → `C·T·|V|`（Rabi 相位），远失谐 → `C·T·|V|²/Δ`（色散/vdW 相位）。**换掉旧的幅度阈值 `_VDD_MIN_FRAC=1e-4`**，因为幅度阈值随基组标度漂移，且管不住"|V| 大但远失谐"——34.6 GHz 双翻转 Förster 通道被误剔，是 hard↔mixed V_dd 结果差 1.1e-5 的根因（换判据后降到 4.3e-8，`docs/参数与判据决策史.md:19-38`）。取值不敏感的依据：两类耦合的 Θ 相差 3 个量级以上（共振 ~3.9 rad vs 双翻转 ~5e-4 rad），1e-4 属保守侧（保留 66~84 vs 50，多留弱耦合，不丢强耦合）。`|V|=|ΔE|=0` 的元素 Θ 记 0（丢弃）（`coupling.py:183`）。

**`R_CRIT = 0.0135`**（`coupling.py:19`，`tier='run'`）：`r=Ω/ω > 此值` 的**远强对从光子块剔除**，位移走 `far_sos` 注入（`evolve_mixed.classify_pairs` `evolve_mixed.py:53-59`）。**与 `RWA_TOL=1e-4` 刻意差 2 个量级**：`R_CRIT` 问"这个远强对能不能留在光子块里"（块截断），`RWA_TOL` 问"旋转波近似本身够不够准"（反旋转误差 ~(Ω/ω)²）——物理要求不同，不是历史漂移（`docs/参数与判据决策史.md:72-79`）。取值锚：M_max=2 的 r 判据 + t60 仲裁 ±18.23 ≡ M=4 锚（`docs/引擎参数总表.md:115`）。

**`PHASE_BUDGET`**（`coupling.py:21`，`tier='run'`，**默认 `None`**）：微波候选窗的**成本**侧，`ΔD_max = PHASE_BUDGET/(C·T)`（`coupling.mw_cap_mhz` `coupling.py:98-114`）。动机：旧 `MW_NRES_BW_MHZ=5e3` 固定窗与 T 无关——T 小则白付步数、T 大则误删慢项；**实测锚**：freeze 三光子梯子第三级 `Δ=7.079 GHz` 被 5 GHz 固定窗整条删掉 → 400 ns 演化布居零变化、**无任何报错**（`docs/参数与判据决策史.md:40-52`）。相预算的性质：最坏总步数 ≈ `值/0.5`，**与 T、态数无关**；标定 `t79 的 1e4 MHz 窗在 T=620 ns 等价（C·1e4·620=3.9e4）→ 取 4e4`（`docs/参数与判据决策史.md:54-66`）。
> ⚠ **代码现状与文档不一致**：`PHASE_BUDGET` 的默认值是 **`None`**（`coupling.py:21`），`mw_cap_mhz` 在 `b<=0 or b is None` 时**返回 `MW_MAX_MHZ`（=不做成本剔除）**（`coupling.py:108-112`）。所以"4e4 rad"只在你显式设 `solve.COST_BUDGET` 时生效；默认是"留全部真实耦合、可能很慢"。`docs/引擎参数总表.md:62` 已把这个迁移写进表里（"默认空＝不限"）。

**三者关系**：①②是同一族的**两个方向**（精度 vs 成本，都随 T 自适应）；③④是同一族的两个不同要求（`R_CRIT` 块截断 vs `RWA_TOL` 近似有效性）。V_dd 与微波对用**同一** Θ 判据是**刻意**的——"与基组标度、引擎、参考系无关 ⇒ 各引擎保留集自动一致"（`coupling.py:181-183`），`checks/mw_pair_keep_selfcheck.py` 守这条。

### 4.6 两体张量化

`tensor.py`（`k=i·N+j`，`_reduce_A/_reduce_B` 约化，`_pair_loss_vectors` 寿命向量）；`tensor_fields.py`（`lift_single_A` 全提升 / `lift_side_A` 分侧提升 / `_pair_groups` 给 `K2_w` 稀疏 N²×N²）。**两体初态**：`evolve_util.pair_psi0_vector`（`evolve_util.py:153-168`）——`psi0_pair` 优先，否则 `np.kron(a,b)`；`as_pair_vector` 按 `(n,l,j,m)` 逐分量解析（不是索引），跨 B/基组重排稳定（`evolve_util.py:119-150`）。

## 5. 耗散与场致损失

### 5.1 自发辐射（三档）

`dynamic.decay_index`：0 自动 / 1 禁用 / 2 自定义（`runspec.resolve_decays` `runspec.py:198-230`，非法值明确报错 `runspec.py:205-208`）。

- `decay(g, Γ, e)`：`e=None` → 丢失；`g==e` → 纯退相（`evolve_util.py:171-180`）。
- 真正的 Lindblad 主方程只在 `evolve_reference`（`evolve_reference.py:94-118`，BDF）与 `evolve_rwa`（`evolve_rwa.py:782`）里。

## 6. 多体 ED

**入口**：`dynamic.mode==2` → `runspec_mb.build_run_manybody`（`runspec_mb.py:134-206`）。

**模型卡**：`ManyBodyModel`（`model.py:16-131`）——任意点云 + 逐原子 2 能级 `(g,r)` + 项开关 `I1/I2/I3`（`model.py:13`）；`add_array` 只给 chain/square/ring 便利（`model.py:59-90`）；`Ω/δ/Γ` 是**运行级**量，不进标定键（`model.py:37-42`）。`template='potts3'` 明确未实现（`runspec_mb.py:150-152`）。

**装配**（`assemble.py`）：
- `geometry`（`assemble.py:36-44`）：两原子坐标 → `(R, θ, φ)`；
- `calibrate_pair`（`assemble.py:75-122`）：4 维对空间 `[|gg⟩,|gr⟩,|rg⟩,|rr⟩]`；**一阶** `d1 = conj(rmat[:,k_idx])`（标准序 `⟨p|V|q⟩`，**复数原样保留 (θ,φ) 相位，绝不取实部**，`assemble.py:13-18`、`93-94`）；**二阶** Löwdin downfolding `Σ_m ⟨p|V|m⟩⟨m|V|q⟩·½(1/(E_p−E_m)+1/(E_q−E_m))`（`assemble.py:96-120`），近简并中间态 `|E−E_m| < guard_mhz` **剔除并计数**（`assemble.py:107-109`）；
- 可观测量提取：`V = Δrr − Δgr − Δrg + Δgg`（nn 不可约组合）、`J = H4[1,2]`（`⟨r_i g_j|V|g_i r_j⟩`）、`A = H4[3,0]`（`⟨rr|V|gg⟩`），`raw_*` 全值保留供"被丢项最大幅值"报告（`assemble.py:179-198`）。

**维度与装配**：`dim = 2^N` 是**唯一主约束**。`build_H_sparse`（`assemble.py:223-288`）：

```
H = Σ_i [δ_i n_i + (Ω_i/2)σˣ_i − (i/2)Γ_i n_i] + Σ_{i<j} [V·n_i n_j + (J σ⁺_iσ⁻_j + A σ⁺_iσ⁺_j + h.c.)]
```

基序 `bit(s,i)=(s>>(n−1−i))&1`（原子 0 在左/MSB），bit=1 ↔ `|r⟩`；**每行 O(N) 非零** ⇒ 取代 2^N×2^N 稠密（N=16 稠密需 68 GB，`assemble.py:231`）。非厄米接缝 `-i·Γ×1e-3/(2·CONV)` 使布居恰按 `exp(−Γ×1e-3·t)` 衰减（`assemble.py:232-234`）。

**演化**（`engine_ed.evolve_manybody` `engine_ed.py:232-363`）三档：
1. `dim ≤ _MB_DENSE_MAX=4096`（`engine_ed.py:36`）**且厄米** → 稠密 `eigh` 全时刻向量化传播（`_propagate_dense` `engine_ed.py:158-180`）；总激发数守恒时（无驱动 + 无双激发 A，`_is_excitation_conserving` `engine_ed.py:138-147`）自动按激发数**扇区块对角化**，并**当场验证块对角性**，不满足即回退全空间（`engine_ed.py:161-165`）；
2. 否则 → 稀疏 `expm_multiply` **逐区间步进**（内存安全、支持非厄米；**`expm_multiply` 不接受 tol**，`engine_ed.py:13`、`191`）；

## 8. 已知缺陷与静默风险

> 排序按"危害 × 可达性"。**§8.1–§8.4 是我认为最该先修的**。

### 8.1 【实测·最高危】窄脉冲被 64 点探针判成"恒常包络"，两个引擎给出两种相反的错

**探针**：sambe 单体 `_env_all_constant(groups, T)`（`sambe.py:782-788`）与两体 `_pair_propagate` 内的同款判断（`sambe.py:1249-1256`）都用 `np.linspace(0.0, T, 64)`，判据 `np.ptp(v) > 1e-9`；ip4/Lindblad 用 `field_build.env_samples`（`field_build.py:28-32`，采样数 `_ENV_SAMPLES=64`，`field_build.py:22`）。

**后果（两条路，方向相反）**：
- **sambe**：判为"全常数"后走快路径 `hamiltonian_seg(0.5*T)`（`sambe.py:799-814`）——取**中点**包络值，若脉冲中心恰在中点就是**峰值** ⇒ 整窗按峰值 CW 算；
- **ip4**：`_evolve_rwa` 取 `env_samples(...)[0]` = **均值**（`evolve_rwa.py:382-397`）⇒ 窄脉冲均值 ≈ 0 ⇒ **场完全消失**；`_lindblad_eligible` 也据此返回 `True`（`evolve_rwa.py:586-587`）⇒ 用 `c=mean≈0` 去做自称"机器精度"的 `lindblad_eig`。

**实测（T=620 ns，高斯 σ=0.5 ns，中心 310 ns）**：
```
np.ptp(env(np.linspace(0,620,64))) = 9.31e-22        # < 1e-9 ⇒ 判为"恒常"
sambe：pops_end = [0.13551561, 0.86448468]  == 与 env≡1（CW 峰值）**逐位相同**
ip4  ：pops_end = [1.0, 5.0e-34]            == 与零场**逐位相同**（与 CW 不同）
```
**阈值（算术推导，非实测）**：64 点间距 `T/63`，最坏错位 `T/126`；要漏掉需 `σ ≲ T/800`（T=620 ns → σ ≲ 0.78 ns）。

**不中的引擎**：mixed 恒用 `_RHS_ENV_TAB_N=20001` 点表（`coupling.py:52`、`evolve_mixed.py:361`）；hard 用 `_TAB_N=2^17`（`hard.py:95`）⇒ 这两条路对此免疫。
**同族风险**：`_env_all_constant` 的 64 点也在 `_run_sambe` 里决定"是否一次对角化"，因此**只要判错就会静默改变算法**，而 `error_report['n_segments']=1` 看起来完全正常。

### 8.2 【实测】`evolve_mixed_pair` 的 `_BW_STATS` 仍跨运行累积

- 写入端无 else 分支地自增：`evolve_mixed.py:744-746`；

- **docstring 明确声称已修**（`evolve_mixed.py:758-760`："N2 修：模块级计数器必须每次运行独立——原来跨运行累积"）——**修复只对 `diag=True` 的序列成立**。

### 8.8 【实测】单体 mixed 的 `psi_amp` 契约与其它引擎不一致

## 10. 静态能力的 AI 可达性（2026-09-22 第二轮调研）

**结论一句话**：`src/core/protocol.py`（AI/mecha 的唯一领域面）**没有任何静态能级计算入口**。`__all__`（`protocol.py:20-25`）里与"静态"沾边的只有 `list_levels` / `preview` / `estimate`；静态页真正在用的那批函数（AC-Stark、能级行、谱线、两体静态）**全部只被 `src/ui/` 调用**（grep 实证：`ui/fields.py:591,636,698,735`、`ui/ui_single.py:119,540,546`、`ui/ui_radar.py:242`）。

### 10.2 缺口定界（要补什么、补在哪）

- **缺口不是"AI 少了几个工具"，而是"静态物理层没有协议面"**：`protocol.py` 是"引擎接受什么配置、怎么跑、能预估/预览什么"的唯一领域声明点（`protocol.py:2-9` 自述），而静态计算（不跑演化、只算量与谱）**从未被纳入这个面**。`runspec.py:9` 提到 `build_level_rows_direct` 恰恰是当初抽出 runspec 的**动因**——但只抽走了基组装配，静态行本身留在了 UI 里。
- **最小补法（按性价比）**：① `protocol` 加 `static_levels(cache, snap)` → 回 `{label, key, E_mhz, ac_shift_mhz, dc_shift_mhz, affected}`（复用 `build_level_rows_direct`，`static_atom.py:968`）——**这是用户最可能先要的**，且现成函数就能包；② 加 `static_spectrum(cache, snap)` → `spectrum_lines`（`static_atom.py:1120`）；③ 加 `static_pair(cache, snap)` → `{pair_eigen, vdw_shift, exchange_coupling}`（`static_pair.py:275/336/316`）；④ `preview` 里把 `amps` 一并回传（`protocol.py:527-530` 补一个键）。
- **反例（不要做）**：不要为此新增一套参数命名空间——AC 精度旋钮（`n_photon`/`sos_n_window`）现在是 ui 本地态（`ui/fields.py:70-71`），要暴露就得先决定它进不进 `solve.*`；**进 registry 会改变"静态页显示量不参与演化"的边界**（`static_atom.py:519-522`），需要产品决策。

### 11.2 不能算什么（能力边界）

1. **`tebd` 只是 stub**：`evolve_tebd_stub` 直接 raise（`engine_ed.py:370-378`），且 build 阶段就被 `resolve_solver` 拦住（`runspec_mb.py:128-130`）——所以它**永远不会被静默用到**（这点做对了）。

5. **`beams` 是占位**：`model.py:34` 自述"M0 只占位，不接线"，序列化往返有它（`model.py:108/121`），计算里没有。

10. **二阶 downfolding 的精度边界是 `n_window`**：伙伴态只有 `|Δn| ≤ n_window`（缺省 3，`assemble.py:143`、`schema_mb.py:46-48`）⇒ C6/vdW **不是精确值**，是截断值。

### 11.4 要成为"能给人用"还差什么（按优先级）

**P0（否则用户会得到错的或不一致的结论）**
1. 把 `template` 要么**接进 H**（ising↔xy 至少差一个耦合项约定），要么**从 schema 删掉**——现在是最坏形态：看着能选、实际无效。
2. `energy_window_mhz` 与 `seed` 同样二选一（接线或删键）；`seed` 若要保留，必须真的喂给 `add_array` 的 `default_rng`。
3. `drive_segments` 在 `session.set` 当场做结构校验（复用 `validate_atom_list` 的模式，`adapter.validate_custom` 加一条）。

**P1（可用性）**
4. 连续包络驱动（至少 gauss/square，与单/两体同名同参）——现在只有分段常数，做不了任何真实的脉冲实验。
5. `entropy_at_cut` 的越界从"静默 0"改为 `None` + 说明（观测量非致命是对的，但"0 熵"和"没算"必须可区分）。
6. `|m| ≤ j` 之类的物理合法性校验（现在是静默接受，到 `dme` 里才返回 0）。
7. 成本预估的实测标定（`cost_mb.py:4-7` 自述"量级估计，未经 cost.py 那样的逐点实测标定"）——`estimate_cost` 是用户决定"要不要跑"的唯一依据。

**P2（扩展）**
8. `tebd`/MPS 后端（n > 16 的唯一出路）。
9. `beams` 串扰标定（`model.py:34` 占位）。
10. 多体场致损耗 / 自发辐射的**逐态**语义（现在只有逐原子 γ）。
