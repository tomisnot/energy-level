# STIRAP 中段 2.2e-2 仲裁报告（t39）

> 2026-09-02 harddev 仲裁（只调查，未改 src）。判定 frozen（实验室系非 RWA）与 ip4（RWA）
> 谁对 + 差异来源。场景：STIRAP.json（3400ns/851 点，光1 713.28 THz 5S↔6P + 光2 295.72 THz
> 6P↔60S，B=300G，psi0=60S mJ=+0.5）。复现 npz：tempsimu/_t36_frozen_3400.npz / _t36_ip4_3400.npz。

## 1. 差异窗口定位

逐 400ns 段 max|Δpops|（frozen h=1 vs ip4，全程）：

| 窗口(ns) | max\|Δpops\| |
|---|---|
| 0-400 | 8.0e-4 |
| **800-1200** | **2.2e-2**（峰：光2 主脉冲区，center=1000 σ=400） |
| 1200-1600 | 1.3e-2 |
| 1600+ | <2.3e-3（收敛） |

**差异集中在光2（6P↔60S 光场）主脉冲区**，末态收敛（Δ≈9e-4）。差异最大态 = 60S（初态）。

## 2. frozen 收敛序列（自证可信）

800-1600ns 窗口（差异区）frozen h 序列：

| h(ns) | 窗末 60S | 相邻差 |
|---|---|---|
| 1.0 | 0.99729520 | |
| 0.5 | 0.99729498 | \|h1−h0.5\| = 1.5e-6 |
| 0.25 | 0.99729493 | \|h0.5−h0.25\| = **3.5e-7** |

**frozen 干净收敛（h=0.25 达 3.5e-7）→ frozen 是收敛参考**；h=1 的误差上界 ~1.5e-6，
远小于 2.2e-2 差异——2.2e-2 不是 frozen 数值误差。

## 3. ip4 敏感性

| 配置 | 1600ns 末 60S | 结论 |
|---|---|---|
| near_cutoff=50 MHz（原始 STIRAP 设计） | 1.000000（无耦合！） | STIRAP 实际失谐 ~1e3 MHz > 50 → 杀光耦合——原存档 nc=50 本身不工作 |
| near_cutoff=500 MHz | 0.995705 | ≡5000（**不敏感**） |
| near_cutoff=5000 MHz（当前默认） | 0.995706 | ≡500 |

→ **2.2e-2 差异不来自 near_cutoff 分流截断**（500 与 5000 结果一致）。
ip4 参考分配核查：光1 对旋转系残差 −939 MHz、光2 对 +1358 MHz（均 MHz 失谐——RWA 有效，
**参考非污染源**，t39 早期符号误判已修正；60S 的 ref=+w1+w2 在本约定下对 RWA 对无害）。

## 4. 结论

- **frozen 正确**（非 RWA 收敛序列 3.5e-7 自证 + 与 hard 620ns 基线一致 1.6e-7 的历史交叉）；
- **ip4 的 2.2e-2 中段差异 = ip4 自身的近似误差**（光2 强脉冲区：RWA 反旋项 + 静态 AC 注入
  31.5 MHz 与 frozen 的 dressed 自然涌现差异），集中在光2 主脉冲、末态收敛；
- 差异来源排除：near_cutoff 分流（不敏感）、参考链式（RWA 对在 MHz 失谐）；
- **建议修复（记录，未改）**：ip4 的 AC 注入为静态峰值（build_fields 注入恒定 2nd-order 位移），
  强脉冲上升/下降沿期间与真实瞬时 dressed 位移偏差大——可改 env 依赖的瞬时 AC（工程改动，另立任务）；
  RWA 反旋项在 Ω/Δ 非极小时的误差为 ip4 结构固有（强驱动场景建议 frozen/混合引擎）。
