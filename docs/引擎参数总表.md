# 引擎参数总表

> 三个主力引擎（sambe / hard / mixed）中所有硬编码参数的集中登记。
> 改任何一项前先看"依据"列——多数参数有实测锚，盲改会破坏已验收的数值基线。
>
> 单位约定：频率 MHz；时间 ns；`_CONV = 2π×1e-3`（rad/ns per MHz）。

## 1. 微波/光场分割

| 参数 | 值 | 位置 | 含义 | 依据 |
|---|---|---|---|---|
| `MW_MAX_MHZ` | 1e5 | evolve_twofield.py:41 | 载频 ≤ 100 GHz 视为微波，> 视为光场（两场引擎） | 里德堡跃迁 ~10 GHz 量级 vs 光学 ~3e8 MHz，中间隔着 4 个数量级 |
| `adaptive_split_threshold` | 函数 | evolve_twofield.py:108 | 能级间隙 log 比几何中点，clamp [1e4,1e6]——自适应替代固定 1e5 | 场依赖（间隙分布因体系而异） |
| 行内 `1e5` | 1e5 | evolve_mixed.py:199-200, sambe.py 多处 | mixed/sambe 的 `f_opt`/`f_mw` 分流（**未命名，同 MW_MAX_MHZ**） | 同上；待统一引用 |

> ⚠ `1e5` 在 sambe/evolve_mixed 中以行内魔法数出现 ≥8 处，应统一引用 `MW_MAX_MHZ`。

## 6. V_dd 处理

| 参数 | 值 | 位置 | 含义 | 依据 |
|---|---|---|---|---|
| `POP_PHASE_TOL` | 1e-4 (rad) | params.py | **静态耦合（V_dd）统一丢弃判据**（t78）：Θ=C·T·\|V\|²/max(\|ΔE\|,\|V\|) ≥ θ_tol 保留 | 二阶微扰累积相位；共振→C·T·\|V\|，远失谐→C·T·\|V\|²/Δ。与基组标度/引擎无关，hard 与 mixed 共用 `coupling.static_phase_keep` |
| `_VDD_RWA_TOL_MHZ` | 1.0 | evolve_twofield.py | 两场引擎：V_dd **旋转系有效性**判据（\|ΔE_rot−ΔE_lab\|≤1 MHz） | 职责≠效应大小（管"该元素在本征旋转系里相位是否成立"）；实测与 Θ 结论一致（这类元素同时是 THz 远失谐） |
| ~~`_VDD_MIN_FRAC`~~ | ~~1e-4~~ | — | **t78 已退役**：换成 `POP_PHASE_TOL`。幅度阈值随基组标度漂移，且管不住"\|V\| 大但远失谐"的元素（如 34.6 GHz 双翻转 Förster 通道——它被误剔，是 hard↔mixed 差 1e-5 的根因） | |

## 重复定义索引

以下参数存在 **≥2 个独立名字**（数值相同/相近），合并时需逐个甄别物理含义：

| 数值 | 名字 | 分布 |
|---|---|---|
| 1e5 | `MW_MAX_MHZ` + 行内 `1e5` | evolve_twofield + evolve_mixed + sambe（≥8 处行内） |
| 5e3 | `MW_NRES_BW_MHZ` ×2 + `_TF_MW_NRES_BW_MHZ` | evolve_mixed + evolve_twofield |
| 2e4 | `BW_OPT` + `_M_ANALYTIC_BW_MHZ` | evolve_mixed + sambe（物理含义不同！） |
| 0.0135 | `R_CRIT` | evolve_mixed（单源 ✓，t74 已并入） |
| 2200 | `_DENSE_MAX` | sambe（单源 ✓） |
| 20001 | `n_tab=20001` | coupling + evolve_mixed |
