# t66 认知固化：单/两体 RHS 语义不对称——收敛发现的潜在物理 bug

> 2026-09-04 船长整理。统一工程（t63/t66）收敛时发现的深层语义问题——分开写
> 单/两体导致 RHS 累加约定漂移，潜伏数月未被交叉测试捕获。

## 1. 语义不对称（代码事实，b1ac76a）

| | pairs | RHS 累加 | 每方向有效耦合 |
|---|---|---|---|
| 单原子 `_rhs_phi` | **全矩阵**（Kcw 全对，含反向）| **单侧**（`tot[a] += v·ph·phi[b]`）| **1×** ✓（用例 2/3/5 验证）|
| 两体 `_rhs_mixed_pair`（旧）| 光场全矩阵 / 微波半对 | **双侧**（`tot[a]+tot[b]` 都加）| **光场 2× ⚠️** |

**根因**：单原子靠"全矩阵对 + 单侧累加"隐含 Hermitian（反向对天然补 b 侧）；
两体写成"双侧累加"后，若配全矩阵对 → 每方向被加两次 → 2× 加倍。

## 2. 为什么一直没被发现（formal ② 假通过）

formal check ②（两体直积 vs 单原子）的光场是**远对 AC 化剔除**（无光场对参与）——
直积只测微波（两体微波是半对 + 双侧 = 1× ✓ 与单原子一致）→ 早期 8e-16 通过。

t62f 后基线出现 3e-2（_t66_diff_trace.py）——船长深挖（_t66_env_row_check.py）：
**根因 = 两体 AC 时变对角 env 行错位**——光场 AC 化剔除后 pairs 无光场对，
ac_env_row fallback 到微波 env（高斯）→ AC 位移按微波高斯门控而非光场 one() →
微波早期不被阻断（两体 |60P,60S⟩ 6.7% vs 单原子 0.5%）。**t67 修复（独立 AC
env 表）后 formal ② 差 1.6e-15**。

（早期"cos⁴ 直积固有差异"归因错误——见 t62f 认知固化 t67 修正；RHS 语义
不对称是真实存在的代码约定漂移，但 formal ② 的 3e-2 主因是 env 行错位 bug。）

## 3. 收敛方案定论

**两体复用单原子 `_rhs_phi`（单侧累加 + 全矩阵对）**——隐含 Hermitian 与单原子
逐位一致（含微波对全矩阵化）。V_dd 对保留同扇区（全矩阵化时对角排除——norm
1.7e-7 已验证）。

## 4. 教训（统一必要性的铁证）

"每个算法单/两体各写一遍"不仅重复——**还会让核心语义（RHS 累加约定）漂移**：
单侧 vs 双侧是物理等价的两种写法，分开写必然不一致，且交叉测试因 AC 化剔除
光场对而长期漏检。统一后一份 `_rhs_phi` + tensor 提升，此类问题不可能再发生。
