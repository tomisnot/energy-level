# Energy Level 代码总览（通读笔记）

> 目的：把整个仓库的代码结构、数据流、每个引擎/面板/接线各自负责什么，压缩成一份可查的地图。
> 与 `用户手册.md`（怎么用）、`引擎能力边界.md`（选哪条路）、`多体接口与维护约定.md`（契约细节）互补；
> 冲突时以代码 + `el_query_params` 的实际返回为准。

## 0. 一句话

EL 是 Rb-87 里德堡原子的仿真软件：**静态能级与谱线 → 单体/两体含时演化 → N 原子阵列多体（ED/MPS/DMRG/KPM/QMC/PEPS/…）**，
外层用 mecha v2 提供**同一道写入门 + 一本操作史**，向上同时暴露 **PyQt5 桌面 GUI**、**15 个 MCP 工具**、**只读运行卡片网页**与**并行扫描**。

## 2. 进程、端口、数据根

- **唯一权威**：由 mecha supervisor 拉起的 `python app_entry.py --mcp`；页面与 GUI 都只是这个进程的视图或同进程窗口。
- **发现文件**（项目根，动态端口，每次重启会变）：`.mcp-port`、`.monitor-port`（只读监控）、`.run-monitor-port`（运行卡片）、`.control-port`（人工控制端点）。
- **数据根**：`resolve_data_root` 固定顺序 `显式参数 > MECHA_SOFTWARE_ROOT（框架声明） > RE0_V2_DATA_ROOT（EL 内部） > el_root`，两者冲突会打印警告。
- **持久化**：`<data>/.mecha-v2/journal.jsonl`（配置史）、`artifacts/`（pickle 结果）、`run-cards/`（卡片 meta/viz）、`calib/`（大模型输入）。
- **写权**：Gate/Authority 四档 `locked/human/ai/open`；AI 通道不能自己切模式；切换走控制端点的 `set_write_authority`，只读自省走 `read_write_authority`。

`app_entry.run_mcp` 的流程：建桥（V2Bridge.for_shared）→ 起 MCP + 监控 + 运行卡片 → 按 `MECHA_INITIAL_MODE` 设初始写权 → 起控制端点 →（可选）同进程开窗 → 主循环里把“开窗请求”搬回 Qt 主线程执行。

## 3. 端到端数据流

```
GUI 控件 / AI 工具
   │  set_config / set_drive / build_calib（经 Gate 校验 + 留痕）
   ▼
Gate 快照（扁平键：groups.* / field.* / dynamic.* / manybody.* / solve.*）
   │  ops.prepare 或 ElEngine.run：build_run(snapshot, cache)
   ▼
RunSpec（纯容器，可 pickle）
   ├─ 单体/两体：states + fields(es) + psi0 + decays + vdd_matrix + engine_kwargs
   ├─ 多体含时：calib + Om/delta/gamma + psi0 + t + plan + segments
   └─ 多体平衡态：calib + want(gs/thermal/dos/spectrum) + backend + betas/source
   │  evolve_run（唯一分派点）
   ▼
引擎结果 dict（t/pops/states/loss/error_report/diag/observables/data_schema）
   │  result_summary（data_schema.summary 策略） + artifact（完整数组，pickle）
   ▼
GUI 画布 / MCP 回执 / 运行卡片（RunMonitor 投影）
```

关键约定：

- **配置是扁平字符串键**（含点号），没有嵌套配置树；`manybody.calib` 是唯一例外的大字典值。
- **RunSpec 只搬运数值**：ARC 标定必须在建 cache 的线程完成，工作线程不再碰 ARC。
- **失败不静默**：缺键、非法枚举、未知 method、不支持的选项、空演化、被成本窗剔除的耦合……都会报错或写进 `warnings`。
- **结果语义由 `data_schema` 描述**（量、轴、单位、缺失值、summary 策略、items 标签），前端按轴/单位绘图而不是按求解器分支。
- **有效驱动只有一处**：`runtime.describe_drive` 同时供 MCP preview、运行卡片和驱动曲线使用；分段/静态不在消费者里各算一份。

## 4. 契约层

### 4.1 `param.py`：就地参数声明

`Param(default, desc, unit, lo, hi, log, tier)` 返回**透明子类**（int/float/tuple 子类），读点无需改；
默认值 `None` 时返回 `_ParamObj`，需 `.value`。`protocol.engine_params()` 用 AST 扫各模块顶层 `NAME = Param(...)` 生成只读参数表——
**表是扫出来的，不是登记进去的**。tier：`run/internal/physics/check`。

### 4.2 `protocol.py`：领域 schema 与查询

- `CONFIG_SCHEMA`：`groups.list`、`field.*`、`dynamic.*`（含单体/两体几何与波形）、`static.columns`。
- 与 `manybody/schema_mb.CONFIG_SCHEMA_MB` 合并成 `config_schema()`；`settable_keys()` = config + solve，**不含 engine.\***。
- `SOLVE_KWARG`（runspec 里）是 solve.* → 引擎形参的**唯一映射**：`MAX_STEP/MAX_STEP_HARD/PER_FREQ_M/FROZEN_H_NS/COST_BUDGET`。
- 查询：`estimate`（成本粗估）、`preview`（驱动了哪些跃迁/基组够不够）、`list_levels`（态 + 身份键）、
  `static_spectrum / static_ac_sweep / static_pair`（静态查询，大结果做成 numpy 数组以便体积闸无损转指针）。
- `validate_wave_list` / `validate_calib` 把“结构写错”提前到写门当场报错。

### 4.3 `runspec.py`：快照 → RunSpec → 引擎

- `_ENGINE_TABLE`：`(method, nbody) → 模块.函数`，是**唯一分派表**；`engine_fn()` 惰性 import。
  单体/两体：`mixed/sambe/hard`；多体：所有后端名（来自 `manybody/backends.py`）+ `gs/thermal/dos/spectrum`。
- 基组：`build_states` 投影 `static_atom.base_sublevels`（静态页与动态页同源）；逐子能级裁剪 `ms`/`Fs`。
- 初态：`resolve_psi` 身份键 → 索引，**绝不静默回落 0 号态**；两体还有 `pair_sup` 纠缠初态。
- 衰变：0 自动（ARC 寿命）/1 禁用/2 自定义；两体只支持“落点=丢失”。
- 引擎参数：`god_kwargs_from_params` 只取 solve.*，再按**引擎函数签名**过滤（`_filter_kw`），丢掉的写进 warnings。
- `check_run`：空演化、时间网格、多体原子数、`field_loss` 只在 mixed 单体生效等运行前检查。
- `evolve_run`：唯一的 method×n_body 分派点；GUI、MCP、扫描 runner 都走它。

## 5. 静态物理（`static_atom.py` / `static_pair.py`）

### 5.1 能级与超精细

- 里德堡态（n ≥ `RYDBERG_N_MIN=20`）：只保留 fine-structure 的 m_J 子能级，能量 = ARC 绑定能 + `g_J μ_B B m_J`。
- 低激发态：在 `|m_J, m_I>` 基下按 m_F 分块对角化 `A I·J + B Q + μ_B B(g_J J_z + g_I I_z)`；
  F 标号用**绝热/双射指派**（Breit–Rabi 惯例），深度混合处 F 只是零场延拓标记，能量与 m_J 振幅仍精确。
- 统一实现 `base_sublevels`：静态页、动态基组、多体页 g/r 都从这里取，保证“两页同基准、同字”。

### 5.2 AC-Stark（唯一后端 = direct Floquet）

- 基组 = 已添加组 + 每组偶极伙伴 `|Δn| ≤ sos_n_window`（默认 3）；构造 `H_F = (H0 + nħω)⊗|n⟩⟨n| + V/2 ⊗ 相邻光子块`。
- `n_photon` 默认 4（9 块）；空间上限 `AC_NM_MAX=12000`（约 2–3 GiB），超了入口报错。
- 耦合 `C_unit` 与频率/强度无关，可缓存；结果再按 (基组, B, 偏振, window, n_photon, 频率, 强度) 缓存。
- 实对称时走 float64 eigh（快 ~7×）；有复相位时回退复数。
- 归属 `|⟨n=0|本征态⟩|²` 最大者；共振 50/50 劈裂取离裸能最近的分支。

### 5.3 DC-Stark 与谱线

- DC：二阶 SOS，遍历所有偶极伙伴（已添加组 + `dipole_partners`）与 q∈{−1,0,1} 的吸收/发射两个方向；
  超精细态按 `|amps[mJ]|²` 加权（不能拿 m_F 当 m_J，否则恒 0）。
- 谱线：子能级间所有偶极允许跃迁，强度用爱因斯坦 A = `ω³|⟨a|d_q|b⟩|²/(3πε₀ħc³)`；
  偏振按球基复系数加权；静态页把 off/on 两条谱镜像画在同一 x 轴上。

### 5.4 两体静态

- `vdd_sparse`：`V = (1/R³) Σ T_qq' D_q⊗D_q'`，kron 稀疏；几何 `(R,θ,φ)` 与周期最小像。
- `pair_eigen`：`H_pair = diag(E1+E2) + V_dd` 稠密 eigh（维度闸 `PAIR_EIGEN_MAX_DIM=3000`，内存 ∝ N⁴）。
- `exchange_coupling`：一阶 `⟨SP|V|PS⟩`；`vdw_shift`：对角化后从 `|ref⊗ref⟩` 最大 overlap 支提取。
- `coupling_strength_map`：固定 φ 扫 R×θ 的 `|V_c|`；非里德堡对返回全零**并带 note**。
- 多体标定 `assemble.calibrate_pair` 复用同一套 V_dd/偶极，把 4 维块 + Löwdin 二阶折进去。

## 6. 单体/两体含时引擎

| method | 模块 | 物理/数值 | 关键边界 |
|---|---|---|---|
| `mixed`（GUI 默认） | `evolve_mixed.py` | 光场 Sambe 光子块（免 RWA）+ 微波/V_dd 当场，φ-帧单 DOP853 | 任意波形微波支持；无光场时 P=1 退化为实验室系 |
| `sambe` | `sambe.py` | 实验室系无 RWA/旋转系，多载频光子块，冻结中点指数 + Duhamel 缺陷 + Richardson | 扩展维 >2200 走稀疏 expm_multiply（如实标记“无误差控制”） |
| `hard` | `hard.py` | 光场旋转系 RWA + 微波 cos 硬积分（零微波近似），numba DOP853 | 任意时域驱动；椭圆偏不支持（按 π 告警） |
| `two_field`（脚本/研究） | `evolve_twofield.py` | 光场旋转系 + 微波-only 光子块（M≥2，多光子显式） | 拍频光场明确拒绝；两体变体有 V_dd 旋转系筛选 |
| `reference` | `evolve_reference.py` | 实验室系 H0 相互作用绘景 + DOP853；含耗散转密度矩阵 BDF | 全库“第一性原理权威锚”，慢 |
| `ip4`/`lindblad` | `evolve_rwa.py` | 级联 RWA + RK4 / Lindblad；全常数包络可一次对角化 | GUI 不暴露；判据/脚本用 |

### 6.1 公共场与判据

- `build_fields_exact`：每条波一个全偶极复耦合矩阵，Rabi 用 `Ω/2π` 周频；椭圆偏走三球基系数相干叠加。
- `build_two_field`：光场按近共振对做旋转系（0.5 因子），微波按“成本窗 + 累积相位 Θ”筛对；方波沿收集为段边界。
- `coupling.py`：
  - `mw_cap_mhz(T) = PHASE_BUDGET/(C·T)`（默认 `PHASE_BUDGET=None` = 不限制，只留绝对上界 `MW_MAX_MHZ=1e5`）。
  - `mw_pair_keep` / `static_phase_keep`：`Θ = C·T·Ω²/max(Δ,Ω) ≥ PHASE_TOL=1e-4`，强场保留远失谐多光子通道，THz 对自动剔除。
  - `rhs_phi_pairs`：mixed 单/两体共用内核（a<b 单侧打包 + 厄米补齐；env/相位查表；AC/损耗对角块）。
- 窄脉冲保护：`field_build.env_span/env_is_const/env_feature_ns/feature_max_step`。
  包络是否恒常由**解析 span**决定（不再用 64 点采样），深混叠区自动给每步硬上限，修复“窄脉冲被整段跨过/结果恒零”。
- 场致损耗 `field_loss.py`：L2 散射 `(Γ/2)s/(1+s)`、L3 阱逃逸（budget/Arrhenius）、L4 光电离；
  `build_field_loss` 自动按远失谐对装配，双计规则 + 近共振剔除；**只有单体 mixed 消费**，其它路径 `check_run` 明确报出来。

### 6.2 两体张量与耗散

- `tensor.py`：`|i⟩⊗|j⟩`，k=i·N+j；A/B 约化、寿命丢失向量；两体只支持“落点=丢失”，显式落点/纯退相拒绝。
- 两体结果：`pops` 为 N²，`pops_A/B` 为约化；`loss_A/B` 为各自累计丢失；`states_2d` 带 ket_i/ket_j。

## 7. 多体：模型、装配、基、初态、Plan

### 7.1 唯一模型货币：`manybody.calib`

```jsonc
{"atoms":[{"id":0,"pos":[x,y,z],"Omega_mhz":0,"Omega_phase_rad":0,"delta_mhz":0,"gamma_mhz":0}],
 "pairs":[{"i":0,"j":1,"V":0,"J":1.05,"A":0}]}
```

- 位置 µm、能量/耦合 MHz、时间 ns；`J/A` 可为复（Peierls 相位），`V` 只取实部。
- **没有 terms 输入**：活跃通道由数值推导（V≠0→I1，J≠0→I2，A≠0→I3）；写 `terms` 与数值不一致会报错。
- `manybody.build` 是构造器入参（`{source:"file"|"arc", …}`），由 `el_build_calib` 转成 calib；
  回执 `build_receipt` 由 calib 现算（指纹/对数/Σ|J|/尾界/丢对/剔除），不存副本。
- 契约：`validate_calib`、`calib_fingerprint`、`calib_summary`、`calib_receipt`；文件只允许读 `<EL>/.mecha-v2/calib/`（`$EL_CALIB_DIR` 可改）。

### 7.2 装配

- `assemble.calibrate_pair`：4 维块 `[gg,gr,rg,rr]`，一阶 V_dd 投影 + 二阶 Löwdin `Σ V_pm V_mq/(E−E_m)`；
  近简并中间态（`|E−E_m| < guard_mhz`）剔除并计数；θ,φ 的相位**全程复数保留**（协变律）。
- `build_H_sparse`：2^N CSR；`H = Σδ n + (Ω/2)σˣ − iΓn/2 + Σ[V n n + Jσ⁺σ⁻ + Aσ⁺σ⁺ + h.c.]`；
  MSB 位序（原子 0 最高位，bit=1=|r⟩）；支持任意 `basis_indices`（投影基）。
- `channels.py`：XOR 翻转/对角的**唯一语义**；`build_H_sparse`、CPU `ChannelKernel`、
  GPU 通道表都消费它，避免四份符号/掩码实现漂移。
- `calib_build`/`runspec_mb.resolve_model`：`manybody.distance_cutoff_um` 按显式 pos 欧氏距离只保留 R≤cutoff 的原子对（不做周期最小像），丢弃项进 `calib.dropped`/warnings（近似，需自查）。
- `ensemble.py`：`run_ensemble(params, sampler, ...)` 的抽样-汇总驱动；只调用
  `protocol.build_run/evolve_run`，不新增求解器；区分无条件/后选统计。
- `idmrg.py`：通用 `cell + terms` 的无限 MPS/iDMRG（TeNPy `bc_MPS="infinite"`）；
  支持一个平移方向、单胞 ≥2、局部维数 2；`from_rydberg_cell` 只是构造器。
  `charge_sector` 按整项净 ΔN 判据（`P_i M_j` 放行，单站点 P/M 或 `P_i P_j` 拒绝）；
  `manybody.pauli_strings` 在 cell 内求值，X/Y 展开成 P/M（固定扇区只留净 ΔN=0），可算手性三体串。
- `hamiltonian_plan`：把 `constraint`（none/blockade/pxp，full/project）翻成受限基（独立集枚举，带 `max_states` 上限），
  `compile_sparse` 只消费 Plan，不改 Plan。

### 7.3 初态

支持：`null`（全 g）、产物态索引、`"grg"` 模式串、`"ground"`、`["sup",…]`、
`{kind:"product", amplitudes}`、`{kind:"mps", backend:"tenpy"}`、`{kind:"ground_of", calib}`（淬火）、
`{kind:"permutation_sector", base, permutation, sign}`（对合置换 ± 扇区）。

- 制备态在 RunSpec 的 `quench` 字段留元数据（`prepared_by/projection_weight/sector_overlap/base_overlap`）。
- 置换扇区投影**只约束初态**；DMRG 不保证留在扇区（已知能力缺口，必须同时看末态 ⟨P⟩ 与 `solver_converged`）。

## 8. 多体含时后端

`manybody.solver` 枚举：`auto/ed/tebd/tebd-gpu/swap-tebd-gpu/tdvp-mpo/tdvp-dense/tdvp/tdvp-single/tdvp-adaptive/tdvp-trajectories/classical-spin/peps-real-time`。

- **ED（`engine_ed.py`）**：`build_H_sparse` → 稠密 eigh 全时刻向量化（dim ≤ `_MB_DENSE_MAX=4096`，厄米）或稀疏 `expm_multiply` 逐区间；
  总激发数守恒且无驱动/A 时按扇区块对角化并**当场校验**块对角；非厄米 gamma 走对角 −iΓ/2；
  联合 `pops` 只在 dim ≤ `_MB_FULLPOP_MAX=65536` 物化，否则退化为逐原子边缘并在 `error_report` 说明。
  每时刻流式归约：`pops_atom/S/corr/观测/loop/pauli`。
- **CPU MPS（`engine_mps.py`）**：TeNPy TEBD / 两站点 TDVP / 单站点 / 自适应；任意 MPO 长程用 TDVP；
  分段驱动在跳变处细分（`drive_interp='midpoint'` 取段中点）；引擎与环境跨内部步复用；测量前对副本做 canonical；
  `charge_sector` 用 Sz 守恒；`max_step_ns` 是内部步长（ED 不需要）。
- **稠密 CPU TDVP（`tdvp_dense.py`）**：numpy + BLAS 的两站点 TDVP；位置依赖 MPO 键、
  显式 canonical form、Taylor/ Lanczos 局部传播；有限开链/乘积初态/显式 `mps_order`；
  支持 segments（分段重建 onsite MPO/环境；`drive_interp='midpoint'` 取段中点）和 Pauli 串（有限 MPS transfer）；
  支持原生 MPS `return_state`（`backend='tdvp-dense'`，可继续喂给同一后端）；拒绝 charge/corr。作为 `manybody.solver=tdvp-dense` 显式启用，
  默认仍走 TeNPy `tdvp`。环境变量 `EL_TDVP_BLAS_THREADS` 可限制 BLAS 线程（opt-in）。
- **GPU MPS（`engine_mps_gpu.py` + `mps_torch.py`）**：torch 全驻留；`tebd` 只接受 MPS 顺序最近邻，`swap-tebd` 用相邻 SWAP 路由任意键；
  每个 SVD 是 Schmidt 截断，丢弃权重含路由 SWAP；显存预算保守估计。
- **PEPS（`engine_peps.py`）**：矩形网格、最近邻键，simple-update；`opt_einsum` 收缩路径按中间张量预算拒绝；非网格/长程明确拒绝。
- **量子轨迹（`engine_trajectories.py`）**：两站点 TDVP + 局域 collapse 通道；无跳跃/跳跃一阶分裂；输出轨迹平均 + MC 标准误 + 跳跃数 + 存活权重。
- **经典自旋（`classical_spin.py`）**：单位 Bloch 向量 + LLG 阻尼；因子化 `<σ⁺ᵢσ⁻ⱼ>≈<σ⁺ᵢ><σ⁻ⱼ>`；计算量随键数线性。
- 所有实时后端共享**公共观测键**：`sx/sy/sz/sp/sm/phase`、`link_pairs/link_corr`、`loops/loop_phase(_series)/loop_winding(_series)`。

## 9. 多体平衡态与谱

- `eq_engine.build_equilibrium`：快照 → 平衡态 RunSpec（无时间轴）；按 `eq_backend` 路由。
- 后端：`ed`、`gpu-batch`（批量稠密本征）、`gpu-lanczos`（CUDA 矩阵自由块 Krylov，带 Ritz 残差认证）、
  `lanczos`、`kpm`/`gpu-kpm`（Chebyshev + Hutchinson 随机迹）、`dmrg`、`free-fermion`、`qmc`（SSE）。
- `eq_route.solve_equilibrium` 是编排入口：
  - `gs`：ED/Lanczos/DMRG/QMC/free-fermion/GPU；小维返回 `evals/gap/vec`，2^N ≤ 2^18 时附 `corr`。
  - `thermal`：精确谱分解（`ed`）或 KPM；betas 单位 1/MHz。
  - `dos`：KPM（exact 时谱分解）；输出 `energies/rho`。
  - `spectrum`：源态 Lanczos → 未展宽求积 + 洛伦兹展宽；源 `vector/diagonal/sparse/full_sparse/site_weights`；
    `Σ weights = ‖φ‖²`，`integral_ratio` 是窗内积分诊断。
  - `ramp`：warm-start 逐点基态（论文协议放模型层）。
  - `sector`/`charge_sector`：组合基 C(N,k)，不先建全空间；非守恒 H 抽样校验后拒绝。
- `sector_scan.scan_ground_sectors`：逐 k 调叶子求解器，返回最低 E0、每扇区残差/收敛/耗时；总基 = 2^N。
- KPM：`_bounds` 用 eigsh 定谱界，`chebinterpolate` 得系数，Jackson 核抑 Gibbs；热力学与 DOS 同一套矩。
- QMC：固定 operator string 的 SSE，对角插入/移除 + 可逆配对更新；局部 ± gauge 检查 stoquastic，复相位/不可消负号明确报 sign problem；
  输出统计误差与自相关时间（`F` 为 NaN，SSE 不直接给 lnZ）。

## 10. DMRG / MPS 与诊断

- `dmrg.py`：
  - `cylinder_order`：按 y 分行、列优先、腿最快；任意腿数、开边界。
  - `terms_from_calib`：把 calib 翻成 `onsite(δ,Ω/2)` + `couplings(coeff,a,opA,b,opB)`，按 MPS 下标归一，
    交换整条 `(算符,格点)` 对（复 J/A 不能只换下标）。
  - `cluster_model`：自写 autoMPO —— `Chain(L=n)` + 逐位数组 + 同 (opA,opB,程) 的 strength 数组；
    避免“N 格点单胞”触发 TeNPy `max_N_sites_per_ring`。
  - `dmrg_run`：TwoSiteDMRG + mixer；可取消；测量前 canonical 副本；返回 `E0/chi/S_mid/truncerr/error_report`。
  - `dmrg_cluster`：任意点云；`charge_sector` 用 Sz；`mps_dtype`；`mps_diagnostics`（variance/permutation/corr）；
    `pauli_strings` 展开成局域算符之积（簇模型注册的 SZ/P/M），逐项 `expectation_value_term`；不用 `get_rho_segment`（轴序随 segment 变）。
- `mps_analysis.py`：`mpo_sum_variance` 用所有交叉项精确算 `||(H−⟨H⟩)ψ||²`；`permutation_expectation` 用分块 transfer；
  工作区预算按电荷块估计，不够就拒绝（不填零）。
- `mps_symmetry.py`：`apply_site_permutation`（无截断相邻 SWAP）与 `project_permutation_sector`（(I±U)/2，报告权重/压缩误差/实际泄漏）。
- `state.py`：MPS 状态校验、HDF5 checkpoint；`mps_dtype.py`：auto/real/complex 无损策略。
- `results.py`：`describe_result` 生成 `data_schema.version=1`（quantity/axes/unit/alias/missing_values），所有后端共用；`summary` 声明紧凑摘要策略（scalar/top/final/head/list/first_last），`items` 声明二维逐项曲线的标签来源，`summarize_result` 只执行策略、不写量名分支。

## 18. 读代码总结出的关键不变量

1. **一个入口、一条分派**：所有演化都经 `runspec.evolve_run`；GUI/MCP/扫描共用 `build_run` 与引擎函数。
2. **配置只有一份真值**：Gate 快照 + journal；控件/存档/扫描都从它派生，写必过 Gate。
3. **ARC 线程亲和**：标定/建基组/寿命在主线程（或专属引擎线程），工作线程只做纯数值。
4. **不静默**：缺键、未知枚举、无驱动、场致损耗不适用、成本窗剔除、稀疏路径无误差控制、扇区守不住……都要报错或写 warning。
5. **同基准**：静态页、动态基组、多体 g/r 都来自 `base_sublevels`；结果轴/单位来自 `data_schema`。
6. **大数组不进回执**：摘要只给标量与少量数组，完整数据走 artifact；卡片有明确预算。
7. **门控与留痕**：写权四档、AI 不能自解锁、actor/reason/call_id 进史；控制端点只给人。

## 19. 当前已知边界（非改动项）

1. **多体 GUI/存档与新的 calib 契约未完全同步**：`ui_manybody.py` 仍绑定 `manybody.atoms`、`manybody.second_order`、
   `manybody.n_window`、`manybody.guard_mhz`、`manybody.r_cut_um`，而 `schema_mb` 已把这些键删除、只认 `manybody.calib`。
   结果是：多体页“添加原子/改标定旋钮”会走 Gate 被 `UnknownKey` 拒绝（Qt 槽内异常风险）；`save_state/多体-*.json` 这些
   旧存档因含 `manybody.atoms` 会在 `set_batch` 原子写时整包被拒。产品路径应先用 `build_calib` 生成 `manybody.calib`。
2. **`waveforms.FileEnv` 有两个 `__repr__`**：后一个引用不存在的 `self.start_ns`，一旦 `repr()` 会 `AttributeError`
   （不影响演化与序列化）。
3. **用户手册列出的 reference/RWA/two-field 在 GUI 中不可选**：GUI 方法下拉只有 `sambe/hard/mixed`；reference 是内部权威锚，
   RWA/ip4 是遗留/判据路径，two-field 走脚本或两体 meta。
4. **`manybody_runspec.resolve_model` 有一行不可达的 `return calib, model, ...`**（旧 ARC 路的残骸，无害）。
5. **默认 `PHASE_BUDGET=None`**：微波候选窗默认只受 `MW_MAX_MHZ` 限制，不会按成本自动剔除；需要省算力要显式给
   `solve.COST_BUDGET` 或 UI 成本档。
6. **`read_waves` 对高斯波不显示时长**（`env` 只有 4 元，`env[4]` 取不到），只给形状；平方波/文件包络才有 `duration_ns`。
