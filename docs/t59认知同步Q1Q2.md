## Q1：direct +1.38 vs far_sos ±18.4

**direct 的 60S 位移分解**（295.7THz、I=5e7、n_photon=4、window=3、基组 44 态 57-63）：

| 伙伴 | 位移 (MHz) |
|---|---|
| 60S (mJ=±0.5) | **+1.378**（总） |
| 60P (j=1.5, mJ=±0.5) | −18.0 |
| 60P (j=0.5) | −9.61 |
| 59P (j=1.5) | +17.75 |
| 59P (j=0.5) | +8.33 |
| 61P | −0.39 |

**结论**：
- direct 的 +1.378 = **多伙伴净位移**——60S↔60P 单对的 ±18 量级被 59P/61P 等
  里德堡系列的相反贡献**部分抵消** → 净 +1.378。far_sos 的 ±18.4 = 单对（无抵消）。
- **direct 基组（|Δn|≤3 → 57-63）不含 6P**（|Δn|=54 被 window 截断）——而 6P 是
  295.7THz 的**近共振强对**（真实场景 60S↔6P 才是主导）——direct 的 60S 位移在此
  配置下**不完整**（缺 6P 的 dressed 贡献）。
- **哪个是"真"dress 取决于基组**：2 态（仅 60S↔60P）→ ±18.4；57-63 全伙伴 →
  +1.378；真实 22 态（+ 6P + 60D……）→ 第三个值。**M=4 锚（2 态）与 D（±18.4）
  一致只证明"同基组自洽"，不证明 ±18.4 是全物理真值**。

## Q2：单原子不转移 vs 两体转移

我的 t59 两体：`_pair_groups(f_opt, f_mw)` = 光场在 **A 侧**、微波在 **B 侧**——
B 侧无光场 → B 的 60S↔60P gap 未被光频移 → 微波共振转移正常（0.144）。
船长单原子：光+微波**同原子** → 光频移阻断同原子的微波。
**两体结构差异（光/微分侧）解释了转移差异**——AC 化方案在两体需按"每原子各自的光
频移作用于该原子的微波"设计（若光+微波同原子，用 ±18 类位移；若分侧，无阻断）。

1. AC 化方向成立（D≈A），但注入值须与目标基组一致——**2 态锚用 ±18.4；全伙伴/真实
   22 态需 direct 式全伙伴净位移（且基组须含 6P——window 需放开或补近共振对）**。
