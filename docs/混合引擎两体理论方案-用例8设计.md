# 混合引擎两体理论方案：用例 8（V_dd φ-帧相位 + 微波当场同扇区）

> 2026-09-06 船长推导（t62 用例 8 实现前设计）。目标：22 态两体 620ns
> dim 1452（vs 全 Sambe 7260——5 倍降维验收）。22 态单原子 dim 结构已确认
> （26092ea：光 P=3 vs P=15）。本文档给两体 run_case 的完整结构与理论依据。

## 0. 结论摘要

1. 两体混合 = 单原子 run_case 的直积推广：**N² 物理基 × 共享光场光子块 P=3**，
   微波与 V_dd **不进光子块**（同扇区当场）→ dim = N²·3 = 1452
2. **V_dd 的 φ-帧相位自动正确**：同扇区 ΔD = E_i+E_j−E_k−E_l（n 消掉，与
   光子块无关）——e^{iC·ΔD·t} 由 φ-帧自动涌现，无需手工 E-IP（呼应 t34
   疑点 2：存活元素 E_lab≡E_rot）
3. 光场反旋对过滤（|ΔD|<BW_OPT，用例 4 教训）与微波近共振过滤两体同样必需
4. 远强对 AC 化：单原子位移注入 E_i（A/B 各自），E_pair 自动携带

## 1. 基与扩展结构

- 单原子 N=22 态（60S/60P/6P 流形），能量 E_i
- 两体物理基 |i,j⟩ = |i⟩_A⊗|j⟩_B，N²=484 维，E_pair[i,j] = E_i + E_j
- A/B 同频光场 ω_opt（295.7THz，驱动各原子 6P↔60S 近对 + 60S↔60P 远强对）
  → **共享光子数 n**（同频场 Floquet 展开单计数）：扩展 |i,j,n⟩，n∈{−1,0,1}
  （M=1）→ P=3，dim = 484×3 = **1452** ✓
- 微波 ω_mw（17GHz，驱动 60S↔60P）与 V_dd：**不进光子块**（同扇区当场）

**对照全 Sambe**：微波也进光子块（M=2 → n_mw∈{−2..2} 5 个）→ P = 3×5 = 15
→ dim = 484×15 = 7260。混合引擎 5 倍降维的根源 = 微波/V_dd 不占光子块。

## 2. 哈密顿与 φ-帧方程

两体实验室系：
H(t) = H_atom⊗I + I⊗H_atom
     + env_o(t)cos(ω_opt t)·[A_o⊗I + I⊗A_o]      （光场，A_o 单原子 Rabi 阵）
     + env_m(t)cos(ω_mw t)·[A_mw⊗I + I⊗A_mw]     （微波当场）
     + V_dd(t)                                    （两体相互作用，同扇区）

光场进光子块后：
K0_pair[i,j,n] = E_i + E_j − n·ω_opt
Kc 光场耦合（每方向）：
- A 原子跃迁 i→k（B 不动）：|i,j,n⟩ ↔ |k,j,n±1⟩，v = A_o[i,k]/2·env_o
- B 原子跃迁 j→l（A 不动）：|i,j,n⟩ ↔ |i,l,n±1⟩，v = A_o[j,l]/2·env_o

φ-帧（D = K0_pair 全对角）：dφ/dt = −iC·[Kc∘e^{iC·ΔD·t} + M∘e^{iC·ΔD·t}
+ V∘e^{iC·ΔD·t}]·φ，逐项 ΔD：

| 项 | 连的扩展态 | ΔD = D[a]−D[b] | 频率 | 处理 |
|---|---|---|---|---|
| 光场近对（6P↔60S）| n→n±1 | E_i−E_k+ω_opt（或反向）≈失谐 | MHz | 保留（DOP853）|
| 光场反旋 | n→n∓1 反向 | ≈±2ω_opt | THz | **|ΔD|<BW_OPT 过滤**（用例 4）|
| 光场远强对（60S↔60P）| n→n±1 | ≈±295.7THz | THz | **AC 化剔除** + far_sos 注入 E |
| 微波共振对 | 同 n | E_i+E_j−E_k−E_l ≈ ∓ω_mw | cos 拍频慢 | 保留（当场）|
| V_dd | 同 n | E_i+E_j−E_k−E_l（n 无关）| MHz | 保留（当场）|

**V_dd 关键**：同扇区（V_dd 不驱动光载波）→ ΔD 的 −nω 项消掉 → 纯物理能级差
→ e^{iC·(E_i+E_j−E_k−E_l)·t} 自动涌现——与 hard_pair 里 V_dd 用 E_lab 的
正确性同源（t34 疑点 2：存活元素 E_lab≡E_rot，因旋转/光子块只落在被光驱动
的流形上，V_dd 连接的里德堡态无 ref/无 n 差）。

## 3. AC 化（远强对）两体化

- A 侧光场远对 (i,k)（如 60S↔60P @ 295.7THz，Ω=13.6THz r=0.046>r_crit）：
  从 A_o 剔除 + far_sos 位移 δE_i/δE_k 注入**单原子能级** → E_pair[i,j] 自动
  = (E_i+δE_i)+E_j。B 侧同。
- 近对（6P↔60S，失谐 MHz）留光子块动态处理（t60 仲裁：近对必须动态）。
- 光频移阻断微波（用例 3 物理）在两体自动：δE 差 → 微波对 E_pair 差偏离 ω_mw。

## 4. 实现建议（run_case_pair）

```
1. 单原子 22 态 states（含 E_i、n/l/j/m）；psi0 = (i0, j0) 两体初态
2. 光场 A_o（kind='exact' 同 fields 规格）→ r 判据分类：
   - 远强对（r>r_crit=0.0135）→ A_o 剔除 + far_sos 注入 E（单原子位移向量）
   - 近对保留
3. 两体光子块：复用 _PairSambeSetup（evolve_sambe_pair）？——它是"两场/全
   Sambe"结构（fields_A/fields_B 各自光子块）。混合引擎需要**共享光场扇区**
   （A_o⊗I+I⊗A_o 同 n）——若 _PairSambeSetup 的 _pair_groups 把 A/B 光场
   合成同频组（同 ω 共享扇区），可直接复用其 K0/Kc_dense；否则手工构造
   K0_pair（E_i+E_j−nω）+ Kc（A 跃迁/B 跃迁两方向）
4. pairs 打包（两体索引 a=(i,j,n)→ i*N+j+n*N²）：
   - 光场近对：|ΔD|<BW_OPT 过滤（用例 4 教训）——Kc 双向
   - 微波当场：同扇区 (i,j,n)↔(k,l,n)，A_mw⊗I + I⊗A_mw，|ΔE_pair−ω_mw|<5GHz
     过滤
   - V_dd：同扇区，全保留（MHz 慢）
5. numba RHS 同 _t62_numba.py（is_mw 标志：微波 cos 载波；V_dd 无载波）
6. 输出：物理两体布居 pops_2d[i,j]（跨扇区投影，_physical_pops 语义——
   nphase 相位 exp(−i·n·ω·t) 求和）
7. 对照锚：hard_pair（微波/V_dd 主导区）或全 Sambe 两体短窗（M=4 级小场景）
```

**dim 验收**：620ns 全程 norm ≤ 1e-4、末态 vs 锚（hard_pair 620ns 基线或
t61 全 Sambe AC 化结果 60S末(k0)=0）max|Δpops| 报告——5 倍降维（1452 vs
7260）带来的速度优势量化。

## 5. 与既有模块的关系

- 单原子 run_case（_t62_hybrid.py）是骨架模板（pairs/numba/重构逻辑复用）
- _PairSambeSetup（evolve_sambe_pair）提供两体光子块几何参考（能否复用
  取决于 _pair_groups 是否同频合并——t4/t9 已修同频合并 bug，光场 A/B 同频
  共享扇区正是其语义）
- 远强对 AC 化注入：与 t61（_t61_acize.py）同物理——单原子位移向量
  E_shift 注入 E_i（E_pair 自动）
