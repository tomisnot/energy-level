# 逐扇区扫描与"不给扇区"的精确基线

## 它是什么

`src/core/manybody/sector_scan.py::scan_ground_sectors` 是**编排层**，不引入新的数值算法：
对每个固定荷扇区 k = 0…N，用现成的叶子求解器（稠密 eigh / GPU 块 Krylov / CPU eigsh）
求该扇区基态，取 E0 最低者。

它回答的问题是：**如果不知道电荷扇区，精确解该付多少代价。**
这比"给一个正确 k 的扇区 ED"更接近真实部署条件（真实部署没有 k 可给）。

```python
from src.core.manybody.sector_scan import scan_ground_sectors

r = scan_ground_sectors(calib, delta=delta, Om=np.zeros(n), terms=['I1', 'I2'],
                        device='cuda', tol=1e-9, dense_max=64)
r['E0'], r['sector'], r['total_seconds'], r['per_sector']
```

返回里每个扇区都带 `dim / E0 / gap / residual / converged / backend / seconds`，
`converged` 是全部扇区都达到残差容限的合取；`dimension_sum` 与 `full_dimension`
用来核对"总共付了 2^N 个基"。

## 成本

- 总基 = Σ_k C(N,k) = **2^N**（不是单个扇区的 C(N, N/2)），比半填充扇区大 **√N 倍**
  （N=20：5.7×；N=24：6.2×）；
- 但每个扇区独立求解，小扇区几乎免费；真正的成本集中在 k ≈ N/2 附近的几个扇区；
- 全部扇区都收敛才报告 `converged=True`；不收敛不静默通过。

## 实测（RTX 4050 Laptop 6 GB，float64，tol=1e-9）

| N | 扫描总耗时 | 最慢扇区 | 2^N |
|---|---|---|---|
| 12 | **1.6 s** | 0.2–0.4 s（dim ≤ 924） | 4,096 |
| 16 | **3.4 s** | 0.25 s（dim 12,870） | 65,536 |
| 20 | **21.6 s** | 3.4 s（dim 184,756） | 1,048,576 |

同一台机器上，同规模神经网络前向是 **0.6 ms / 1.2 ms / 7.2 ms**。
即"不给 k 的精确解"比模型慢约 **3 个数量级**；即使把 k 白给 ED（只解一个扇区，
N=20 约 3.4 s），仍慢约 470×。

## 这次升级的零件（都与旧实现同一数学）

| 零件 | 旧 | 新 | 依据 |
|---|---|---|---|
| 扇区基生成 | Python 生成器逐组合求位码 | numpy 逐位倍增 + 排序 | N=24：5.98 s → **0.47 s**（13×） |
| 通道枚举 | 逐态 `pos.get(int(tgt))` | 位置表查表（N≤26） | N=20 单扇区：3.45 s → **0.55 s** |
| 矩阵作用 | 每通道一次 `index_add_` | 按内存预算分组，一次 `index_add_` | N=20：380 通道 → 1 组 |
| 正交化 | 2×m 次 `vdot` | 一次 GEMM（两次修正的经典 GS） | 单扇区 4.42 s → **0.25 s**（N=12，17.7×） |
| 算术 | 一律 complex128 | 全实模型走 float64 | 显存/带宽减半 |

单扇区 N=12、dim=924：**4.42 s → 0.25 s**，E0 与残差逐位一致（2.3e-14）。

## 口径（必须写清）

1. `onsite = 2h`：EL 的 δ·N̂ 与生成器 `xy_gen.build_sparse` 的
   `diag = −Σh + 2·(bits·h)` 对应；两者**只差常数 −Σh**（实测 N=12 为 0.598824，与 Σh 一致）。
   常数不改变 argmin，但跨代码比较 E0 时必须减掉。
2. `Ω≠0` 或含 `I3` 双激发时**拒绝**（`check_number_conserving`），不静默扫描。
3. DMRG 不支持 `sector=`，扫描里也不会偷偷用它。

## 与数据标签的一处不一致（记录，不是本模块的问题）

用载荷里的真实行核对时发现：**强场行**（如 N=16、h≈4.6–4.9）的 `k_true` 是
扇区条件解（k=1，能量 −71.19），而全局基态是真空（k=0，−76.09）。
低场行（h≈0.05，N=12/16/20 抽查）与全局基态一致，E 差 ≤1.3e-4（来自存档 ARPACK 容差）。
⇒ 若要用这份数据训练/评测"全局基态"，需先按 `scan_ground_sectors` 复核标签。
