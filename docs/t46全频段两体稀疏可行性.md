# 全频段两体 Sambe 稀疏传播可行性（t46）结论

> 2026-09-03 harddev 验证（只调查/原型，未改 src 正式逻辑）。
> 场景：2 态两体（N=2→N2=4），A 侧光场 295.7 THz（13.6 THz Rabi）+ B 侧微波
> 17 GHz，光子块 M=[1,2]（P=15，dim=60）；稀疏（IP Volterra）vs 稠密（eigh）。

## 结论

**全频段两体 Sambe 的稀疏传播（IP Volterra）是 THz 死局——不可行**（量化证据见下）。
推荐路线：两体两场变体（现成，自检 11/11）或两体级 φ-帧混合（待单原子 mixed 残差解决后推广）。

## 量化证据（tempsimu/_t46_sparse_thz.py）

| 项 | 值 |
|---|---|
| 稀疏路径单段 est 收敛的段长 | **h ~1e-6 ns**（est=5.6e-10 仅在 h=1e-6ns；h≥1e-4ns 时 est=inf——GMRES 不收敛） |
| THz 对角 | diag 范围 ±2.958e8 MHz（C·diag ~1.86e6 rad/ns，相位 2π/3.4e-6 ns） |
| 620ns 全程外推 | ~6e8 段（不可行） |

**机制**：稀疏路径（_subspace_segment L547）的 IP-Volterra 用离散节点（_NODE_LADDER
16/32/64/128）求积 e^{iC·diag·(nodes−ta)} 核——diag 含 THz（3e8 MHz）时节点间相位
~1e5 rad ≫ 2π → 求积完全欠采样 → GMRES 病态/est=inf → 段须细分到 ~1e-6 ns ——与
单原子 defect 路径的 Gauss 求积死局（t33/t35 教训）**同源**：THz 振荡须解析处理，
节点求积无法承载。

## 方案对比（数据）

| 方案 | 能否跑 | 备注 |
|---|---|---|
| 全频段两体 sparse（IP Volterra） | ✗ THz 死局（h~1e-6ns，6e8 段） | 本任务量化 |
| 全频段两体 dense（eigh frozen） | ✗ 成本 O(dim³)：7260 维 ~358s/段（船长核算） | 不可行 |
| 两体两场变体（光旋转 + 微波光子块） | ✓ dim 2420，自检 11/11 | **现成可用（推荐）** |
| 两体级 φ-帧混合（单 DOP853） | 待定 | 单原子 mixed 的 22 态残差（2.36e-2，t42-t44 未决）需先解决；推广两体前需独立验证 |

## 建议

1. 短期：两体全频段需求走两体两场变体（光场 RWA 近似 + 微波光子块——光场 RWA 误差
   (Ω/ω)²~1e-14 级，两体交换场景已验证）。
2. 中期：若必须无 RWA 两体——两体级 φ-帧混合（φ=e^{iC·D·t} 吸收 THz + 单 DOP853）是
   唯一数学可行路线——但需先解决单原子 mixed 的 22 态残差（t42-t44 的未决问题）。
3. 脚本 tempsimu/_t46_sparse_thz.py 可复跑（含段长扫描量化）。
