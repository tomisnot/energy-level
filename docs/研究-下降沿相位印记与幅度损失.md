## 0b. 机制（本轮确立）

**一句话**：下降沿在系统上"写下"一个相位；这个相位改变两个工作通道之间的**布居分配**；
分配变了，交换能力（振幅）就变了——**原子没有跑掉**。

三层证据链：

```
① 频率不变 (2.3347 MHz, 5e-5)      ⇒ 末态哈密顿量未变，沿只留下相位
② 峰值 = C + A0 (12/12)            ⇒ "峰值"是常量包络在某个相位上的采样
③ Δa = s·Δ(a/s) + (a/s)·Δs         ⇒ 68% 来自分配、32% 来自总量（恒等式到 8e-17）
   且 峰值时堆外布居 ≈ 0            ⇒ 无泄漏；a/s: 0.713 ↔ 0.910
```

物理图像：V_dd 网络给出末态的两通道拍频 2V = 2.3347 MHz（V = 1.167 MHz，
与前人静态直算 1.2056 同量级）；沿期间光移 δ(t)=κ(I−I_res) 使瞬时
√(V²+δ²) 偏离 2V，**各通道偏离量不同**，于是留下相对相位。
末态回到 I_res 后两通道仍以 2V 拍动，但**相位起点被沿改写** ⇒ 读出时刻的分配不同。

**最大可达分配的上限**（理想阶跃 a/s = 0.878，本轮最好 0.910）由末态通道混合角
（竞争通道 V=1.2585 > 目标 1.2056 MHz）给定 ⇒ 这就是前人 §4 说的"0.78 天花板"的来源。

## 1. 为什么要改"怎么看"——主指标纠偏

前人的主指标是 **峰值 = max_t P(换后态)**。在有限窗口内取极大，结果同时取决于
**幅度**与**相位采样**。锁相分析（§2）分离后：

| 观察 | 数值 | 含义 |
|---|---|---|
| 稳态主频 f0 | **2.3347 MHz**，跨 21 条相对散布 **5e-5** | 沿**不改频率** |
| 拟合相位 φ0 | 同频率下跨 **5.4 rad** | 沿**主要改相位** |
| 观测峰值 vs (C+A0) | \|差\| 中位 3.5e-3、最大 8.4e-3（12/12） | 峰值 = 该相位上的采样 |
| 幅度 A0 | 0.289 → 0.400（**38%** 展宽） | 且**幅度确实被削** |

⇒ 只看峰值会把"相位移动"读成"交换被破坏"。**主量应是 A0**。

## 2. 方法：锁相式单模提取

**做法**：稳态段加 Hann 窗 → FFT 取主峰频率 f0（抛物线细化）→ 最小二乘投影到
{1, cos2πf0t, sin2πf0t} ⇒ C（基线）、A0（幅度）、φ0（相位）。

**为什么不用 Hilbert**（弯路，留档）：布居至少两个频率分量（主交换 + 慢拍），
解析信号把拍当包络，给出**非物理**结果（E1/hold100 的"包络" 0.83 > 观测峰值 0.78）。
锁相法只取目标频率，不受此影响。

**稳健性（必做）**：A0 在 4 个含 2.2–3.9 个振荡周期的窗口下一致到 **±2.7%**；
只剩 1.4 个周期的窄窗失效（跨窗口极差 68%）。
**纪律：分析窗内 ≥2 个完整交换周期**（T_exchange ≈ 428 ns ⇒ 窗口 ≥900 ns）。

### 4.1 设计

### 4.3 判读

**(a) "光强积分"第三次被否**（强判决）
S = 747.4 的四条轨迹，末态从 0.0233 到 0.1799，**差 7.7 倍**。
⇒ 平台段光强时间积分不是决定末态的量。前人否掉 H1（超额积分），本文否掉"完整光强积分"。

**(b) 交叉校验逐位通过**
`C/down50` 观测峰值 = **0.7395**，前人离线通道 `F/tf=50` = **0.7395**（差 0.0000）
⇒ MCP 扫描通道与离线脚本等价。
（`C/step` 的 A0 与离线相差 3.1%，来源已定位：**窗口不同**——离线只到 1362 ns，
本文到 2000 ns；窗口稳健性实测同量级。观测峰值本身两者一致。）

**(c) ⚠ 我的预注册 P1/P2 被自己否定**
- P1（"对称往返显著优于单向"）**只在短时长成立**：τ=25 ns 时 A0=0.4002（比阶跃**高** 5.4%），
  但 τ=100 ns 时 A0=0.2895（比阶跃低 **23.8%**，比单向下降还差 20 个百分点）。
- P2（"对称往返的 A0 与时长无关"）**明确不成立**：A 族内 A0 极差 **0.1107（相对 32.3%）**。
- ⇒ **"往返更优"是错的**；正确的表述是"**短、且对称**"。

**(d) 控制量：净相位积累主导，单向性次之**
双变量最小二乘（两个量相关系数 −0.717，非共线）：

```
loss_rel = +0.1169·|Δφ| + 0.1340·单向行程 − 0.0688
           标准化 +1.04      标准化 +0.40
拟合 rms = 0.0475（数据 rms = 0.0790）
```
- 单变量：`corr(|Δφ|, 损失) = +0.748`；`corr(单向行程, 损失) = −0.341`
- **相位项主导**（标准化系数是单向项的 2.6 倍）
- 但残差仍有 0.048、个别点残差达 ±7%（如 B/hold50）⇒ **不是单参数定律**，
  需要物理模型（见 §6）才能闭合

**(e) 可报告的增益**
`A/tri25_d1.00`（对称往返升到 I₃ 再回 I_res，共 50 ns）的 (C+A0) = **0.8064 > 阶跃的 0.7623**。
⇒ 合适的短 excursion **提高**交换能力，不只是"少损失"。该增益在 4 个窗口下稳定
（−5.0% … −5.7%）。

## 6. 机制图像（与证据一致的解释，待独立检验）

真空 Rabi 频率 Ω(t)=√(V²+δ(t)²)（δ = 光移）给出**与强度历史有关的相位**
φ = ∫√(V²+δ²)dt。交换网络有 5–6 个通道（前人 §4），各通道 δ 系数不同
⇒ 沿在通道间留下**相对相位**。目标通道的相对相位偏离最优值越多，
它与竞争通道的干涉越不利 ⇒ 表观幅度下降。
**这解释了**：频率不变（末态 δ=0，Ω=2V）、峰值=C+A0（末态两能级混合角固定）、
以及"损伤 ∝ |Δφ| 而非停留时间"。
**未解释**：为何 B/hold50 大 Δφ 却零损失、A/tri25 出现增益 ⇒
需要显式多通道计算（§7）。

**三条可直接引用的事实**：
1. **相位随沿宽单调增长**：`corr(τ_f, |Δφ|) = +0.994`，21 点跨 0 → 1.39 rad（0.22 周期）。
2. **交换质量随相位下降**：`A0` 从 0.3747 降到 0.3573（**−4.7%**），

3.  **但相位依赖是非单调的**：A0 在 \|Δφ\| ≈ 1.01 rad（τ_f=100 ns）触底（0.3387），
   之后**回升**到 0.3573。平滑样条给出谷底 **1.06 rad**（R²=0.983，与实测最低点吻合）。
   ⇒ 正确表述是"**相位越大、交换越差（在 0–1 rad 区间严格成立）**，
   但依赖在 ~1 rad 处触底并部分回升"，**不是**单调律。
4. **(a) 的直观证据**：5 条曲线随 τ_f 变宽**整体右移**（峰位 500→600 ns）
   且**峰高被压低**——"下降沿明显影响交换过程"这一点在单张图上即可见。

**与前人数据的一致性**：本轮 τ_f=50 的 A0 = 0.3614（此窗口）
与前人离线 `F/tf=50` 的 0.3632 一致到 0.5%；τ_f=100 的 0.3387 对 0.3455（1.9%）。

**工程提示**：本轮 21 点分两批提交时，**两个 runner 同时跑触发 ARC sqlite 并发**
（`no such table: literatureDME`）导致 2 点失败；补跑（单 runner，2 点）后数据完整。
⇒ **再确认一次研究文档 §5 教训 1**：同一时刻只让**一个** sweep runner 活跃。

## 7. 对实验的建议（可立即使用）

1. **报告口径**：给"交换质量"时报 **(C+A0)**（可达最大值）与 **A0**（振荡半幅），
   **不要**报单一时刻峰值——后者含相位采样，换窗口就变。
   前人文档里的 −5.4/−6.7 点需按此重述。
2. **降光不要"慢慢来"**：τ_f 0→100 ns 使可达最大值从 0.781 降到 0.709（−9.3%）。
   若要缓沿，必须同时接受**相位重标定**与幅度代价。
3. **首选"短对称往返"**：把强度降回 I_res 前先做一个 ~25 ns 的对称 up-down
   excursion（本文实测 **+5.4%**）。**但别拉长**：50 ns 变 −11%、100 ns 变 −24%。
4. **相位必须标定**：沿造成的相位差可达 **0.85 个周期**。若实验在固定时刻读交换，
   不同沿会给出完全不同的读数。
5. **窗口纪律**：≥2000 ns，且分析窗内 ≥2 个交换周期（≥900 ns）。
6. ⚠ 以上均基于单组几何（R=14.1 μm/θ=31.1°）与单一光强标度；换几何需重标定。

## 10. 本轮事故与工程坑（供后人）

### 10.1 事故：软件进程静默消失（两次）

- **第一次（09:55:53）**：提交**大体量** `run_python`（11 点 × 整张包络折线，≈12 KB）
  时 GUI 进程消失；日志只有连串 `Terminating session`，无 traceback。
  现场保全于 `scripts/tmp/crashdumps/`。
- **第二次（10:04:47）**：我自己 `Start-Process` 启动的实例以
  **空日志 + 立即退出**；系统事件日志显示 `Application Hang`。
- **教训**：提交载荷尽量小（本文改用"参数化生成波形"的模块，载荷降两个量级）；
  实例日志按 §七.0 用带 pid/时间戳的路径。

### 10.2 ⚠ 沙箱限制：自己启动软件会让并行扫描全废

**现象**：以 DSH 沙箱（workspace-write）方式启动的软件，其 `submit_sweep`
**每次都在建 `ProcessPoolExecutor` 时失败**：
```
PermissionError: [WinError 5] 拒绝访问。
  ... multiprocessing/connection.py:558 in Pipe -> _winapi.CreateFile
```
**原因**：子进程继承受限 token，无法创建 multiprocessing 命名管道
（DSH 文档记录的沙箱边界）。
**不是软件缺陷**（人正常双击启动不受影响）。
**解法**：以不受限方式启动软件（本会话用 `sandbox_permissions: danger-full-access`
重启后，同一份 spec 立即 9/9 跑通）。
**判据**：`sweep_status` 的 `note` 出现 `runner 崩溃：[WinError 5]` 即是此情形。

### 10.3 代码/接口坑

1. **`submit_sweep(points=[...])` 不能带元数据键**（如 `tag`）：
   `src/sweep/spec.py::apply_delta` 把 delta 每个键当参数路径校验
   ⇒ `KeyError: 轴键 'tag' 不在登记册快照里`（预检失败、0 点入队）。
2. **`FileEnv` 要求时间样品严格递增**：折线重复时刻会让该点
   `ValueError: 包络文件时间样品必须严格递增`。
3. **`record='final'` 的 npz 只有 `labels/final_pop/t_ns`**；要时间序列必须
   `record='pops'`（才会写 `series_t/series_pop`）。
4. ⚠ **`run_python_async` 没有接线 sweep 工具**（`src/ai/codeact.py` 的
   `run_python_async` 回调列表缺 `t_sweep_*`，而同步 `run_python` 有）
   ⇒ 异步脚本里 `submit_sweep` 永远返回
   `{'ok': False, 'msg': '本进程不支持并行扫描（服务端未接线）'}`。
   **要提交扫描必须走同步 `run_python` 或 MCP 的 `submit_sweep`。**
5. **`points` 字典的键是完整参数路径**（`'dynamic.waves_A'`），
   不是末段名（`'waves_A' in p` 恒为 False——本轮在此浪费了一轮调试）。
6. **扫描点必须回到同一末态**，否则 A0 的变化与末态哈密顿量混淆。
7. **相关不等于机制**：单调绑定的控制量都会给出 corr≈±0.99。
