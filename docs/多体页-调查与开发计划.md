## 0. TL;DR

1. **需求翻译成一句话**：多体页 = "**自旋模型工作台**"——用户摆原子（3D 坐标）、
   选 2–3 个能级/原子、给静态（或慢变）失谐与 Rabi，软件自动生成
   Rydberg Ising/Potts/XY 型哈密顿量并演化，画布居/关联/纠缠/相图。
   **逐电子态、逐光子、逐 mJ 的精细原子物理全部留在静态/动态页**，多体页只消费
   它们**产出的少数参数**（ε、Ω、U_ij、V_ij、Γ）。
2. **维度灾难是唯一的主约束**（前置文档 §4.2 已断言）：38ⁿ 子能级基不可行；
   提炼到"每原子 2 能级"后 2ᴺ，N≤24 可精确对角化（ED），N 到 ~100 靠 MPS/TEBD，
   2D 阵列靠"蛇形排序 + χ 截断"或 TTN。**分层引擎是必然**：ED 做金标准，
   TEBD 做主力，两者在重叠区互相校验。
3. **张量网络不建议自研核心**：TeNPy（Apache-2.0，含长程 MPO Witschardt 算法、
   2D 蛇形链、iTEBD/TEBD/TDVP/DMRG）与 quimb（BSD，API 轻）二选一做后端库，
   本项目只做**模型装配层 + GUI + 记账/自检**。自研 MPS 只在"库不满足耗散需求"
   时作为 M6 备选。
4. **相互作用直接复用 `static_pair.py`**：`_vdd_tensor`/`vdd_sparse` 的球张量机制
   原样推广为"按对求和"的 N 体装配器；交换耦合 `exchange_coupling`（一阶）与
   `vdw_shift`（二阶）就是多体页的 J_ij、V_ij 的来源——**两体页是多体页的 N=2 特例**，
   参数提取应做成一键（"从动态页两体标定 → 填入多体页"）。
5. **耗散沿用已验证的"非厄米对角 + 分项记账"载体**（`−iΓ/2` ≡ sink-Lindblad
   实测 ≤2.2e-9；dissipation_lab 已把时变 γ(t) 与分项 loss 走通）。多体页 v1 只支持
   **丢失型**通道（自发辐射 → 损失），显式落点/纯退相留给 M6 的 MPO 主方程。
6. **前端两个新零件**：① 3D 几何编辑器（pyvista/VTK 嵌 QOpenGLWidget，或降级为
   matplotlib 3D 只读 + 表格式编辑）；② 结果图按"原子是否共面"自动切 2D/3D
   （共面判据：最大离面残差 < 阈值）。页面注册走 `app_entry.modules` 表，
   参数入册走 `pm_setup` 工厂——**框架现成，无侵入**。
7. 里程碑：**M0 参数提取与模型定义 → M1 ED 引擎（N≤10 全链）→ M2 多体页 UI+几何
   → M3 TEBD 后端 → M4 开放系统与耗散 → M5 观测量大扫除（关联/熵/相图）→
   M6 2D/3D 大阵列**。每档独立可验收，M1 结束就能出第一批物理结果。

## 1. 需求解读（使用者原话 → 工程口径）

| 原话 | 工程口径 |
|---|---|
| "单开一页独立于静态页和动态页" | 新 tab「多体页」，新面板类，**新参数命名空间 `manybody.*`**；与动态页只共享"能级组/场"的**只读快照**，不共享运行路径 |
| "尽量不去考虑细枝末节的原子物理，提炼少数几个能级、几个跃迁、几个交换" | 每原子局部空间 = **2–3 维**（|g⟩,|r⟩[,|s⟩]）；全部原子物理浓缩进几个数：ε（跃迁失谐）、Ω（Rabi）、V_ij（相互作用矩阵）。精细计算（ARC 寿命、超精细、mJ、AC 化）在**别的页做完**，以"参数标定"动作流入本页 |
| "电磁场估计不能考虑时变的了" | **准静态驱动**：Ω、δ 为常数（或分段常数斜坡，见 §3.4）。放弃逐光子 φ-帧；这是多体可行的前提，也是与动态页的本质分工 |
| "几何位置得有三维自由度，平面画 2D、三维画 3D" | 原子坐标 (x,y,z) 逐原子可编辑 + 阵列生成器（链/方格/三角/环/任意导入）；渲染按共面性自动 2D/3D |
| "多体问题后端张量网络比较合适" | 同意，但**分层**：小 N 用 ED（金标准、任意几何），大 N 用 MPS/TEBD（1D 与 2D 蛇形），耗散大 N 才考虑 MPO/TTN。张量网络不是银弹——纠缠线性增长会限制演化时长（见 §5.4 预算表） |

**不做什么（明确排除，防止范围蔓延）**：
- 不做逐 mJ/超精细的多体（维度不允许；要精细物理请回动态页两体）；
- 不做时变光场的多体光子块全局化（前置文档 §4.3 判定为"大改"，v1 排除）；
- 不做 PEPS/2D 真张量网络（2D 大阵列用蛇形 MPS 或 TTN 够用，PEPS 更新太慢）；
- 不做量子蒙特卡洛（符号问题 + 与动态演化无关）；
- 不做实时可视化动画（v1 出曲线与快照图即可）。

## 2. 领域调研结论（外部）

### 2.1 物理模型：中性原子阵列的标准做法

学界对"里德堡阵列多体"的共识抽象就是**自旋格点模型**，按精度分三档：

1. **硬芯玻色 / Rydberg Ising**（blockade 区，最常用）：
   `H = Σ_i (Ω/2)σˣ_i − Σ_i (δ_i/2)σᶻ_i + Σ_{i<j} V_ij n_i n_j`，
   每原子 2 能级；V_ij = C6/R⁶（含 m 混合时加 C3/R³ 与反对称交换）。
   2D 10×10 反铁磁制备（Scholl et al. Nature 2021）的 MPS 模拟跑了 14 天超算——
   说明**方法成熟但计算不便宜**，工程上必须给用户成本预估。
2. **软自旋 / PUPAS 模型**（中等失谐、可测输运/磁化率）：
   每原子 3 能级 |g⟩,|g'⟩,|r⟩，含基态-基态跃迁（"自旋波"通道），
   能复现自旋塞曼输运、XY 模型、条纹相。对应本项目的"几个跃迁、几个交换"。
3. **偶极交换 / XY**（resonant dipole-dipole，如 kagome 自旋液体实验
   N=114，Bornet/Bintz et al. 2026）：
   `H = Σ J_ij (σ⁺σ⁻ + h.c.)`，J_ij 直接来自 V_dd 的非对角元——
   **正是本项目 `exchange_coupling`（一阶）与 `vdw_shift`（二阶）算的东西**。

> 结论：本项目两体页已经会算第 2、3 档需要的全部矩阵元（V_dd 球张量、交换、
> vdW 位移），多体页只是"按对求和 + 换求解器"。这不是猜测，是 `static_pair.py`
> 的既有能力。

### 2.2 数值方法：库与算法现状

| 工具 | 许可 | 对本项目的相关性 |
|---|---|---|
| **TeNPy 1.x** | Apache-2.0 | MPS/DMRG/TEBD/TDVP/MPO 演化全家桶；**长程相互作用 MPO**（Witschardt & Pichler 算法，正是 Rydberg C6/R⁶ 所需）；`SpinChainNNN2`/`DipolarSpinChain`/`TFIModel` 内置；支持任意 lattice（含 2D 蛇形链）；OpenMP 并行；Windows 可用 |
| **quimb** | BSD | API 更轻（`spin_operator`、`TEBD`、MPS），几何无关的张量网络图表示；长程支持靠 MPO 手搓，不如 TeNPy 现成 |
| **QuSpin** | GPL-like | ED 标杆：32 站点自旋链、任意多体算符、对称性分块（磁化守恒/宇称）；**若自研 ED 层，接口设计照抄它** |
| ITensor (Julia/C++) | Apache | 性能天花板，但跨语言；本项目 src/julia 已有桥的先例，留作 M6 备选 |
| Bloqade (Julia) | Apache | QuEra 官方里德堡模拟器，MPS+Lindblad（MPO 密度矩阵）；其**模型定义层**（atom 坐标 → 哈密顿量）值得抄设计 |
| PUPAS | — | 软自旋多体 + 耗散的参考实现（C++），验证 §2.1 第 2 档的物理口径 |

**开放系统多体**（里德堡寿命、激光线宽）：纯态 MPS 不够，标准做法是
(i) MPO 密度矩阵（1D 可行，χ² 爆炸）；(ii) **跳变积分法 JIM**（每个量子轨迹用
纯态 MPS 演化，蒙特卡洛平均——与本项目 dissipation_lab 的"非厄米 + 事后记账"
哲学一致，只是把"事后 loss"升级为"量子跳跃"）；(iii) 平均场/累积量截断（TWA，
大 N 输运）。v1 用 (ii) 的"无跳变 + loss 记账"简化版即可（里德堡 Γ 小、
演化 µs 级，跳跃概率低）。

**2D/3D 几何**：蛇形（snake/serpentine）排序把 2D 格点映射成 1D 链，长程项走 MPO；
10×10 是当前 MPS 动力量级上限（文献实测）。树张量网络（TTN）在 2D 小横向场
微扰区可打到 16×16。3D 无成熟张量网络方案——3D 几何 v1 只进 ED（N≤16）
与平均场（任意 N），文档如实标注。

## 3. 物理模型抽象（多体页的"模型卡"）

> **2026-09-17 使用者裁决**：① 几何**不许定死**——任意原子坐标输入是硬需求，
> 生成器只是便利；② 相互作用走"**分类 + 逐项实现**"路线（§3.2），但每一类的
> **系数必须从真实原子物理标定**（ARC + static_pair），不许拍参数；
> ③ 耗散（M4）**先不做**；④ 后端库定为 TeNPy（已装 physics-tenpy 1.1.1 @ py3.10）。

### 3.1 局部空间与几何

每原子从"能级组"里**勾选**参与态，v1 支持三种局部空间模板（模板 = onsite 维数与
算符集的选择，**不是**几何或相互作用形式的限制）：

| 模板 | onsite 基 | 算符 | 典型场景 |
|---|---|---|---|
| `ising` | {|g⟩,|r⟩} | σˣ, n=(1−σᶻ)/2 | blockade、AF 制备、quench |
| `xy` | {|g⟩,|r⟩}（激发数守恒） | σ⁺σ⁻ 交换 | 共振偶极交换、自旋液体 |
| `potts3` | {|g⟩,|r1⟩,|r2⟩} | 推广 Potts | 多 Rydberg 态竞争、条纹相 |

- 态的**身份**仍用 (n,l,j,m) 四元组（与全库一致，`_resolve_level_idx` 可复用），
  但**能量/寿命/矩阵元在"标定"时一次性算好**，运行时不再查 ARC。
- 标定来源（§6.2 详述）：ε 与 V_ij 来自 `static_pair` 的 pair_eigen/exchange；
  Γ 来自 `auto_decays`；Ω 来自 `static_atom.rabi_mhz`。

**几何 = 完全自由的点集**。`manybody.atoms` 就是逐原子 (x,y,z) 列表（任意
2D/3D 点云，可导入），链/方格/三角/环生成器只是"帮你摆点"的便利工具，
**不构成任何对称性假设**：
- ED 层：几何天然任意（逐对算 V_ij 即可）；
- MPS 层：任意点集 → 排序问题（默认贪心/希尔伯特曲线排序，让强耦合对尽量近邻），
  排序只影响 χ 效率、不影响物理；TeNPy 的 `CouplingTerms.add_coupling` 支持
  **逐对任意强度**（u1/u2 给站点对数组），MPO 用 `compress_mpo`（Witschardt 式
  长程构造）装配——这正是"任意几何 + 长程相互作用"的现成机制；
- 相互作用截断 R_cut 是唯一与几何相关的旋钮，且它丢的是**可量化的尾项**
  （Σ C6/R⁶ 尾部 < 阈值），报告进诊断。

### 3.2 相互作用：分类表（裁决②的落地）

**为什么"分类"与"贴合真实"不矛盾**：不截断的"完全真实"= 38 维子能级基 × N 原子
= 38^N，任何求解器都救不了（§6.1 维度账）。真实物理能保留的**唯一去处是
"对"的层面**——两个原子各 2 个选定态张成的 4 维对空间 {|gg⟩,|gr⟩,|rg⟩,|rr⟩}
里，偶极-偶极算符 V_dd(R,θ,φ) 是**完全精确**的（ARC 矩阵元 + `_vdd_tensor`
全张量，含全部中间态混合 = 自动包含 C3/C6/C8/共振交换/各向异性/双激发翻转）。
把它按对空间的矩阵结构拆开，**只有以下几项**：

| # | 项 | 对空间矩阵元 | 算符形式 | R 依赖 | 系数来源（现成代码） | 档位 |
|---|---|---|---|---|---|---|
| I1 | 密度-密度 | ⟨rr|V|rr⟩ | V_ij·n_i n_j | C6/R⁶(+C8/R⁸) | `vdw_shift`（二阶全对角化） | L0 |
| I2 | 交换 | ⟨gr|V|rg⟩ | J_ij(σ⁺_iσ⁻_j+h.c.) | C3/R³ 或二阶 | `exchange_coupling`（一阶）/ pair_eigen 对角化 | L1 |
| I3 | 双激发翻转 | ⟨gg|V|rr⟩ | A_ij(σ⁺_iσ⁺_j+h.c.) | 同上 | `vdd_sparse` 对应元 | L2 |
| I4 | 各向异性 | 以上各项的 (θ,φ) 依赖 | 系数随几何变 | T(θ,φ) 球张量 | `_vdd_tensor` 原样 | 随 I1–3 |
| I5 | 寻址光串扰 | **不是原子间项**：邻束光落在别的原子上 | 逐位点 δ_i′、Ω_i′、γ_i | ∝ I(r_i−r_beam) | 静态页 `far_sos_shift`/`rabi_mhz` + dissipation_lab L2 散射公式 | 标定层 |

- **结论：相互作用就这 3+1 类（I1–I4），外加一个单点项 I5。** 挨个实现可行，
  且每个系数都从真实对能谱提取（不是手调 C6）——这就是"分类路线拿到真实度"。
- I5 值得强调：寻址光对**非目标原子**的作用在自旋模型语言里是**单点位错/泄漏
  驱动/散射损失**，不是新的原子间相互作用——标定阶段逐原子算一遍串扰矩阵即可，
  成本 O(N×束数)，且公式全现成。
- 诚实边界（写进模型卡）：以上都是**可加对近似**（pairwise additive）；
  非可加三体项（如 C11/R¹¹ 型、中间里德堡态介导）v1 排除，量级报告留 M6。
- 精度旋钮 `model.level` 改为**项开关集合**（I1/I2/I3 独立勾选 + 自动推荐档），
  每关一项给出"被丢项的最大幅值"（`static_phase_keep` 的 info 口径），不许静默。

**TeNPy 能力实测（2026-09-17，`scripts/tmp/tenpy_probe.py`，physics-tenpy 1.1.1）**：

| 探针 | 结果 |
|---|---|
| ① 任意逐对 V_ij 装进 MPO（20 原子**非晶格微扰点云**，154 对，max_range=11） | ✅ `add_coupling(strength=按位置数组, dx)` 逐 dx 分组即可；`add_onsite(Om 数组, u=0)` 逐原子任意 |
| ② 长程 C6/R⁶ 的 MPO 键维数 | 实测 3→13（Witschardt 式指数衰减压缩生效，**非** O(N) 增长） |
| ③ MPO ≡ 显式稠密逐对装配 | Δ⟨H⟩ = 9.1e-13 |
| ④ 长程 MPO 演化（ExpMPOEvolution）≡ ED（scipy expm） | dt 减半误差 ÷3（二阶 Trotter 正常收敛）；**dt 必须解析最快 V**（V·dt≪1），此约束写进 cost_mb 的 dt 推荐 |

### 3.3 哈密顿量（装配公式）

```
H = Σ_i [ (Ω_i + Σ_b Ω_i^leak,b)/2 · Tˣ_i + (δ_i + Σ_b δ_i^AC,b) · n_i ]   # 驱动+失谐+串扰
  + Σ_{i<j} [ V_ij·n_i n_j + J_ij·(σ⁺_i σ⁻_j + h.c.) + A_ij·(σ⁺_i σ⁺_j + h.c.) ]
```

（耗散项 −(i/2)ΣΓ_i n_i 保留在公式里但 v1 不接线——裁决③。）

### 3.5 "场不能时变"的边界（裁决点 D3）

v1：**常数 Ω、δ**。但两个廉价扩展值得留接缝：
- **分段常数斜坡**（绝热制备 AF/扫描 QPT）：δ(t) 阶梯化，每段独立 H——
  ED 用矩阵指数分块乘积，TEBD 天然支持（换 MPO 即可）；
- 全局高斯/黑塞包络的 Ω(t)（quench 实验常用）：env(t) 只乘系数，
  不引入光子块——与 dissipation_lab 的 env² 接缝同款。
若使用者要"逐原子 AOM 任意波形"，那是新量级需求，进 M6 再议。

## 6. 关键设计裁决的论证

### 6.1 为什么"提炼能级"是必须的，不是偷懒

维度账（ising 2ᴺ，ED 稀疏上限 ~2×10⁷ 复数）：

| 方案 | onsite 维 | N=10 | N=20 | N=50 |
|---|---|---|---|---|
| 子能级全基（现状） | 38 | 6.3e15 ✗ | — | — |
| 提炼 2 能级 | 2 | 1024 ✓ | 1e6 ✓ | — |
| 提炼 + TEBD | 2 | ✓ | ✓ | χ~100 ✓（短时） |

纠缠增长限制演化时长：`S(t) ~ v_E·t`，χ ≥ e^S；1D 临界区 v_E~2–4 /ns 量级
（对里德堡 µs 窗口，χ=256 大约撑 1–2 µs 的 1D quench——M3 用 ED 重叠区实测标定，
写进 cost_mb 而不是拍脑袋）。

### 6.2 标定流程（多体页与动态页的唯一"数据桥"）

```
用户在多体页选 (n,l,j,m)_g, (n,l,j,m)_r →「标定」
  → calibrate.py（主线程，ARC）：
     ε_i：单原子能差 + 光移（可选：从动态页当前配置快照）
     Ω_i：由输入光强/直接给 Rabi
     V_ij(R,θ,φ)：pair_eigen 的 |rr⟩ 对角元 − 2×|gr⟩ 对角（即相互作用移位）
     J_ij：exchange_coupling（一阶）；A_ij：⟨rr|V_dd|gg⟩
     Γ_r：auto_decays 口径
  → 回参数表 + "有效范围"报告（blockade 半径、L0 近似误差估计）
```

- 缓存键 (n,l,j,m)×2 + R 网格（复用 `coupling_strength_map` 的网格扫描）；
- **两体页验证过的场景可一键导入**（如 60S/60P 对），作为多体页的回归锚。

### M0 · 模型与标定内核（无 UI）——**✅ 完成（2026-09-17）**

**锚 A0**：N=2 装配 H 与两体页 V_dd 矩阵差 <1e-12；标定回参可序列化往返。

> **实现记录**（`src/manybody/`，自检 `checks/manybody_m0_selfcheck.py` **20/20，31s**）：
> - 一阶 4×4 ≡ `vdd_sparse` 逐元素 **0 差**（A0a；注意 vdd_sparse 存储是
>   ⟨q|V|p⟩ 转置序，装配统一为标准序 ⟨p|V|q⟩）；
> - **φ 相位协变精确成立**（A0b，用户点名的方向角依赖）：
>   ⟨p|V|q⟩(θ,φ)=e^{i(M_p−M_q)φ}⟨p|V|q⟩(θ,0)，三组 (θ,φ) max|Δ|≤4.4e-16；

>   如 1.46−3.50j MHz），交换元 J（ΔM=0）φ-不变——全程复数保留，绝不取实部；
> - 二阶 Löwdin downfolding：gg 支 vdW 位移 ≡ `vdw_shift` 全对角化，Δ=2%
>   （四阶 PT 截断，密集中间态流形上的正常误差；量级与符号正确）；
>   近简并中间态 guard 剔除并计数上报（n_guarded=32，不许静默）；
> - θ=0 总 m 守恒锚：A 元严格 0、J 元非零（A0e）；
> - ED 装配（2^N）：Ω≠0 厄米回归（修过一次"驱动漏 h.c."bug）、幺正演化 1.2e-14；
> - 任意点云验证：N=3 非共面几何端到端通过。
> **已知边界**（写进诚实声明）：J/A 支与 m 简并伙伴流形近简并 ⇒ downfolding
> 在该支不适用（guard 剔除），需要精确交换谱的场景应扩大模型空间或走
> `pair_eigen` 全对角化提取——M1 的 ED 装配层按"项开关+guard 报告"接线。
