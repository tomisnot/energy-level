## 1. 物理模型（两体、无近似）

```
H_2d(t) = [H_A0 + Σ_f Ω_f env_f(t)cos(ω_f t)·d̂_A] ⊗ I
        + I ⊗ [H_B0 + Σ_f Ω_f env_f(t)cos(ω_f t)·d̂_B] + V_dd
```

- 无 secular、无 RWA、无旋转系、无近/远通道分流：完整 V_dd（偶极-偶极）保留，近简并交换与远失谐 vdW 通道由精确传播自然涌现。
- 场为 `kind='exact'`（`waveforms.build_fields_exact` 构造）：单载频 ω_L 调制整个耦合矩阵 A，包络 `env_f(t)` 任意（逐节点精确采样，不做插值）。
- 耗散仅支持寿命通道：对角 −iΓ/2（NonHermitian），Γ_MHz = gam_ns/_CONV；loss 曲线 = 速率×布居梯形积分。显式落点/纯退相未实现（同 pair_evolve v1 限制）。
- 返回契约与 `pair_evolve` 完全同键，GUI 直接复用（`src/ui/evolve_worker.py`、`src/ui/ui_dynamic.py` 已接入）。

## 2. 数值架构

### 2.1 Sambe (t,t') 扩展空间
- 两体基 `k = i·N + j`（N²），光子维按 A/B 全部场的**相异载频**分组（同频共享光子维），索引 `idx = k + N²·p`。
- 结构：`K(t) = K_static + Σ_g c_g(t)·Kc_g`
  - `K_static = diag(E_pair + 光子偏移) + V_dd(块对角) − iΓ/2`
  - `Kc_g = 光子邻接（n→n±1，系数 1/2）⊗ 单位包络两体耦合`
- 物理布居投影：`ψ_phys(t) = Σ_p e^{−i(n_p·ω)t}·X_p(t)`（`_physical_pops`）。
- 虚部全零的复矩阵自动转实数（`_realify`，BLAS/eigh 提速 ~10×）。

### 2.2 稠密路径（扩展维 ≤ `_DENSE_MAX=700`）——已验证
- 段算符冻结于中点：本征分解精确指数（**绝对容差判厄米** `atol=1e-10`——能量标度 ~1e6 MHz，默认 rtol 会吞掉 Γ 虚部）+ 本征基 Duhamel 缺陷积分（逐节点向量运算，无逐节点 expm）。
- 误差控制：节点阶梯差（16/32/64/128）≤ tol 接受，否则真中点细分（可到输出网格以下，下限 `T/_DT_MIN_FRAC`）。
- 全常数包络快速路径：一次对角化 + 全输出时刻向量化重构。

### 2.3 稀疏路径（当前版本：IP Volterra–GMRES）——研究级
- 对角相互作用绘景 `φ = e^{+iD(t−ta)}ψ`（D = K_static 对角，含光子偏移）：
  `φ(t) = X + (−iC)∫_{ta}^{t} e^{+iD(t−s)} R(s) φ(s) ds`，R 只含非对角（V_dd + 驱动）。
  关键性质：**收敛速度与巨大对角能量标度（~THz）无关**——这是前两代算法（见 §3）失败后的核心认识。
- 节点配置：GL 节点上离散为**线性**系统 `(I−T)φ = b`，T 用全部分积分权重
  `Wpart[q,s] = ∫_{−1}^{x_q} L_s(x)dx`（`_volterra_rule` 缓存）。
- 求解：`scipy.sparse.linalg.gmres`，预条件 = 因果（cumsum）Picard 扫掠近似求逆（8 次）。未收敛 → 返回 est=inf → 交主循环细分（不返回垃圾态）。
- 端点：全区间 GL 求积。估计器 = max(节点阶梯差, GMRES 相对残差)。
- M 探针：常数峰值包络传播，M vs M+1 布居差 ≤ tol；稀疏探针窗口 `max(10ns, T/4)`，差值按 `(T/T_pr)²` 外推（截断泄漏幅值随时间线性增长 → 布居差 ~T²，实测吻合）。

## 3. 算法演化史（给下一任的最重要部分：死路与教训）

### 第一代：逐节点 `expm_multiply` + Duhamel 缺陷（v1 交付）
- 发现 `scipy 1.15.2 expm_multiply` 不接受 `tol` 参数（4 处修复）。
- N=20/dim≈2000 场景 >25 分钟不可用 → 弃。

### 第二代：共享 Arnoldi 子空间冻结传播（本次会话前半）
- 思路：段算符冻结于中点，Arnoldi 子空间按 K 对初态/残差方向的作用闭包构造，子空间内小矩阵指数 + 子空间内缺陷积分。对巨大对角标度"原理上精确"。
- 实做成果：实数化（12×）、SVD 秩截断热启动、泄漏估计自适应维度。
- **死因（关键认识）**：两体算符的非对角谱展宽（V_dd 通道分离 ~数百 GHz）使得所需子空间维度随 `C·‖R‖·h` 增长，m 需 200+；高维饱和区热启动基被舍入噪声方向污染（warm vs cold 差 4.3e-2），泄漏估计在 ~1e-6 处停滞。
- **已删除**（`_ArnoldiState`/`_sub_apply`/`_defect_pass_sub`），勿复活，除非解决高维饱和污染。

### 第三代：对角相互作用绘景 + Volterra–Picard（当前）
- 常数包络链验证到 **1e-11**（dim 2000，h≤1ns）——机制本身正确。
- 但发现两个坑：
  1. **因果截断（cumsum）有系统偏置**：截断 `q'≤q` 等价于丢弃 Lagrange 基尾部权重，长链（200 段）范数漂移 2.5e-2 → 不可用；
  2. **全权重（Wpart）+ Picard 迭代边缘不稳定**：迭代矩阵谱半径 ≈1，res 平台 ~1e-8 后发散（tol 收紧时爆炸）→ 不可用；
  3. **GMRES 直解配置系统**（当前方案）：无条件稳健，但配置离散化误差 + 光子截断外推误差使长窗口累积 ~1e-4 量级，未达段 tol。

### 失败但值得记录的尝试
- **Volterra-Picard 逐耦合对指数拟合权重法**：发现 m 无关系统误差（6.1e-3），放弃。
- **探针实用下限 `_PROBE_FLOOR=1e-4`**：Krylov 时代用于抑制探针噪声，Volterra 机制下不再需要且会低估小体系所需 M，已移除。

## 5. 已知问题与瓶颈

### 5.1 稀疏路径精度上限（最重要）
- 200ns 小体系（dim 20/36）累积误差 ~3e-4（稠密参考），来自两处：
  1. 节点配置离散化（Wpart 配置解与真 Volterra 解之差，阶梯差估计器部分低估）；
  2. 光子截断（探针外推 (T/T_pr)² 是保守启发式）。
- 段误差 ~1e-6..1e-7 相干累积 ×200 段 → 1e-4 量级。
- **提升方向**：配置解的缺陷修正（用节点残差构造 δ 积分）或谱配置（Chebyshev）替换 GL 配置。

### 5.2 稀疏路径速度（未达标）
- 实测：N=20/dim=2000 场景，主循环接受段长 ~0.0156ns（tol=1e-6，振荡求积分辨率限制），~64 段/ns → 400ns 需数万段，分钟级以上。
- 探针（外推后）在强驱动长窗口会把 M 推高（dim 随之增长）。

### 5.3 根本瓶颈：IP 被积函数振荡求积
- 相互作用绘景被积函数 `e^{+iD(t−s)}Rφ` 的振荡频率 = D 差（光子块间 ~C·ω、对态间 ~C·ΔE_pair），GL 求积需要 `n ~ C·ΔD_max·h` 个节点。这是段长上不去的根本原因。
- **出路（路线图首选）**：逐分量对振荡解析求积——把 `∫e^{iΔD·s}·(const over segment) ds` 解析算出（`(e^{iΔD h}−1)/(iΔD)`），节点只用于包络（慢变）部分。V_dd/驱动耦合稀疏（nnz ~数千），按 (行,列) 分量对组织权重可行（单原子侧曾有 `Wosc` 原型）。
- 备选：Magnus/分裂 + 子步（误差估计困难，不推荐作主线）。

## 6. 环境与工程坑（必读）

1. **BaiduSyncdisk 同步冲突**：代码库在同步目录内，历史上多次出现保存失败/内容横跳/新建文件被清空（0 字节）。用户已暂停同步，恢复前务必提醒用户保持暂停或移出仓库。**任何大改用整文件 Write 恢复比增量 SearchReplace 安全。**
2. **僵尸进程**：超时的基准进程不会自动退出（曾累积 51 小时 CPU 时间），占满 CPU 并使进程启动间歇性"拒绝访问"。跑长任务后检查 `Get-Process python | ? CPU -gt 100`。
3. **旧字节码**：同步扰动可能使 `__pycache__` 与源码不同步，出现"改了没生效"——先删 `src/core/__pycache__/evolve_exact_pair*.pyc` 再跑。
4. **本机数值栈慢**：复数 `np.linalg.eig` 140×140 ≈ 168ms（实对称 `eigh` ≈ 13ms）。实数化收益巨大。

## 7. 路线图建议（按优先级）

1. **振荡解析求积**（§5.3）：解决稀疏路径段长问题，是达成 ≤60s 目标的唯一已识别可行路径。
2. **配置解缺陷修正**：提升稀疏路径单段精度到段 tol，消除 EP6 研究级标注。
3. **探针外推校准**：(T/T_pr)² 目前单点实测吻合，需更多场景验证（特别是多载频分组）。
4. **numba 化**：仅当 1-2 完成后仍有瓶颈才考虑（当前瓶颈是算法段长而非单段开销）。
5. 稠密路径无已知问题，勿动。
