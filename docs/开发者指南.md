# Energy Level 开发者指南

Energy Level 的领域实现由模型、数值协议、引擎线程和工具接线组成；mecha 只提供写权、事实记录、任务、产物和操作者适配。

## 代码结构

| 区域 | 职责 |
|---|---|
| `src/core/` | 物理模型、协议、能级和演化算法 |
| `mecha_v2/engine.py` | EL 自己的计算协调器和引擎线程边界 |
| `mecha_v2/tools.py` | 配置、查询、驱动、演化、任务和组合调用 |
| `mecha_v2/bridge.py` | GUI、共享进程和 MCP 的装配桥 |
| `app_entry.py` | GUI、服务和统一启动入口 |
| `dsh/` | AI 宿主侧的面板资产 |

## 运行边界

`ElEngine` 负责 build → check → evolve → summary，并处理 ARC cache 的线程亲和性。mecha `Surface` 不承载引擎；EL 工具直接调用项目协调器。配置状态进入 `Gate`，计算规格从快照复制后再叠加 `spec_patch`，不修改共享配置。

## 工具路径

只读查询注册到 `Surface.QUERY`，写动作通过 Gate 和工具闭包完成。`run_actions` 使用项目提供的 dispatcher 组合查询、估算和演化动作；每一步带名称、结果和失败原因。后台演化通过 mecha Jobs，结果通过 ArtifactStore 或项目结果引用返回。

## 修改原则

物理语义和数值判断留在 EL；通用治理留在 mecha。修改引擎线程、配置快照、任务终态或工具回执时，运行对应的小尺寸物理检查和真实接线检查。领域说明、单位和适用范围写在用户手册，不把实现细节暴露给 AI 工具描述。
