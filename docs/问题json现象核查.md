## 2. 现象 ①：B 侧"无光 / 微弱光"结果不同

### 2.1 现象描述

将 B 侧波形删除（无光）与保留 1e-6 光，交换结果不同；且 B 无光时交换几乎完全消失。

### 2.2 复现数据（当时）

脚本：`tempsimu/repro_issue.py`（含 22 态、auto decay、R=10/θ=45°）：

```
①A光 / B无光    |1>峰=0.0000 |2>末=1.0000  lossA=0.0000
①A光 / B≈0光(1e-6) |1>峰=0.0291 |2>末=0.9835  lossA=0.0045
```

- B 无光：初态布居完全不动（|1⟩ 峰 0、loss 0）——目标交换对「不共振」；
- B 加 1e-6 光（物理上可忽略）：出现少量转移与 loss——结果对"是否加那点光"敏感。

### 2.3 机制分析（当时结论）

旋转参考 `_ip4_reference`（级联 RWA 参考）：从能量最低组（6P，ref=0）出发，沿每个
RWA 场的驱动对传播 `ref[高能组] = ref[低能组] + ω_L`。A 光（295.7 THz、近共振
60S↔6P、RWA）→ **ref[60S] 被平移 295.7 THz**（把 60S↔6P 对拉进失谐 ~620 MHz 的旋转系）。

但 **60P 不在 A 光的驱动对里**（60P↔6P 的 Δl=0 无偶极，不传播）→ 60P 的 ref 保持 0
→ **60S 与 60P 之间出现 ~ω_L = 295.7 THz 的旋转系假差**。

关键数值（`tempsimu/attr_issue1.py`）：

```
[B 无光]  ref_B 非零: []                       目标对 |1>-|2> 差 = −295723967 MHz（≈−295.7 THz）
[B 1e-6光] ref_B 非零: [(0, 295723987.5), (1, 295723987.5)]   目标对差 = +20.224 MHz
```

- B 无光：k1=(60S−1/2;60P+3/2) 的 A 侧 60S−1/2 被 −295.7 THz 平移、B 侧 60P+3/2 不动
  → 目标对差 ≈ −295.7 THz → 交换被判"远失谐" → 无交换；
- B 加同频微弱光：ref_B 把 B 侧 60S+1/2 也平移同样的 295.7 THz → 目标对差恢复
  +20.22 MHz → 出现少量转移/loss——**属两侧平移恰好抵消的巧合，不是 1e-6 光的物理**。

旁观态归一（coupled 集合减公共参考）**不消除该差**：k1/k2 均含耦合态（60S/60P/6P
均在驱动或 V 耦合集合内），整体平移不减相对差。

### 2.4 本质

同一能级被**频率量级悬殊的两个 RWA 场**同时驱动（60S 连 295.7 THz 光的 60S↔6P 对，
又连微波 60S↔60P 对）时，旋转参考只能取**单一平移值**：
- 按光（295.7 THz）平移 → 60S↔60P 微波对的旋转系差也被拖到 ~295.7 THz；
- 按微波（17 GHz）平移 → 60S↔6P 光对差回到 295.7 THz（光 Rabi 高频振荡失效）。

参考传播把 295.7 THz 平移给了 60S（按光对），未参与该光的 60P 不共享 → 假差产生。
这是「光频 + 微波同挂一个态」场景的固有参考冲突，不是数值误差。

### 2.5 当前状态（核查时对照）

- 当时**未改动算法**，记录为「待复核边界」（README §10.1 条目 6：多频 RWA 参考传播）；
- 复查步骤建议：
  1. 加载 `save_state/问题.json`，分别跑「B 无光」与「B=1e-6 光」；
  2. 打印目标交换对（|60S−1/2;60P+3/2⟩ ↔ |60P−1/2;60S+1/2⟩）的旋转系能量差：
     - 若 B 无光时仍 ≈ ±295.7 THz → 现象仍存在（参考污染未处理）；
     - 若已 ≈ 0（A 光位移校准后）→ 现象消失/已缓解；
  3. 对比 |1⟩ 峰与 lossA：两配置应一致（物理上 B 光可忽略）。

## 3. 现象 ②：A 方波上升沿形状影响交换结果

### 3.1 现象描述

将 A 原子方波的上升沿（0–20 ns 段）改为多个取值（多段/阶梯逼近斜坡），交换结果
完全不同。

### 3.2 当时核查结论

**未能在「目标对真正共振」的条件下验证**——当时 A 光（5e7 mW/cm²）配置下目标交换对
受现象 ① 的 ref 假差影响（B 无光时差 ≈ −295.7 THz）→ 无交换 → 上升沿差异被"无交换"
掩盖，无法区分是物理（沿内频移建立过程的相位敏感）还是引擎问题。

复现数据（`tempsimu/repro_issue.py`）：2 ns 沿与 20 ns 阶梯沿在 B 无光下 |1⟩ 峰均
= 0.0000（都无交换，无从比较）。

### 3.3 复核步骤建议

1. 先消除/避开现象 ①（如 B 侧加与 A 同频光使参考对称、或改用现象①已修复后的环境）；
2. 确保目标交换对共振（A 光位移按引擎校准后目标对差 ≈ 0，|1⟩ 峰应显著 > 0）；
3. 在共振条件下对比：A 方波 edge=2 ns vs edge=20 ns（或 0–20 ns 多段阶梯）；
4. 判据：若仅沿内（<20 ns）差异、平台段（20–200 ns）行为一致，且相位累积可解释
   （交换周期 ~340 ns、200 ns 窗口内对沿内相位敏感）→ 物理合理；
   若平台段后结果仍显著发散 → 需复核包络采样/absorb 平台判定。
