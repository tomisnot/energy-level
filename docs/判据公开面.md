> 目标：**判据只走公开面**——改引擎内部时，判据不该跟着碎。
> 结果：私有依赖从「20 个名字 import + 11 处点号直取」降到 **3 项**（全部显式白名单化）。
> 纪律：先证明等价、覆盖只迁移、不套层。

## 关键发现：那 20 个"私有依赖"里有一大半是**空声明**

改之前我先做了两件事：**逐名查 DEF/import** + **逐名查真调用次数**。

第一查（DEF vs import）就暴露了 6 份**重复的单位常量定义**：

| 位置 | 内容 |
|---|---|
| `src/core/evolve_util.py` | `CONV = 2π·1e-3`（**正本**） |
| `src/core/evolve_sambe_pair_gpu.py` | 自己又定义一份 |
| `checks/evolve_exact_pair_selfcheck.py` | 自己又定义一份 |

| `checks/pair_evolve_selfcheck.py` | 自己又定义一份 |
| `checks/two_field_pair_selfcheck.py` | 自己又定义一份 |

**⇒ 不只是"import 了私有名"，而是 4 个判据各抄了一份单位约定。**

第二查（真调用）更关键——`evolve_rwa` 那 7 个"权威锚"里：

| 文件 | 真调用 | **死 import** |
|---|---|---|
| `evolve_dissipative_selfcheck` | `_e_rot`×2、`_ip4_reference`×3 | `_evolve_full`、`_evolve_full_hybrid` |
| `evolve_exact_selfcheck` | **无** | `_e_rot`、`_evolve_full`、`_evolve_full_hybrid` |

**⇒ "判据绑死私有 API"这个判断方向对，但规模被我高估了**：声明 20 个，实际只用 5 个。

## 做了什么

### ① 公开能力：去下划线（296 处改名）

| 旧 | 新 | 正本 |
|---|---|---|
| `_CONV` | `CONV` | `evolve_util` |
| `_as_vector` | `as_vector` | `evolve_util` |
| `_as_pair_vector` | `as_pair_vector` | `evolve_util` |
| `_resolve_state_idx` | `resolve_state_idx` | `evolve_util` |
| `_decay_ops` | `decay_ops` | `evolve_util` |
| `_sublevel_row` | `sublevel_row` | `field_build` |
| `_group_by_freq` | `group_by_freq` | `field_build` |
| `_env_samples` | `env_samples` | `field_build` |
| `_field_geometry` | `field_geometry` | `field_build` |
| `_sublevel_energy` | `sublevel_energy` | `static_atom` |
| `_dc_stark_hf` | `dc_stark_hf` | `static_atom` |

改名一律用**词边界正则一次性替换**（`(?<![A-Za-z0-9_])…(?![A-Za-z0-9_])`），
避免 `_as_pair_vector` 被 `_as_vector` 误伤、`_DD_CONV` 被 `_CONV` 误伤。
**6 份重复常量删掉，改为从 `evolve_util` 单源导入。**

### ② 权威锚：只改真正被用的两个，删别名

| 旧 | 新 | 说明 |
|---|---|---|
| `_rwa_reference` | **`reference_rwa`** | ip4 的旋转参考构造（**不是**引擎） |
| `_e_rot` | **`reference_e_rot`** | 旋转系对角能 |
| `_ip4_reference` | **删**（`= _rwa_reference` 的别名；判据 3 处调用改指 `reference_rwa`） | 名字像"ip4 引擎"，实为参考构造 —— **命名本身就是误导** |
| `_evolve_ip4` | **删**（无使用者） | |

**保持私有不改**：`_evolve_full` / `_evolve_full_hybrid` / `_evolve_rwa` / `_assign_reference`
——它们在判据里**全是死 import**，是 `evolve()` 的内部件。**内部件保持私有才是对的**，
不该为了让判据好看而"提为公开"。

### ③ 白盒依赖：改写 2 个 + 白名单 3 个

| 名字 | 处置 |
|---|---|
| `_group_sublevel_rows`（判据 4 处点号直取） | **判据改走公开的 `base_sublevels`**（`base_sublevels(cache, [dict(n,l,j)], B)` 与它逐位等价） |
| `_dc_stark_hf` | **提为公开 `dc_stark_hf`**（真能力：超精细态的 DC 位移） |
| `_MixedSetup` / `_assemble_H_snapshot` / `_pack_pair_hard` | **保持私有**——它们是**合法的白盒测试对象**（构造引擎 setup 验 T 自适应/成本上限、验 H 快照尺寸闸、验 V_dd 打包）。**提为公开会高估它们的地位。** |

三个白盒接口**写进了模块 docstring**（`evolve_mixed.py` / `hard.py` 的「判据白盒接口」段），
并加了**判据强制**：

```python
# engine_contract_selfcheck.py 的 F 包
_WHITELIST = {
    ('src.core.evolve_mixed', '_MixedSetup'),
    ('src.core.evolve_mixed', '_assemble_H_snapshot'),
    ('src.core.hard', '_pack_pair_hard'),
}
```
**白名单之外新增任何私有 import 或点号直取 → 判据红。**
白名单里失效的项（不再被用）也报——**这是一个会自己收缩的契约**。
新增一项要改判据，**这是刻意的摩擦**：私有耦合必须是显式决定，不能顺手长出来。

## 过程中暴露的两个真问题

### ① `hard.py` 的 `CONV` / `_CONV` 同名遮蔽（既有隐患）

源仓 `hard.py::_pack_pair_hard` 里有 `CONV = float(_CONV)` ——
**局部变量 `CONV` 与模块常量 `_CONV` 同名但不冲突**（一个带下划线一个不带），
所以一直跑得好好的。**我的"去下划线"把它们合并成一个名字** ⇒
`CONV = float(CONV)` 变成局部读自己 ⇒ `UnboundLocalError`（4 个判据同时红）。

**修法**：那个局部本来就是多余的转换 ⇒ 删掉，返回处直接 `float(CONV)`。
**这是"统一命名"暴露出来的既有隐患**——同一函数里两个名字只差一个下划线，迟早出事。

### ② 我自己的脚本漏了 `src/_archive/`

改名脚本的 skip 列表里有 `_archive`，但 `evolve_floquet_pwc.py` 会 import 那两个名字
⇒ `evolve_exact_selfcheck` 红。补改 17 处。
