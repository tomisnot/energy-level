# EL 运行观察

AI 模式 `python app_entry.py --mcp` 自动启动本机只读页面。端口在 `.run-monitor-port`，
`EL_OPEN_RUN_MONITOR=0` 关闭自动打开。没有创建、重跑、删除运行等写入口。
最新卡片在前，滚轮、方向键和历史栏翻页。能级可按组展开/折叠，波形来自真实输入。
页面采用浅色底（色块/连线在浅底上对比更可靠）；运行卡片输入:输出宽度为 1:2，
简单参数两列排布；输入原子几何和输出原子阵列都按正方形绘制，避免 x/y 独立拉伸。
两处阵列图都支持鼠标拖动平移、以鼠标为中心滚轮缩放，双击复位；
滚轮在阵列图上优先于卡片翻页；
原子选择器额外提供“初态 ⟨σᶻ⟩”，对直积、叠加、纠缠态都显示逐格点局域均值。

## 一次调用对应一张卡片

- `ElEngine.run` 在 build 前登记卡片，再更新实际 RunSpec；构建失败也留下原因。
- GUI `ElOps.prepare/execute` 复用同一记录；重复 execute 创建新记录。
- store 默认保留最近 32 条，正在运行的卡片不因数量上限被删除。
- `/api/runs` 只轮询输入和摘要；选中完成卡片后才请求 `/api/runs/<id>/result`。
- 原始引擎结果完整保存在 pickle artifact，`/api/runs/<id>/artifact` 只提供该记录
  已登记的存档，不开放任意路径。绘图 JSON 下载是有界预览，两者用途不同。
- 页面没有演示结果回退。离线明确显示连接状态；原有真实卡片可继续查看。

## 按数据语义映射，不按求解器分支

服务端 `mecha_v2/visualization.py` 消费 `data_schema`、真实坐标与基身份，前端
`visualization.js` 按 dataset kind 渲染。以下均以引擎**实际返回**该数据为前提。

| 数据 | 主视图 | 补充/交互 |
|---|---|---|
| 局部占据 `pops_atom / n_atom / occupations` | 原子位置上的连续色节点，含时则动画 | 点选原子，真实时间/β 曲线；已有标准误则画误差带 |
| `corr / xy_corr / link_corr` | 原子之间的连线：颜色为值、粗细为强度 | 选择参考原子、隐藏弱关联、点选边；矩阵对角元另有节点视图 |
| 复关联 | 实部/虚部/幅值/相位切换 | 相位色环；相位模式线宽仍为幅值，不把相位误标成电流 |
| 局部相干 `sp / sm / phase` | 节点颜色 | 复值切换、选点曲线；零幅值相位显示缺失 |
| 自旋 `spins` 或局部 `sx/sy/sz` 期望 | 节点颜色为 z 分量，箭头为自旋 x/y 分量 | 分量曲线；期望值箭头不声称重建完整量子态 |
| `loop_phase / loop_winding` 与 series | 按实际 loop 身份描出多边形并标值 | 含时曲线/播放；不把绕数强制取整或称作 Chern 数 |
| `S` | 标记求解器实际 A/B 子系统并显示二分熵 | 保留 S 曲线；没有切割身份时只画曲线/数值 |
| 联合构型概率、`vec / psi_amp` | 选择构型后，阵列显示 g/r 图案与其概率 | 主要 16 个构型、概率曲线、原生振幅相位；使用完整空间基身份 |
| 单体/两体态布居 | 主要态随时间的曲线 | 具体态标签和选择，不假设它们是多体原子占据 |
| 能量、损失、范数漂移、热力学 `E/C/F`、ramp、DOS | 真实横轴曲线 | 正负值、缺失段、已有标准误；这些全局量不强行涂成局域量 |
| `evals / one_particle_energies` | 能谱横线 | 已有单粒子轨道占据身份时区分占据/未占据 |
| `jump_counts` | 次数分布柱图 | ≤40 种计数保持离散值，更多时明确合箱 |
| QMC 平均符号、样本数 | β 曲线或标量 | 计算诊断中保留可用元信息 |
| 原生 MPS 等张量态 | 类型、后端、顺序和荷扇区元信息 | 完整张量留在存档，不把巨大对象转成字符串发给浏览器 |

仅末态 `corr/xy_corr` 不会伪造为含时关联。复矩阵以有序 `(i,j)` 的上三角元绘制，
反向元不重复画；含时关联使用引擎返回的 `link_pairs`。几何提供 XY/XZ/YZ 等比例
投影、物理比例尺与点选坐标读数；没有坐标时不猜测原子排列。

## 动画和规模约束

所有可播放的序列固定 **8 秒一轮**，可暂停、拖动、循环；8 秒是页面设计选择。
滑块按实际横轴定位最近的真实采样点，不插值编造物理中间态。颜色范围在整轮固定，
占据使用 0–1，自旋分量使用 −1–1。缺失/NaN 为 null，不能当作零。

绘图最多 160 帧，主要观测数组预算 240,000 数值单元（复值计两份），最多 700 条关联边，主要构型最多 16 个，
能谱最多 256 级。降采样保持首尾，界面说明抽样/截取；高维数据按预算略去并提示。
完整数值始终以运行存档为准。未计算的观测量不会为展示而暗中追加昂贵计算。

## 文献参照与本项目的选择

1. Browaeys & Lahaye, *Many-body physics with individually controlled Rydberg atoms*,
   Nature Physics 16, 132–142 (2020)，尤其空间链与激发概率展示。
   [作者公开 PDF](https://thierry-lahaye.org/wp-content/uploads/2020/02/2020_browaeys_naturephys-16-132..pdf)。
2. Mao, Ma & Xu, *Chiral Spin Liquid in Rydberg Atom Arrays*, arXiv:2603.21147v1
   (2026)，Fig. 2(a) 将自旋关联画成阵列上的彩色键。
   [原文及图注](https://arxiv.org/html/2603.21147v1)。

从中采用“保持真实空间身份”和“用键表达二点关联”的方法。固定 8 秒、颜色/粗细双编码、
点选追踪和按数据种类切换是本项目的交互设计，不是上述论文的实验结论。
