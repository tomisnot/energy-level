# 原子能级计算器（Rb-87 / 通用碱金属）

一个面向里德堡原子实验的**原子能级 + 寻址光 AC-Stark + 两体耦合雷达图 + 单原子含时演化**计算与可视化工具。界面可直接交互：实时调整磁场 / 电场 / 光场，直观看到能级位移、超精细结构、谱线变化，并通过点击谱峰定位跃迁对；动态页可直接在右侧面板配置**光波形列表**（无通道、无独立窗口），模拟任意多场同时作用下的态演化。

> 本项目以 Rb-87 为默认原子，但物理核心与 ARC 库解耦，**可切换到任意 ARC 支持的碱金属原子**（Cs、Li、Na、K…）。

## 二、科学计算核心算法

### 2.1 单原子含时演化引擎（`src/evolve.py`）

**问题**：给定能级（fine + Zeeman + 超精细，含 B 场）与任意多组时变光场（频率 / 光强 / 偏振 / 包络形状 / 起始偏移），求各态布居随时间的演化 P(t)。

**统一场算符**（Pulser 范式）：每个物理光场 = **一个算符**

```
M_k = A_k + diag(ac_k)
```

- `A_k`：近共振驱动对的**真实 Rabi 耦合矩阵**（含偶极选择定则与相对强度）
- `diag(ac_k)`：该场对**远失谐态的二阶 AC 位移**（SOS，对角）

演化哈密顿量：

```
H(t) = H0 + Σ_k env_k(t)·M_k
```

**驱动与能移不分流**——Rabi 耦合与 AC 位移同属一个场的效应，随包络 `env_k(t)` 一起时变（光场开启期间位移才存在，关闭即消失）。这避免了"常数 AC 位移全时段生效"的物理错误（曾导致光场未开时提前破坏微波驱动的 bug）。

**统一级联旋转参考系**：多场共享能级时（如光频 6P↔60S 与微波 60S↔60P 共用 60S），以 (n,l,j) 组为单位从最低能级组出发，沿每个场的耦合对传播旋转参考 `ref[高能组] = ref[低能组] + ω_L`，使每个驱动对在旋转系里共振；纯位移场不参与传播。闭环不一致的驱动留下残留拍频（按 RWA 丢弃并警告）。

**四个档位**（method 参数；`auto` 自动调度）：

| 档位 | 适用 | 原理 | 精度/成本 |
|---|---|---|---|
| `floquet` | 常数包络 + 单频 | 精确积分**一个驱动周期**得传播子 U(T)，本征分解准能量 εₙ，ψ(t)=U(τ)·W·diag(e^{−iεₙt})·W†·ψ₀ | 机器精度，成本与时长无关 |
| `ip4` | 任意时变包络（默认精算） | **相互作用绘景 RK4**：H0=diag(E−ref) 相位精确除去，Ṽ(t)=Σ env(t)·M 的 u-变换耦合；光频（Ω/ωL<1e-4）RWA 旋转系，微波非 RWA 保留 cos(ωt)；步长 = 最快非 RWA 载波周期/frac | ~3e-5（frac=20）~1e-6（frac=40），20-30 s |
| `pwc` | 快速预览 | RWA 分段常数 + 每段 eigh 对角化（numpy/torch 批量） | 最快（0.1-0.3 s），RWA 误差 ~Ω/ωL |
| `auto` | 默认 | 常数包络+单频 → floquet；否则 → ip4 | 自动最优 |

**ip4 关键实现细节**：
- 相互作用绘景 Ṽ 对角项（AC 位移）随包络时变，|u|²=1 相位自动抵消——**统一场算符无需独立 ac 机制**
- 步长三重约束：载波分辨率（最快非 RWA 振荡 /frac）、RK4 精度（dt·‖Ṽ‖≲0.06）、稳定性（dt·‖Ṽ‖<2），另加 500 步下限与 0.05 ns 上限
- 旁观态（无耦合）E_rot 归零、耦合态减共同参考——避免光频量级参考使 u(t) 相位爆炸
- numba JIT 稀疏 CSR 内核（nogil，进度可轮询/取消），numpy 回退
- `progress_arr` 共享进度数组：主线程轮询进度、请求取消（抛 RuntimeError）

**第一性原理验证**（`checks/`）：
- `evolve_dissipative_selfcheck`（D 系列）：解析衰变 e^{−Γt}、CW/时变/交换耦合
  + 衰变 vs 独立 Liouvillian 本征参考与 solve_ivp 向量化主方程、纯退相 e^{−Γt/2}、
  **multi 场 ac 约定回归**（ip4/lindblad vs 第一性原理全额 ac）、取消、无耗散一致性
- `_archive/evolve_selfcheck`：单原子动态 vs `solve_ivp` 直接积分 H(t)（独立参考）
- `mw_bench_firstprinciples` / `evolve_matrix`：vs 独立 RK4-IP、floquet 精确解、高 frac 收敛
- 实测精度：S1 floquet 5e-13、S2 ip4 7e-07、S3 阶梯 2e-07、S4 制备阻塞 2.5e-09、S5 时变AC 5.4e-10

**Lindblad 主方程（自发辐射等马尔可夫耗散，算法 4）**：动态引擎在纯幺正
TDSE 之外提供耗散的第一性原理描述：

```
dρ/dt = −i[H(t),ρ] + Σ_k ( L_k ρ L_k† − ½{L_k†L_k, ρ} )
L_k = √Γ_k |to_k⟩⟨from_k|        （decay(g, Γ, e) 工厂；Γ 单位 MHz）
```

- `method='lindblad'`：矩阵 RK4（ρ 为 N×N；rank-1 跳变按 O(N²) 快速路径），
  任意时变包络，含非 RWA 载波；步长三重约束同 ip4（载波/精度/稳定 + 500 步下限）。
  **numba 内核**（稀疏 H + ρ 厄米对易子一次点乘、S 预计算到 dt/2 子网格、
  RK4 阶段精确采样、输出部分步线性插值、nogil 可取消）——非 RWA 微波场景
  （如初态制备 S4，~103 万步）从 numpy 纯循环的 ~40 分钟降到 ~1 分钟（42×，
  与 numpy 回退机器精度一致）；`backend='cpu'` 强制纯 numpy 回退（无 numba 时
  自动回退）
- `method='lindblad_eig'`：旋转系下 H 恒定（全 RWA + 包络恒常 + 无残留拍频）→
  **Liouvillian 本征分解精确解**（机器精度，成本与时长无关，同 tempsimu 参考实现）
- `auto` 含耗散时自动调度；显式纯幺正方法（floquet/ip4/pwc）配耗散自动切换并提示
- **旋转系下跳变算符时不变**（LρL† 与 L†L 中相位自动抵消）→ 耗散项与旋转参考
  选择无关，精确；结果新增 `loss`（离场布居，Σpops + loss = 1），GUI 画布叠加
- 单位约定：Γ MHz → 速率 Γ×1e-3 /ns（跳变算符**不乘 2π**——曾误乘致衰减快 6.28×）
- 设计对齐成熟开源（Pulser/qutip 噪声模型）：自发辐射 = 每通道一个跳变算符
  √Γ|g⟩⟨e|，主方程精确求解（等价 qutip `mesolve` 的 Lindblad 项；Pulser
  SPAM/NoiseModel 同款跳变算符范式），不引入任何唯象衰减因子

**自动档（ARC 权威寿命，默认）**：`evolve.auto_decays(cache, states)` 直接查 ARC
`getStateLifetime(n,l,j,temperature=0)`——由偶极矩阵元对全部下能级求和得到的
权威寿命，比逐通道算 A 系数更精准便捷；Γ = 1/τ。只含 τ ≤ 100 µs 的低激发态
（5P/6S/6P/4D 等，排除里德堡 ~0.1 ms+ 的慢自发衰变；需要里德堡/黑体辐射请用
自定义）。GUI 动态页"自发辐射"三档：**自动**（默认，按上表配置，落点=丢失，
运行后状态栏显示通道数）/ **禁用** / **自定义**（手动从态→Γ→落点，仅此档显示
配置区）。实测：6P3/2 τ=118 ns → Γ=8.46 MHz（ARC 权威值）。

> 2025-02 修复：ip4 曾把 multi 场（`real_field`）的对角 AC 位移随 M 一起 ×1/2，
> 使远失谐位移减半；已拆分为 Rabi 半耦合 + ac 全位移，D5 第一性原理回归钉死。

### 2.2 静态能移（`src/core.py`）

- **AC-Stark**：近共振（|Δ| < max(cutoff, Ω)）→ dressed 精确解（Autler-Townes ±Ω/2）；远失谐 → 非 RWA 二阶 SOS（含反旋项）。失谐精确到子能级（含超精细/Zeeman）。默认 `direct` 后端 = 完整哈密顿量对角化，`legacy` = 逐子能级解析/微扰。
- **DC-Stark**：二阶微扰 SOS，遍历全部偶极伙伴（含未添加组），E² 标度已验证。
- **偶极矩阵元**：ARC `getDipoleMatrixElement` 缓存；超精细 F↔mJ 经核自旋基展开，核自旋平均归一。

### 2.3 两体（`src/pair_core.py` + `src/driver.py`）

- pair 哈密顿量 = 单体张量积 + 偶极-偶极 V_dd(R,θ,φ)（含 σ+/π/σ⁻ 分量），本征分解得 vdW / 交换耦合能移。
- `driver.build_system(n_body=1/2)` 统一构造：单体寻址光 Rabi 算符 + 两体驱动（含封锁），线性响应谱（黄金规则）共用一套引擎。

### 2.4 精度与单位约定

- 内部频率统一 **MHz**、光强统一 **mW/cm²**（Python float64 全精度）；单位切换纯显示层换算，不丢位
- 频率/光强 spin 每单位给足 decimals（GHz 6 位、THz 9 位等，保证 1 kHz / 1e-6 mW 精度）；"定频率/定光强"写回内部全精度值（不经 spin round）
- 智能默认单位：显示值落 [1,1000)（微波→GHz、光频→THz、μW 光强→nW），只为可读不损精度

**环境**：Python 3.10+（实测 3.10）。**依赖**：

```
numpy  scipy  matplotlib  PyQt5  arc   (可选: numba 加速, torch GPU)
```

（`arc` 为 [ARC — Alkaline Rydberg Calculator](https://arc-alkali-rydberg-calculator.readthedocs.io/) 库，提供碱金属量子亏损、波函数、偶极矩阵元等。首次运行会生成项目内 `.arcdata/` 缓存，可 `python scripts\setup_arcdata.py` 预生成。）

**运行**（在项目根目录内）：

```bash
python 能级.py            # 启动 GUI
python checks\selftest_all.py   # 一键跑全部回归自检（3 个核心脚本，约 1 分钟）
```

## 四、使用说明书

### 4.1 界面布局（两页）

- **左侧画布**（QTab 切换）：
  - **静态页**：能级图（off/on 两能谱镜像对比）+ 谱峰点击联动
  - **动态页**：上 = 各波形**光强** I(t)（每波形独立 y 轴标度，颜色=频率对数映射，半透明下面积），下 = 态布居演化 P(t)（自动按平均布居选前 N 态）
- **右侧共用面板**：
  - **磁场 B (G)** / **电场 E (V/cm)** / **添加光** 同一行（B/E 两页共用，恒显）
  - **光场表格**（静态页）：序号 / 频率 (GHz) / 光强 (mW/cm²) / 偏振 / 作用范围；单击即编辑；右键菜单按列不同
  - 能级组管理、能级数值表、显示范围、参考频率 + 谱横轴范围、两体耦合雷达图（静态页最下方）

### 4.2 动态页

1. **配置波形**（右侧面板直接操作，无独立窗口/无通道/无面板内预览图）：
   点"＋高斯"或"＋方波"添加波形折叠组（标题栏 ✕ 删除）；展开后参数多列并排——
   频率（THz/GHz/MHz/kHz/Hz 智能单位）、光强（W/mW/μW/nW）、偏振、包络参数
   （高斯：中心/σ/峰值；方波：起点/沿/高度/下降）、起点偏移；编辑即时生效，
   光强/布居预览直接看左侧主画布
2. **辅助定参**（每个波形折叠组内"辅助"区）：选 g/e 态 + 目标Ω「定光强」反推光强写回、
   目标Δ「定频率」= 裸差+Δ 写回（内部 MHz 全精度）；实时反馈 Rabi/失谐
3. **（可选）自发辐射**：动态页"自发辐射"三档——
   - **自动（默认）**：按 ARC 权威能级寿命自动配置 Γ=1/τ（仅 τ≤100 µs 低激发态，
     落点=丢失；运行后状态栏显示通道数，画布叠加 loss 曲线）；
   - **禁用**：无耗散（纯幺正）；
   - **自定义**：手动加通道——从态 → Γ(MHz) → 落点（选"（丢失）"则布居离场；
     g==e 为纯退相）；常数 H 自动走精确本征解，时变包络走矩阵 RK4（第一性原理）
4. **运行演化**：选初态（两页共用能级组）、t_max/点数、方法（auto/floquet/ip4/pwc）→ 后台线程计算，进度条可取消
5. **观察**：上图画各波形光强 I(t)（每波形独立 y 轴，颜色=频率），下图画前 N 个平均布居最大的态（含 loss 虚线）

### 4.3 光场表格的右键操作（重要）

| 右键位置 | 功能 |
|---|---|
| **频率列** | `从跃迁对导出频率…` → 窗口：选跃迁对（按距当前光失谐排序）+ 失谐 Δ → 确定写回频率 |

### 4.4 两体耦合雷达图

- 位置：静态页右侧面板最下方（极坐标躺平半圆热图）
- 数据：固定 φ 方位角，扫描 R（间距，对数刻度）× θ（子午面 0~180°），颜色 = 耦合强度 |V_ex|
- **跃迁对选择**：点击 off 谱表/谱图 → 原子1 跃迁；点击 on 谱表/谱图 → 原子2 跃迁
  （耦合 = |⟨tgt1⊗tgt2| V_dd |src1⊗src2⟩|；交换对只在里德堡态之间，非里德堡全零）
- 鼠标悬停图内 → 实时读数 R / θ / φ / J（耦合强度）

### 4.5 基本流程

1. **添加能级组**：输入 `n / l / j`（如 60/0/0.5 添加 60S），点"添加"；重复可添加多个组（6P、60P…）
2. **设置磁场**：`B (G)` 输入框，如 21.7 G（两页共用）
3. **添加光场**：点"添加光"（默认 295724.048 GHz / 126849894 mW/cm²），表格里填频率 / 光强 / 偏振 / 作用范围
4. **右键频率/强度**：用"导出频率"或"扫描光强"快速设定光参数
5. **动态模拟**：切到动态页 → 波形区配波形（＋高斯/＋方波）→ 运行演化
6. **观察**：左侧画布看能级图 / 两能谱对比 / 波形光强 / 布居演化；点击谱峰高亮并联动峰表与雷达图

### 4.6 常见使用提示

- 想观察"某对能级在共振下的大位移"：**偏振方向决定哪侧共振**。例：σ⁻ 下 6P3/2 F=3 mF=3 ↔ 60S mJ=0.5 是 6P3/2 侧大位移；要让 60S mJ=+0.5 大位移请用 σ⁺。
- B=0 时超精细 F 内各 mF 简并，无法从频率区分同 F 不同 mF 的跃迁；B≠0（默认 21.7 G）才可区分。
- **失谐 Δ 正 = 蓝失谐**（光频率高于跃迁）；导出频率 = 跃迁频率 + Δ。
- 扫描光强的目标 = **单一能级**的 AC 位移（不是能级对频移）；某对只能往负方向位移时正目标会报"未收敛"，改符号或换能级。
- 共振光若同时作能移会把自己 dressed 推走（0 峰）——只对"关注跃迁"光作驱动，其余作能移。
- **光场做"频移阻塞"须远失谐**（Δ≫Ω）：近失谐光场会真实转移布居（Ω²/(Δ²+Ω²) 量级），动态演化如实反映——6P 等低激发态布居会损失，方案设计时注意。
- 频率输入精度：波形面板频率/光强内部 MHz 全精度；"导出频率"给出逐位精确的共振频率，避免 THz/GHz 档小数位丢精度。

### 4.7 已知环境问题与规避（2025-02 排查记录）

- **Qt 原生堆损坏崩溃（0xC0000005）**：在 GUI 主线程事件流里（tab 切换 / matplotlib
  渲染之后、窗口创建前后）调用 ARC `getStateLifetime`（`evolve.auto_decays`）会在
  **稍后无关的 Qt 控件操作**处崩溃（堆损坏延迟显现，崩溃点与改动点无关）。已通过
  "门槛只做廉价判断（`any(s['n']<=15)`）、寿命计算只在真正运行时执行一次"规避
  （见 `src/ui_dynamic.py` `_run` 注释）。**规避原则**：① 不在 GUI 门槛/准备路径做
  批量 ARC 计算；② ARC 计算与 Qt 控件操作不穿插；③ 重计算放 worker 线程（运行时
  路径实测安全）；④ 新增 GUI 流程的 ARC 调用后必须跑 `checks/ui_selftest.py` 回归。
- **QMessageBox + offscreen 崩溃**：离屏（无显示）环境下真实弹窗会崩——ui_selftest
  已 monkeypatch 规避；手写离屏测试脚本时同样处理（不要真弹窗）。
