# 截图自查清单（每轮交付前逐项过）

> 纪律：功能对了不等于能交付。**UI 检验的权威标准是"放大后的画面逐元素
> 核对"**——截图必须放大到元素级（每个徽标、每块文字、每条线）核对位置、
> 对齐与可读性；缩略扫一眼整体构图不算检验。
> （教训：曾有两轮只在整页缩略上扫一眼+跑几何断言就交付，被用户一眼指出
> "色块和文字偏离""轴标签穿插"——几何断言只覆盖外框，查不出组合元素
> 内部的相对错位。组合绘制（色块+文字、线+标记）必须配对断言内部对齐。）

## A. 排版关（看一眼就能发现的那种问题）

- [ ] **文字可读**：没有方框（CJK 字体）、没有被裁剪的字（贴边/截断）、
      没有相邻文本互相穿插重叠；
- [ ] **字体一致**：同级信息字号一致；主体内容的醒目度 ≥ 辅助内容
      （主体如果比辅助表格还小气，就是布局失败）；
- [ ] **空间利用**：没有大片无意义空白；卡片/面板占满应占的区域；
      标签页切换后布局都正常（隐藏页尺寸为 0 的坑）；
- [ ] **对齐参照**：图形刻度与数据有对齐手段（网格线/分隔线/斑马条）；
- [ ] **无遮挡**：弹层、旋转文本、图例不压在数据或别的控件上；
- [ ] **颜色语义一致**：同一含义在公式、图例、勾选项里用同一颜色。

## B. 功能关

- [ ] 每个新控件的三态都验证：默认态 / 填了值 / 填了非法值（解析失败要有
      提示不能崩）；
- [ ] Qt 信号直连的方法：确认信号载荷（bool 等）不会污染业务参数；
- [ ] 运行后回调路径：有数据 / 无数据 / 用户取消 三种结果都有合理 UI；
- [ ] 覆写参数：默认（空）结果与不覆写逐位一致（零侵入验证）；
- [ ] 大数据量场景：dim 最大时页面仍可用（下采样/导出兜底）。

## C. 回归关

- [ ] 项目原有 UI 回归测试全绿；
- [ ] 新功能默认关闭时，旧路径行为逐位不变。

## D. 自查方法

1. 对每个页面/对话框单独截图（不要只截主窗口）；
2. 缩放场景单独截图（放大到局部后标记是否随动、是否重叠）；
3. 对比上一轮截图确认改动生效（离屏渲染是确定性的，像素级可比）；
4. 把发现的问题记入 pitfalls.md——同类坑会复发。
